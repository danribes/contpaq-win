# T028.2 - Tesseract Bundle Learnings

**Task**: Bundle Tesseract OCR with Electron app
**Date**: 2025-12-18

## Key Learnings

### 1. Tesseract Windows Distribution

Tesseract for Windows is distributed by UB-Mannheim:
- Repository: https://github.com/UB-Mannheim/tesseract
- Latest version: 5.3.3 (as of 2024)
- Installer or portable distribution available

**Key components:**
- `tesseract.exe` - Main executable (~15 MB)
- `leptonica-*.dll` - Image processing library
- `libcurl-*.dll` - Network support
- `tessdata/` - Language models

### 2. Language Data Variants

Tesseract offers three language data variants:

| Variant | Size | Speed | Accuracy |
|---------|------|-------|----------|
| tessdata | Large | Slow | Best |
| tessdata_fast | Medium | Fast | Good |
| tessdata_best | Large | Slowest | Highest |

For invoice OCR, `tessdata_fast` provides the best balance:
- Fast enough for real-time use
- Accurate enough for structured documents
- Smaller download size

### 3. Bundling Native Binaries in Electron

Use `extraResources` for external executables:

```json
{
  "extraResources": [
    {
      "from": "resources/tesseract",
      "to": "tesseract",
      "filter": ["**/*", "!**/doc/**"]
    }
  ]
}
```

**Why extraResources instead of files:**
- Not included in ASAR archive
- Accessible as regular files
- Can be executed by child process
- Path via `process.resourcesPath`

### 4. Path Resolution Strategy

Handle both development and production modes:

```typescript
export function getTesseractPath(): string {
  if (isDevelopment()) {
    // Use system installation
    return process.env.TESSERACT_PATH ||
           'C:\\Program Files\\Tesseract-OCR\\tesseract.exe';
  }

  // Use bundled version
  return path.join(process.resourcesPath, 'tesseract', 'tesseract.exe');
}
```

**Development benefits:**
- No need to copy binaries
- Uses already installed Tesseract
- Faster iteration

**Production benefits:**
- Self-contained application
- No installation dependencies
- Consistent behavior

### 5. Electron app.isPackaged

The best way to detect packaged vs development mode:

```typescript
import { app } from 'electron';

function isDevelopment(): boolean {
  return !app.isPackaged;
}
```

Alternatives:
- `process.env.NODE_ENV` - Requires build configuration
- Check for `.app` or `.exe` path - Platform specific
- Check for ASAR - Implementation detail

### 6. TESSDATA_PREFIX Environment Variable

Tesseract uses `TESSDATA_PREFIX` to find language data:

```typescript
// Set before calling Tesseract
process.env.TESSDATA_PREFIX = getTessdataPath();
```

In packaged app:
```javascript
const tessdata = path.join(process.resourcesPath, 'tesseract', 'tessdata');
```

### 7. Spanish Language Support

For Mexican invoices (CFDI), Spanish language is essential:

```
spa.traineddata  # Spanish
eng.traineddata  # English (fallback for product names)
osd.traineddata  # Script detection (rotation)
```

Using multiple languages:
```bash
tesseract image.png output -l spa+eng
```

### 8. File Size Considerations

Tesseract bundle adds significant size:

| Component | Size |
|-----------|------|
| tesseract.exe | ~15 MB |
| DLLs | ~10 MB |
| spa.traineddata (fast) | ~3 MB |
| eng.traineddata (fast) | ~4 MB |
| osd.traineddata | ~10 MB |
| **Total** | **~42 MB** |

Consider:
- Download language data on first run
- Exclude unused languages
- Compress in installer

### 9. PowerShell Download Script

Robust file download with PowerShell:

```powershell
function Download-File {
    param([string]$Url, [string]$OutFile)

    try {
        $ProgressPreference = 'SilentlyContinue'  # Speed up download
        Invoke-WebRequest -Uri $Url -OutFile $OutFile -UseBasicParsing
        return $true
    }
    catch {
        Write-Host "Failed: $Url"
        return $false
    }
}
```

**Tips:**
- `$ProgressPreference = 'SilentlyContinue'` speeds up large downloads
- `-UseBasicParsing` avoids IE dependency
- Error handling with try/catch

### 10. Availability Check

Always verify Tesseract availability before use:

```typescript
export function isTesseractAvailable(): boolean {
  const tesseractPath = getTesseractPath();
  const tessdataPath = getTessdataPath();

  // Check executable
  if (!fs.existsSync(tesseractPath)) return false;

  // Check language data
  const spaPath = path.join(tessdataPath, 'spa.traineddata');
  if (!fs.existsSync(spaPath)) return false;

  return true;
}
```

This allows graceful degradation if OCR is not available.

## Common Issues

### 1. "Cannot load language data"
- Check `TESSDATA_PREFIX` points to tessdata directory
- Verify `.traineddata` files exist

### 2. "tesseract.exe not found"
- Check path in development vs production
- Verify file was copied to resources

### 3. "Orientation wrong on rotated PDFs"
- Include `osd.traineddata`
- Use `--psm 1` for auto-orientation
