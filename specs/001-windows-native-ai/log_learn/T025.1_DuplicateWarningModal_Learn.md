# T025.1 - Duplicate Warning Modal Learnings

**Task**: Implement duplicate warning modal
**Date**: 2025-12-18

## Key Learnings

### 1. Tailwind CSS Modal Patterns

The modal uses a common Tailwind pattern for overlay + content:

```tsx
<div className="fixed inset-0 z-50 flex items-center justify-center">
  {/* Overlay - catches clicks */}
  <div className="absolute inset-0 bg-black bg-opacity-50" onClick={handleOverlay} />

  {/* Content - relative to overlay, stops propagation */}
  <div className="relative bg-white rounded-lg" onClick={e => e.stopPropagation()}>
    {/* Modal content */}
  </div>
</div>
```

Key points:
- `fixed inset-0` creates full-screen container
- `z-50` ensures modal is above other content
- Overlay uses `absolute inset-0` with semi-transparent background
- Content uses `relative` to position above overlay

### 2. Accessibility Requirements for Dialogs

Essential ARIA attributes for modal dialogs:
- `role="dialog"` - identifies element as dialog
- `aria-modal="true"` - indicates modal behavior (focus trap)
- `aria-labelledby={titleId}` - associates dialog with title

Also important:
- Escape key should close modal
- Focus should be trapped within modal
- Background content should not be interactive

### 3. Click Event Handling

To prevent modal from closing when clicking inside:

```tsx
const handleOverlayClick = (e: React.MouseEvent) => {
  // Only close if clicking the overlay itself, not children
  if (e.target === e.currentTarget && !isLoading) {
    onCancel();
  }
};

const handleContentClick = (e: React.MouseEvent) => {
  // Stop propagation to prevent overlay click handler
  e.stopPropagation();
};
```

### 4. Keyboard Event Handling

For modal escape key handling:

```tsx
useEffect(() => {
  if (isOpen) {
    const handleKeyDown = (event: KeyboardEvent) => {
      if (event.key === 'Escape' && !isLoading) {
        onCancel();
      }
    };
    document.addEventListener('keydown', handleKeyDown);
    return () => document.removeEventListener('keydown', handleKeyDown);
  }
}, [isOpen, onCancel, isLoading]);
```

The `useCallback` pattern is also valid but adds complexity.

### 5. Loading State Pattern

For buttons with loading state:

```tsx
<button disabled={isLoading} className="... disabled:opacity-50 disabled:cursor-not-allowed">
  {isLoading && <SpinnerSVG />}
  Button Text
</button>
```

Tailwind's `disabled:` variants handle styling automatically.

### 6. Spanish UI Best Practices

For Mexican accounting software:
- Use formal Spanish: "Usted" implied, not "tu"
- Technical terms: "póliza" (entry), "RFC" (tax ID), "folio" (document number)
- Button labels: "Continuar", "Cancelar" (standard Spanish)
- Clear, professional messaging
