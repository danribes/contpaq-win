# T029.1 - Inno Setup Learnings

**Task**: Create Inno Setup installer script
**Date**: 2025-12-18

## Key Learnings

### 1. Inno Setup Script Structure

Inno Setup uses sections defined with brackets:

```pascal
[Setup]
AppName=MyApp
AppVersion=1.0

[Files]
Source: "app.exe"; DestDir: "{app}"

[Icons]
Name: "{group}\MyApp"; Filename: "{app}\app.exe"
```

**Main sections:**
- `[Setup]` - Installer settings
- `[Files]` - Files to install
- `[Dirs]` - Directories to create
- `[Icons]` - Shortcuts to create
- `[Run]` - Post-install commands
- `[UninstallRun]` - Pre-uninstall commands
- `[Code]` - Pascal scripting

### 2. Preprocessor Definitions

Define constants for reuse:

```pascal
#define MyAppName "ContPAQ-Win"
#define MyAppVersion "0.1.0"

[Setup]
AppName={#MyAppName}
AppVersion={#MyAppVersion}
```

Benefits:
- Single source of truth
- Easy version updates
- Cleaner maintenance

### 3. Special Folder Constants

Inno Setup provides folder constants:

| Constant | Description |
|----------|-------------|
| `{app}` | Application install directory |
| `{autopf}` | Program Files (auto 32/64-bit) |
| `{autodesktop}` | Desktop folder |
| `{group}` | Start Menu folder |
| `{commonpf}` | Common Program Files |
| `{tmp}` | Temporary directory |
| `{userappdata}` | User AppData |

Use `{autopf}` for automatic 32/64-bit handling.

### 4. 64-bit Installation

Force 64-bit only installation:

```pascal
[Setup]
ArchitecturesAllowed=x64
ArchitecturesInstallIn64BitMode=x64
MinVersion=10.0
```

This ensures:
- Only runs on 64-bit Windows
- Installs to `Program Files` (not x86)
- Requires Windows 10 minimum

### 5. Spanish Language Support

Use built-in Spanish language file:

```pascal
[Languages]
Name: "spanish"; MessagesFile: "compiler:Languages\Spanish.isl"
```

The `compiler:` prefix refers to Inno Setup's installation directory.

Custom messages:
```pascal
[CustomMessages]
spanish.InstallServices=Instalando servicios...
```

### 6. Running PowerShell Scripts

Execute PowerShell with proper flags:

```pascal
[Run]
Filename: "powershell.exe"; \
Parameters: "-ExecutionPolicy Bypass -File ""{app}\scripts\install.ps1"""; \
Flags: runhidden waituntilterminated
```

**Key flags:**
- `-ExecutionPolicy Bypass` - Allow unsigned scripts
- `runhidden` - No console window
- `waituntilterminated` - Wait for completion

### 7. File Copying with Flags

Common file copy flags:

```pascal
[Files]
; Recurse into subdirectories
Source: "dist\*"; DestDir: "{app}"; Flags: recursesubdirs

; Create directories
Source: "data\*"; DestDir: "{app}\data"; Flags: createallsubdirs

; Ignore version comparison
Source: "config.ini"; DestDir: "{app}"; Flags: ignoreversion
```

### 8. Admin vs User Installation

Support both admin and user installs:

```pascal
[Setup]
PrivilegesRequired=admin
PrivilegesRequiredOverridesAllowed=dialog
```

For services, admin is required.

### 9. Uninstallation

Configure uninstall behavior:

```pascal
[Setup]
UninstallDisplayIcon={app}\MyApp.exe
UninstallDisplayName={#MyAppName}

[UninstallRun]
Filename: "powershell.exe"; \
Parameters: "-File ""{app}\uninstall-services.ps1"""; \
Flags: runhidden
```

### 10. Pascal Scripting

Add custom logic with Pascal:

```pascal
[Code]
function InitializeSetup(): Boolean;
begin
  Result := True;

  if not IsContPAQiInstalled() then
  begin
    if MsgBox('ContPAQi not found. Continue?',
              mbConfirmation, MB_YESNO) = IDNO then
      Result := False;
  end;
end;
```

**Common functions:**
- `InitializeSetup()` - Before installation
- `InitializeWizard()` - Customize wizard
- `CurStepChanged()` - Step completion hooks
- `DirExists()`, `FileExists()` - File checks
- `RegKeyExists()` - Registry checks

### 11. Compression Settings

LZMA2 provides best compression:

```pascal
[Setup]
Compression=lzma2/ultra64
SolidCompression=yes
LZMAUseSeparateProcess=yes
```

Trade-offs:
- `ultra64` - Best ratio, slow compile
- `max` - Good balance
- `fast` - Quick builds

### 12. Modern Wizard Style

Use modern appearance:

```pascal
[Setup]
WizardStyle=modern
WizardSizePercent=120
```

`WizardSizePercent=120` makes the wizard 20% larger
for better readability on high-DPI displays.

## Common Issues

### 1. File Not Found
- Check relative paths from .iss location
- Use `{src}` for source directory

### 2. Permission Denied
- Ensure admin privileges for services
- Check UAC elevation

### 3. Unicode Issues
- Save .iss file as UTF-8 with BOM
- Use `MessagesFile` for translations

## Build Process

```batch
:: Build installer
iscc contpaq-win.iss

:: Build with verbose output
iscc /V9 contpaq-win.iss

:: Output to specific directory
iscc /O"C:\output" contpaq-win.iss
```
