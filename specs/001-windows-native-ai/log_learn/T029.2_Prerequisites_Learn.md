# T029.2 - Prerequisites Learnings

**Task**: Add prerequisite detection and installation
**Date**: 2025-12-18

## Key Learnings

### 1. .NET Runtime Detection

Multiple methods to detect .NET:

```powershell
# Method 1: dotnet CLI
$runtimes = & dotnet --list-runtimes 2>$null
$desktopRuntime = $runtimes | Where-Object { $_ -match "Microsoft\.WindowsDesktop\.App 8\." }

# Method 2: Registry
$regPath = "HKLM:\SOFTWARE\dotnet\Setup\InstalledVersions\x64\sharedfx\Microsoft.WindowsDesktop.App"
$versions = Get-ChildItem $regPath | Where-Object { $_.PSChildName -like "8.*" }
```

### 2. VC++ Redistributable Detection

Visual C++ runtimes are cumulative (2015-2022):

```powershell
$regPath = "HKLM:\SOFTWARE\Microsoft\VisualStudio\14.0\VC\Runtimes\x64"
$installed = Get-ItemProperty -Path $regPath
if ($installed.Installed -eq 1) {
    # Version is cumulative: 14.x covers 2015-2022
}
```

### 3. Silent Installation Flags

Microsoft installers use consistent flags:

```powershell
# .NET and VC++ both use:
/install     # Install mode
/quiet       # No UI
/norestart   # Don't auto-restart

# Exit codes:
# 0    = Success
# 3010 = Success, restart required
```

### 4. Download with aka.ms

Microsoft uses aka.ms for stable download URLs:

| URL | Target |
|-----|--------|
| `aka.ms/dotnet/8.0/...` | Always points to latest 8.0.x |
| `aka.ms/vs/17/release/...` | Latest VS 2022 tools |

### 5. Administrator Check

Always verify admin rights for installations:

```powershell
$isAdmin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole(
    [Security.Principal.WindowsBuiltInRole]::Administrator
)
```

### 6. Inno Setup Pascal Integration

Call PowerShell from Inno Setup:

```pascal
[Run]
Filename: "powershell.exe"; \
Parameters: "-ExecutionPolicy Bypass -File ""{app}\scripts\install-prerequisites.ps1"""; \
Flags: runhidden waituntilterminated
```
