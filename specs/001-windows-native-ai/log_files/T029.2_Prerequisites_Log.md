## Detection Methods

### .NET 8.0 Desktop Runtime
1. `dotnet --list-runtimes` command
2. Registry: `HKLM:\SOFTWARE\dotnet\Setup\InstalledVersions\x64\sharedfx\Microsoft.WindowsDesktop.App`

### Visual C++ Redistributable
1. Registry: `HKLM:\SOFTWARE\Microsoft\VisualStudio\14.0\VC\Runtimes\x64`
2. File check: `%SystemRoot%\System32\vcruntime140.dll`

### ContPAQi Installation
1. Directory check: `C:\Program Files (x86)\Compac`
2. Registry: `HKLM:\SOFTWARE\Compac`
