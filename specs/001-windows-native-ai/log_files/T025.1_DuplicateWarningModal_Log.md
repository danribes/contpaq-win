## Component Interface

```typescript
export interface DuplicateWarningModalProps {
  isOpen: boolean;
  existingFolio: string;
  existingDate: string | null;
  vendorRfc: string;
  invoiceNumber: string;
  isLoading?: boolean;
  onContinue: (forceDuplicate: boolean) => void;
  onCancel: () => void;
}
```

## Key Features

1. **Visual Design**
   - Orange warning header with icon
   - Gray details section with existing entry info
   - Gray cancel button, orange continue button
   - Consistent with ContPAQ-Win design language

2. **User Experience**
   - Clear Spanish language copy
   - Keyboard accessible (Tab, Enter, Escape)
   - Click outside to close
   - Loading spinner on continue button

3. **Integration Points**
   - `onContinue(true)` signals user wants to force duplicate creation
   - `onCancel()` signals user wants to abort
   - Works with BridgeServiceClient for duplicate check
