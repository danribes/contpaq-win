## Vendor Resolution Flow

```
1. User clicks "Enviar a ContPAQi"
2. System calls getVendorByRfc(invoice.rfc)
3. If vendor not found:
   a. Show CreateVendorModal with RFC and suggested name
   b. User fills in vendor details
   c. System calls createVendor(data)
   d. Continue with entry creation
4. If vendor found: proceed to entry creation
```
