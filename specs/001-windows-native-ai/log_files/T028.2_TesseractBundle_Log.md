## Configuration Details

### Electron Builder extraResources
```json
{
  "from": "resources/tesseract",
  "to": "tesseract",
  "filter": [
    "**/*",
    "!**/doc/**",
    "!**/README*"
  ]
}
```

### Language Data (tessdata_fast)
| File | Language | Size |
|------|----------|------|
| spa.traineddata | Spanish | ~3 MB |
| eng.traineddata | English | ~4 MB |
| osd.traineddata | OSD | ~10 MB |

### Path Resolution

**Development Mode:**
1. `TESSERACT_PATH` environment variable
2. Default: `C:\Program Files\Tesseract-OCR\tesseract.exe`

**Packaged App:**
1. `{resourcesPath}/tesseract/tesseract.exe`
2. Fallback to system path

## Usage

### Download Language Data
```powershell
cd desktop-app\scripts
.\download-tesseract.ps1
```

### In Application Code
```typescript
import { getTesseractConfig, isTesseractAvailable } from './main/tesseract-config';

if (isTesseractAvailable()) {
  const config = getTesseractConfig();
  // config.binary = path to tesseract.exe
  // config.tessdata = path to tessdata directory
  // config.lang = "spa+eng"
}
```

## Notes

- Binary files (tesseract.exe, DLLs) must be copied manually
- Script downloads language data from GitHub (tessdata_fast)
- Spanish is primary language, English as fallback
- OSD data enables automatic orientation detection
