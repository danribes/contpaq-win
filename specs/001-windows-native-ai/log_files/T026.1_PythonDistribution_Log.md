## Build Process

1. **Check Prerequisites**: Python 3.11+, PyInstaller installed
2. **Download Models** (optional): LayoutLMv3 from HuggingFace
3. **Run PyInstaller**: `pyinstaller --clean --noconfirm ai-service.spec`
4. **Validate Build**: Check executable size (>100MB with PyTorch)

## Usage

```bash
# Development build (no models, faster)
python scripts/build.py --no-models --clean

# Production build (with models)
python scripts/build.py --clean

# Run the built service
cd dist/contpaq-ai-service
./contpaq-ai-service.exe
```

## Notes

- Build must run on Windows for Windows executable
- CPU-only PyTorch keeps size manageable (~500MB)
- Model weights add ~1GB if bundled
- Service runs on http://127.0.0.1:8000
