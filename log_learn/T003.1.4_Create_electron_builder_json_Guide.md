# Learning Guide: T003.1.4 - Electron Builder Configuration

## Overview

Electron Builder is a complete solution for packaging and building Electron applications. This guide covers configuration for Windows NSIS installers.

## Key Concepts

### What is Electron Builder?

Electron Builder:
- Packages Electron apps for distribution
- Creates installers (Windows, macOS, Linux)
- Handles code signing
- Manages auto-updates
- Bundles native dependencies

### Configuration File

electron-builder reads configuration from:
1. `electron-builder.json` (recommended)
2. `electron-builder.yml`
3. `package.json` under `build` key

## Configuration Structure

### Application Identity

```json
{
  "appId": "com.company.appname",
  "productName": "My Application",
  "copyright": "Copyright © 2024"
}
```

**appId**: Reverse domain notation identifier
- Used for Windows registry
- Used for macOS bundle identifier
- Must be unique across all apps

**productName**: Human-readable name
- Shown in installer
- Used for Start Menu folder
- Can contain spaces

### Directories

```json
{
  "directories": {
    "output": "release",
    "buildResources": "build"
  }
}
```

| Directory | Purpose |
|-----------|---------|
| output | Where installers are created |
| buildResources | Icons, license files, etc. |
| app | Alternative app location |

### Files Configuration

```json
{
  "files": [
    "dist/**/*",
    "package.json",
    "!**/*.map"
  ]
}
```

- Glob patterns for files to include
- `!` prefix excludes files
- `**/*` matches all files recursively

### ASAR Archive

```json
{
  "asar": true
}
```

**What is ASAR?**
- Archive format for Electron apps
- Bundles all files into single file
- Provides slight source code protection
- Faster file reading

**When to disable:**
- Native modules that need filesystem access
- Development/debugging

## Windows Configuration

### Target Configuration

```json
{
  "win": {
    "target": [
      {
        "target": "nsis",
        "arch": ["x64", "ia32"]
      }
    ]
  }
}
```

**Available targets:**
| Target | Description |
|--------|-------------|
| nsis | NSIS installer (most common) |
| nsis-web | NSIS web installer |
| portable | Portable executable |
| appx | Windows Store app |
| msi | MSI installer |
| squirrel | Squirrel.Windows |

### Architecture Options

- `x64`: 64-bit Windows
- `ia32`: 32-bit Windows
- `arm64`: ARM64 Windows

### Artifact Naming

```json
{
  "win": {
    "artifactName": "${productName}-${version}-Setup.${ext}"
  }
}
```

**Variables:**
- `${productName}` - Product name
- `${version}` - Package version
- `${arch}` - Architecture
- `${ext}` - File extension

## NSIS Configuration

### Basic Options

```json
{
  "nsis": {
    "oneClick": false,
    "perMachine": true,
    "allowElevation": true,
    "allowToChangeInstallationDirectory": true
  }
}
```

| Option | Default | Description |
|--------|---------|-------------|
| oneClick | true | No wizard, direct install |
| perMachine | false | Install for all users |
| allowElevation | true | Request admin rights |
| allowToChangeInstallationDirectory | false | User chooses path |

### Shortcut Options

```json
{
  "nsis": {
    "createDesktopShortcut": true,
    "createStartMenuShortcut": true,
    "shortcutName": "My App"
  }
}
```

### Localization

```json
{
  "nsis": {
    "language": "1034"
  }
}
```

**Common LCIDs:**
- 1033 - English (US)
- 1034 - Spanish (Spain)
- 2058 - Spanish (Mexico)
- 1031 - German
- 1036 - French

### Custom Installer UI

```json
{
  "nsis": {
    "installerIcon": "build/icon.ico",
    "uninstallerIcon": "build/icon.ico",
    "installerHeaderIcon": "build/icon.ico",
    "license": "LICENSE.txt"
  }
}
```

## Extra Resources

```json
{
  "extraResources": [
    {
      "from": "../backend",
      "to": "backend",
      "filter": ["**/*", "!**/tests/**"]
    }
  ]
}
```

**Use cases:**
- Bundling Python/Node services
- Including data files
- Adding documentation

**Accessed at runtime:**
```javascript
const path = require('path');
const resourcePath = process.resourcesPath;
// e.g., C:\Program Files\MyApp\resources\backend
```

## Build Commands

### package.json scripts

```json
{
  "scripts": {
    "build": "electron-builder",
    "build:win": "electron-builder --win",
    "build:dir": "electron-builder --dir"
  }
}
```

### CLI Options

```bash
# Build for current platform
npx electron-builder

# Build for Windows only
npx electron-builder --win

# Build unpacked directory (for testing)
npx electron-builder --dir

# Publish to configured provider
npx electron-builder --publish always
```

## Best Practices

### 1. Use Schema for Validation

```json
{
  "$schema": "https://raw.githubusercontent.com/electron-userland/electron-builder/master/packages/app-builder-lib/scheme.json"
}
```

IDE provides autocomplete and validation.

### 2. Separate Build Resources

Keep icons and certificates in `build/` directory:
```
desktop-app/
├── build/
│   ├── icon.ico
│   ├── icon.png
│   └── background.png
├── src/
└── electron-builder.json
```

### 3. Exclude Unnecessary Files

```json
{
  "files": [
    "dist/**/*",
    "!**/node_modules/*/{CHANGELOG.md,README.md}",
    "!**/*.{ts,map}"
  ]
}
```

### 4. Use Maximum Compression

```json
{
  "compression": "maximum"
}
```

Reduces installer size significantly.

### 5. Configure for Enterprise

For enterprise deployment:
- `perMachine: true` - System-wide install
- `oneClick: false` - Show options
- Custom install path option
- Silent install support

## Troubleshooting

### Icon Not Showing
- Icon must be at least 256x256 pixels
- Must be `.ico` format for Windows
- Check path in `win.icon`

### Build Fails on Native Modules
- Set `asar: false` or use `asarUnpack`
- Rebuild native modules for Electron version

### Installer Too Large
- Use `compression: "maximum"`
- Exclude source maps and test files
- Check `extraResources` filters
