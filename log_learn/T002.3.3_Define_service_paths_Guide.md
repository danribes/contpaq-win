# Learning Guide: T002.3.3 - External Service Path Configuration

## What are Service Paths?

Service paths are configuration settings that point to external dependencies:
- **Executables**: Programs the application calls (e.g., Tesseract)
- **Models**: AI/ML model files (e.g., LayoutLMv3)
- **Data directories**: Where to find/store data

## TESSERACT_PATH Setting

### What is Tesseract?

Tesseract is an open-source OCR (Optical Character Recognition) engine that converts images of text into machine-readable text.

```
┌──────────────┐      ┌─────────────┐      ┌──────────────┐
│ Scanned PDF  │ ───► │  Tesseract  │ ───► │ Extracted    │
│ (Image)      │      │  OCR Engine │      │ Text         │
└──────────────┘      └─────────────┘      └──────────────┘
```

### Why Configure the Path?

Tesseract is installed separately from our application:

**Windows** (our target):
```
C:\Program Files\Tesseract-OCR\tesseract.exe
```

**Linux**:
```
/usr/bin/tesseract
```

**Mac (Homebrew)**:
```
/usr/local/bin/tesseract
```

### Using TESSERACT_PATH

```python
import subprocess
from src.config import settings

def run_ocr(image_path: str) -> str:
    result = subprocess.run(
        [settings.TESSERACT_PATH, image_path, "stdout", "-l", "spa"],
        capture_output=True,
        text=True
    )
    return result.stdout
```

### Verifying Tesseract Installation

```python
import os
from src.config import settings

def check_tesseract() -> bool:
    """Check if Tesseract is available."""
    path = settings.TESSERACT_PATH
    if os.path.isfile(path):
        return os.access(path, os.X_OK)  # Check if executable
    return False
```

## MODEL_PATH Setting

### What is LayoutLMv3?

LayoutLMv3 is a document understanding model that:
- Understands both text AND layout
- Can identify fields like "Invoice Number", "Total", etc.
- Uses position information to improve extraction

### Model Directory Structure

```
models/
└── layoutlm/
    ├── config.json          # Model configuration
    ├── pytorch_model.bin    # Model weights (~400MB)
    ├── tokenizer.json       # Tokenizer
    └── vocab.txt            # Vocabulary
```

### Why a Relative Path?

Using `./models/layoutlm` (relative) instead of absolute:

**Pros**:
- Works when code moves to different directories
- Easy for development (no machine-specific paths)
- Bundled with the application

**Cons**:
- Depends on working directory
- May need adjustment for production deployment

### Using MODEL_PATH

```python
from transformers import AutoModel, AutoTokenizer
from src.config import settings

def load_model():
    """Load the LayoutLMv3 model."""
    model = AutoModel.from_pretrained(settings.MODEL_PATH)
    tokenizer = AutoTokenizer.from_pretrained(settings.MODEL_PATH)
    return model, tokenizer
```

## Path Configuration Patterns

### Absolute vs Relative Paths

```python
# Absolute - machine-specific
TESSERACT_PATH: str = "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"

# Relative - portable but depends on working directory
MODEL_PATH: str = "./models/layoutlm"
```

### Environment-Based Defaults

```python
import os

class Settings(BaseSettings):
    # Use environment or default
    TESSERACT_PATH: str = os.getenv(
        "TESSERACT_PATH",
        "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"
    )
```

### Platform-Aware Defaults

```python
import platform

def get_default_tesseract_path() -> str:
    if platform.system() == "Windows":
        return "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"
    elif platform.system() == "Darwin":  # Mac
        return "/usr/local/bin/tesseract"
    else:  # Linux
        return "/usr/bin/tesseract"
```

## Path Validation

### At Startup

```python
from pathlib import Path
from src.config import settings

def validate_paths():
    """Validate all service paths exist."""
    errors = []

    # Check Tesseract
    if not Path(settings.TESSERACT_PATH).exists():
        errors.append(f"Tesseract not found at: {settings.TESSERACT_PATH}")

    # Check model
    model_path = Path(settings.MODEL_PATH)
    if not model_path.exists():
        errors.append(f"Model not found at: {settings.MODEL_PATH}")
    elif not (model_path / "config.json").exists():
        errors.append(f"Invalid model directory: missing config.json")

    if errors:
        raise ConfigurationError("\n".join(errors))
```

### In Health Check

```python
@app.get("/health")
def health_check():
    return {
        "status": "healthy",
        "tesseract_available": Path(settings.TESSERACT_PATH).exists(),
        "model_loaded": Path(settings.MODEL_PATH).exists(),
    }
```

## Windows Path Escaping

### In Python Strings

```python
# Raw string (recommended for Windows paths)
path = r"C:\Program Files\Tesseract-OCR\tesseract.exe"

# Escaped backslashes
path = "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"

# Forward slashes (works on Windows too!)
path = "C:/Program Files/Tesseract-OCR/tesseract.exe"
```

### In .env File

```env
# No escaping needed in .env files
TESSERACT_PATH=C:\Program Files\Tesseract-OCR\tesseract.exe
```

### Using pathlib (Cross-Platform)

```python
from pathlib import Path

# Works on any platform
tesseract = Path(settings.TESSERACT_PATH)
model = Path(settings.MODEL_PATH)

# Check existence
if tesseract.exists() and tesseract.is_file():
    print("Tesseract found!")
```

## Installer Considerations

For the ContPAQ-Win installer (T029), these paths will be:

1. **Bundled Tesseract**: Installed to known location
2. **Bundled Models**: Installed to application directory
3. **Auto-configured**: Settings point to installed locations

```
C:\Program Files\ContPAQ-Win\
├── ContPAQ-Win.exe
├── ai-service\
│   └── models\
│       └── layoutlm\
└── Tesseract-OCR\
    └── tesseract.exe
```
