# Learning Guide: T003.3.3 - Create desktop-app/src/renderer/App.tsx

## Overview

This guide covers creating the main App component with React Router setup for an Electron application, including layout structure and Tailwind CSS styling.

## Concepts Covered

### 1. React Router in Electron

Electron apps need special routing considerations:

```typescript
// DON'T use BrowserRouter in Electron
import { BrowserRouter } from 'react-router-dom';  // ❌

// DO use HashRouter for Electron
import { HashRouter } from 'react-router-dom';     // ✅
```

**Why HashRouter?**
- Electron loads files via `file://` protocol
- BrowserRouter needs a web server
- HashRouter uses URL fragments (`#/path`)
- Works with static HTML files

### 2. Route Configuration

Define routes with React Router v6:

```typescript
import { Routes, Route } from 'react-router-dom';

<Routes>
  <Route path="/" element={<HomePage />} />
  <Route path="/processing" element={<ProcessingPage />} />
  <Route path="/settings" element={<SettingsPage />} />
  <Route path="*" element={<NotFoundPage />} />  {/* Catch-all */}
</Routes>
```

Route v6 changes from v5:
- `element` prop instead of `component`
- `Routes` instead of `Switch`
- No need for `exact` prop

### 3. Application Layout Pattern

Create a consistent layout structure:

```typescript
function App() {
  return (
    <HashRouter>
      <div className="flex flex-col min-h-screen">
        {/* Header - fixed at top */}
        <header className="...">
          <nav>...</nav>
        </header>

        {/* Main - expands to fill space */}
        <main className="flex-1">
          <Routes>...</Routes>
        </main>

        {/* Footer - fixed at bottom */}
        <footer className="...">
          <StatusBar />
        </footer>
      </div>
    </HashRouter>
  );
}
```

### 4. Tailwind Layout Classes

Key Tailwind classes for full-height layouts:

```css
/* Container */
.flex          /* Enable flexbox */
.flex-col      /* Stack children vertically */
.min-h-screen  /* Minimum height = viewport */

/* Main content */
.flex-1        /* Grow to fill available space */

/* Centering */
.max-w-7xl     /* Maximum width */
.mx-auto       /* Center horizontally */
```

### 5. Status Indicators

Create visual status indicators:

```typescript
<span className="flex items-center">
  <span className="w-2 h-2 bg-yellow-400 rounded-full mr-2" />
  AI Service: Iniciando...
</span>
```

Color meanings:
- `bg-green-500` - Running/healthy
- `bg-yellow-400` - Starting/warning
- `bg-red-500` - Error/stopped

## Code Example

### Complete App Component

```typescript
import React from 'react';
import { HashRouter, Routes, Route } from 'react-router-dom';

// Page components
const HomePage: React.FC = () => (
  <div className="flex flex-col items-center justify-center min-h-[60vh]">
    <h1 className="text-3xl font-bold text-gray-800 mb-4">
      ContPAQ Win
    </h1>
    <p className="text-gray-600">
      Sistema de gestión de facturas
    </p>
  </div>
);

// Main App component
function App(): JSX.Element {
  return (
    <HashRouter>
      <div className="flex flex-col min-h-screen bg-gray-50">
        {/* Header */}
        <header className="bg-white border-b border-gray-200 px-4 py-3">
          <nav className="flex items-center justify-between max-w-7xl mx-auto">
            <h1 className="text-xl font-semibold text-primary-600">
              ContPAQ Win
            </h1>
          </nav>
        </header>

        {/* Main Content */}
        <main className="flex-1 p-4">
          <div className="max-w-7xl mx-auto">
            <Routes>
              <Route path="/" element={<HomePage />} />
              <Route path="*" element={<NotFoundPage />} />
            </Routes>
          </div>
        </main>

        {/* Status Bar */}
        <footer className="bg-white border-t border-gray-200 px-4 py-2">
          <div className="text-sm text-gray-500">
            v0.1.0
          </div>
        </footer>
      </div>
    </HashRouter>
  );
}

export default App;
```

## Best Practices

### 1. Keep App Component Clean

Move page components to separate files:

```
src/renderer/
├── App.tsx           # Router and layout only
├── pages/
│   ├── HomePage.tsx
│   ├── ProcessingPage.tsx
│   └── SettingsPage.tsx
└── components/
    ├── Header.tsx
    └── StatusBar.tsx
```

### 2. Use Lazy Loading for Routes

Improve performance with code splitting:

```typescript
import { lazy, Suspense } from 'react';

const ProcessingPage = lazy(() => import('./pages/ProcessingPage'));

<Route
  path="/processing"
  element={
    <Suspense fallback={<Loading />}>
      <ProcessingPage />
    </Suspense>
  }
/>
```

### 3. Type Safety with TypeScript

Define proper types:

```typescript
// Type for App component
function App(): JSX.Element { ... }

// Type for page components
const HomePage: React.FC = () => { ... }

// Type for page components with props
interface PageProps {
  title: string;
}
const Page: React.FC<PageProps> = ({ title }) => { ... }
```

### 4. Consistent Styling

Use Tailwind's design system:

```typescript
// Define reusable class patterns
const containerClasses = "max-w-7xl mx-auto px-4";
const headingClasses = "text-2xl font-bold text-gray-800";

// Apply consistently
<div className={containerClasses}>
  <h1 className={headingClasses}>Title</h1>
</div>
```

## Router Types Comparison

| Router | Use Case | URL Format |
|--------|----------|------------|
| BrowserRouter | Web apps with server | `/processing` |
| HashRouter | Electron, static sites | `#/processing` |
| MemoryRouter | Testing, mobile | No URL |

## Common Issues

### Issue: Blank Page in Electron
**Cause**: Using BrowserRouter with file:// protocol
**Solution**: Use HashRouter instead

### Issue: Routes Not Matching
**Cause**: Missing catch-all route
**Solution**: Add `<Route path="*" element={<NotFound />} />`

### Issue: Layout Not Full Height
**Cause**: Missing min-h-screen on container
**Solution**: Add `className="min-h-screen"` to root div

### Issue: Content Not Centered
**Cause**: Missing max-width and margin auto
**Solution**: Add `className="max-w-7xl mx-auto"`
