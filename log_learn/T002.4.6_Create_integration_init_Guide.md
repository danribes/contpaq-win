# Learning Guide: T002.4.6 - Integration Tests Organization

## Integration Tests Overview

Integration tests verify that multiple components work together correctly.

### Key Differences from Unit Tests

| Aspect | Unit Tests | Integration Tests |
|--------|------------|-------------------|
| Scope | Single function/class | Multiple components |
| Dependencies | Mocked | Real (or realistic) |
| Speed | Fast (ms) | Slower (seconds) |
| Isolation | Complete | Partial |
| Fixtures | Simple data | Files, databases |

## Integration Test Structure

```
ai-service/tests/
├── conftest.py          # Shared fixtures
├── fixtures/            # Test data files
├── unit/                # Unit tests
└── integration/         # Integration tests
    ├── __init__.py
    ├── test_api.py              # API endpoint tests
    ├── test_extraction_pipeline.py  # Full workflow
    └── test_health_check.py     # Service health
```

## FastAPI Integration Testing

### Using TestClient

```python
from fastapi.testclient import TestClient
from src.main import app

client = TestClient(app)

def test_health_endpoint():
    response = client.get("/health")
    assert response.status_code == 200
    data = response.json()
    assert data["status"] == "healthy"
```

### File Upload Testing

```python
def test_extract_endpoint(sample_pdf_path):
    with open(sample_pdf_path, "rb") as f:
        response = client.post(
            "/extract",
            files={"file": ("invoice.pdf", f, "application/pdf")}
        )
    assert response.status_code == 200
    data = response.json()
    assert "vendor_rfc" in data
```

## Pytest Markers for Integration Tests

### Mark Slow Tests

```python
import pytest

@pytest.mark.slow
def test_full_extraction_pipeline():
    # Takes >5 seconds
    pass

# Run without slow tests
# pytest -m "not slow"
```

### Mark Tests with Requirements

```python
@pytest.mark.requires_tesseract
def test_ocr_extraction():
    # Requires Tesseract installed
    pass

@pytest.mark.requires_model
def test_ai_extraction():
    # Requires LayoutLMv3 model loaded
    pass
```

### Skip Based on Environment

```python
import pytest
import shutil

@pytest.mark.skipif(
    shutil.which("tesseract") is None,
    reason="Tesseract not installed"
)
def test_ocr_functionality():
    pass
```

## Testing Full Pipelines

### Extraction Pipeline Test

```python
def test_extraction_pipeline(sample_pdf_path):
    # 1. Upload PDF
    # 2. Detect PDF type
    # 3. Extract text (or OCR)
    # 4. Run AI extraction
    # 5. Validate results

    result = extract_invoice(sample_pdf_path)

    assert result.vendor_rfc is not None
    assert result.total > 0
    assert 0 <= result.confidence <= 1
```

### Testing with Database

```python
@pytest.fixture
def test_db():
    """Create test database."""
    db = create_test_database()
    yield db
    db.cleanup()

def test_invoice_storage(test_db, extracted_invoice):
    # Save to database
    invoice_id = test_db.save_invoice(extracted_invoice)

    # Retrieve and verify
    loaded = test_db.get_invoice(invoice_id)
    assert loaded.vendor_rfc == extracted_invoice.vendor_rfc
```

## Running Integration Tests

### All Integration Tests

```bash
pytest ai-service/tests/integration/ -v
```

```bash
pytest ai-service/tests/integration/ -v -m "not slow"
```

```bash

```

## Best Practices

### 1. Test Real Scenarios

```python
def test_user_workflow():
    """Test complete user workflow."""
    # 1. User uploads PDF
    # 2. System extracts data
    # 3. User reviews and edits
    # 4. System validates
    # 5. User approves
    pass
```

### 2. Clean Up Resources

```python
@pytest.fixture
def uploaded_file(client, sample_pdf_path):
    """Upload file and clean up after test."""
    with open(sample_pdf_path, "rb") as f:
        response = client.post("/upload", files={"file": f})
    file_id = response.json()["id"]

    yield file_id

    # Cleanup
    client.delete(f"/files/{file_id}")
```

### 3. Isolate Test Data

```python
def test_extraction_does_not_affect_other_tests(sample_pdf_path):
    # Each test gets fresh data
    # No side effects from other tests
    pass
```
