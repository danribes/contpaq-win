# Learning Guide: T002.2.2 - Python Subpackages and Data Models

## What are Subpackages?

A subpackage is a package nested inside another package. Just like the main package, subpackages need their own `__init__.py` file.

```
src/                    # Main package
├── __init__.py
└── models/             # Subpackage
    └── __init__.py
```

## Why Create a models/ Subpackage?

### Separation of Concerns

Instead of putting everything in one place:
```python
# Bad: Everything in one file
# src/everything.py
class Invoice: ...
class ProcessingService: ...
def api_route(): ...
```

We organize by purpose:
```python
# Good: Organized by responsibility
# src/models/invoice.py - Data structures
# src/services/processor.py - Business logic
# src/api/routes.py - HTTP endpoints
```

### Benefits

1. **Findability**: Know where to look for data structures
2. **Testing**: Test data models independently
3. **Maintenance**: Change models without affecting services
4. **Documentation**: Package docstring describes what's inside

## Data Models in Python

### What is a Data Model?

A data model is a class that represents structured data. In Python, we use:

- **dataclasses**: Built-in, simple data containers
- **Pydantic**: Validation, serialization, FastAPI integration

### dataclasses (Built-in)

```python
from dataclasses import dataclass

@dataclass
class Invoice:
    vendor_rfc: str
    total: float
    invoice_number: str
```

### Pydantic (Our Choice)

```python
from pydantic import BaseModel, Field

class Invoice(BaseModel):
    vendor_rfc: str = Field(..., pattern=r"^[A-Z]{3,4}[0-9]{6}")
    total: float = Field(..., ge=0)
    invoice_number: str
```

## Why Pydantic?

### 1. Automatic Validation

```python
from pydantic import BaseModel

class BoundingBox(BaseModel):
    x: float
    y: float
    width: float
    height: float

# Valid
box = BoundingBox(x=10, y=20, width=100, height=50)

# Invalid - raises ValidationError
box = BoundingBox(x="not a number", y=20, width=100, height=50)
```

### 2. JSON Serialization

```python
# To JSON
box.model_dump_json()
# '{"x": 10, "y": 20, "width": 100, "height": 50}'

# From JSON
box = BoundingBox.model_validate_json('{"x": 10, "y": 20, "width": 100, "height": 50}')
```

### 3. FastAPI Integration

```python
from fastapi import FastAPI
from pydantic import BaseModel

class ExtractionResponse(BaseModel):
    vendor_rfc: str
    confidence: float

app = FastAPI()

@app.post("/extract")
def extract(file: bytes) -> ExtractionResponse:
    # FastAPI automatically:
    # - Validates response matches ExtractionResponse
    # - Generates OpenAPI schema
    # - Converts to JSON
    return ExtractionResponse(vendor_rfc="ABC123456789", confidence=0.95)
```

## Package __init__.py Patterns

### Empty (Current State)
```python
# src/models/__init__.py
"""Models package docstring"""
__all__ = []
```

Submodules imported explicitly:
```python
from src.models.extraction import Invoice
```

### Re-exports (Future State)
```python
# src/models/__init__.py
from .extraction import BoundingBox, ExtractionField, InvoiceExtraction
from .validation import RFCValidationRequest

__all__ = ["BoundingBox", "ExtractionField", "InvoiceExtraction", "RFCValidationRequest"]
```

Convenience imports:
```python
from src.models import Invoice  # Works!
```

## Why __all__ = []?

### Current Situation
No submodules exist yet:
```
src/models/
└── __init__.py    # That's it!
```

`__all__ = []` says "nothing to export yet".

### Future Situation
After T013.1:
```
src/models/
├── __init__.py
├── extraction.py
└── validation.py
```

```python
# src/models/__init__.py
from .extraction import BoundingBox, InvoiceExtraction
__all__ = ["BoundingBox", "InvoiceExtraction"]
```

## Testing Data Models

### Test Model Creation
```python
def test_bounding_box_creation():
    box = BoundingBox(x=10, y=20, width=100, height=50, page=1)
    assert box.x == 10
    assert box.page == 1
```

### Test Validation
```python
def test_bounding_box_rejects_invalid():
    with pytest.raises(ValidationError):
        BoundingBox(x="not a number", ...)
```

### Test Serialization
```python
def test_bounding_box_to_json():
    box = BoundingBox(x=10, y=20, width=100, height=50, page=1)
    data = box.model_dump()
    assert data["x"] == 10
```

## Project Organization Pattern

```
ai-service/
└── src/
    ├── __init__.py         # Package root
    ├── models/             # Data structures
    │   ├── __init__.py
    │   ├── extraction.py   # AI extraction models
    │   └── validation.py   # Validation models
    ├── services/           # Business logic
    │   ├── __init__.py
    │   ├── pdf_extractor.py
    │   └── ai_extractor.py
    ├── api/                # HTTP endpoints
    │   ├── __init__.py
    │   └── routes.py
    └── utils/              # Helpers
        ├── __init__.py
        └── config.py
```
