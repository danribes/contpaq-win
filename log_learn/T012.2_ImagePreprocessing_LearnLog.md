## Key Learnings

### 1. PIL/Pillow Image Enhancement
PIL provides built-in enhancement classes:

```python
from PIL import ImageEnhance

# Contrast enhancement
enhancer = ImageEnhance.Contrast(image)
enhanced = enhancer.enhance(1.5)  # 50% more contrast

# Other enhancers available:
# ImageEnhance.Brightness(image).enhance(factor)
# ImageEnhance.Sharpness(image).enhance(factor)

```

### 2. PIL Image Filters
Built-in filters for noise reduction:

```python
from PIL import ImageFilter

# Median filter (good for salt-and-pepper noise)
denoised = image.filter(ImageFilter.MedianFilter(size=3))

# Gaussian blur (general smoothing)
blurred = image.filter(ImageFilter.GaussianBlur(radius=2))

# Sharpening
sharpened = image.filter(ImageFilter.SHARPEN)
```

### 3. Image Rotation with PIL
Rotating images while handling background:

```python
# Simple rotation (may crop corners)
rotated = image.rotate(angle)

# Rotation with expansion (no cropping)
rotated = image.rotate(
    angle,
    resample=Image.Resampling.BICUBIC,  # Quality interpolation
    expand=True,                         # Expand canvas to fit
    fillcolor=(255, 255, 255)           # White background
)
```

### 5. Skew Detection Concepts

2. **Projection Profile**: Find angle that maximizes variance

### 6. Median Filter for OCR
Why median filter is good for OCR:
- Removes salt-and-pepper noise
- Preserves edges better than mean filter
- Works well with text boundaries
- Fast computation

```python
# Odd sizes only: 3, 5, 7, etc.
from PIL import ImageFilter

# Light noise reduction
light = image.filter(ImageFilter.MedianFilter(size=3))

# Stronger noise reduction (may blur text)
strong = image.filter(ImageFilter.MedianFilter(size=5))
```

### 7. Preprocessing Pipeline Design
Order matters for preprocessing:

1. **Deskew first**: Rotation before other operations
2. **Contrast second**: Improve text visibility
3. **Noise reduction last**: Don't blur before contrast

```python
def preprocess(image):
    # 1. Fix rotation
    result = deskew(image)

    # 2. Enhance contrast
    result = enhance_contrast(result, factor=1.5)

    # 3. Remove noise
    result = reduce_noise(result, strength=3)

    return result
```

### 8. Testing Image Processing
Strategies for testing image transformations:

```python
# Check output type
assert isinstance(result, Image.Image)

# Check dimensions preserved
assert result.size == original.size

# Check mode preserved
assert result.mode == original.mode

# Check transformation effect (using NumPy)
original_arr = np.array(original)
result_arr = np.array(result)

# For noise reduction: std should decrease
assert np.std(result_arr) <= np.std(original_arr)

# For contrast: range should increase
assert (result_arr.max() - result_arr.min()) >= (original_arr.max() - original_arr.min())
```
