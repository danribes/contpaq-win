## Key Learnings

### 1. Pydantic V2 Basics
Pydantic V2 has significant changes from V1:

```python
from pydantic import BaseModel, Field

class MyModel(BaseModel):
    # Field with constraints
    name: str = Field(..., min_length=1, description="User name")
    age: int = Field(..., ge=0, le=150)
    score: float = Field(default=0.0, ge=0.0, le=1.0)
```

### 2. Field Validators in Pydantic V2
Cross-field validation:

```python
from pydantic import field_validator

class BoundingBox(BaseModel):
    x0: float
    x1: float

    @field_validator('x1')
    @classmethod
    def x1_greater_than_x0(cls, v: float, info) -> float:
        """Access other field values via info.data"""
        if 'x0' in info.data and v < info.data['x0']:
            raise ValueError('x1 must be >= x0')
        return v
```

### 3. Properties in Pydantic Models
Adding computed properties:

```python
class BoundingBox(BaseModel):
    x0: float
    y0: float
    x1: float
    y1: float

    @property
    def width(self) -> float:
        return self.x1 - self.x0

    @property
    def area(self) -> float:
        return self.width * self.height
```

Note: Properties are not included in `model_dump()` by default.

### 4. Optional Fields
Using Optional for nullable fields:

```python
from typing import Optional

class ExtractionField(BaseModel):
    value: str  # Required
    bbox: Optional[BoundingBox] = None  # Optional with default
    raw_text: Optional[str] = Field(default=None)  # Also optional
```

### 5. Decimal for Currency
Using Decimal for precise monetary values:

```python
from decimal import Decimal
from pydantic import field_validator

class LineItem(BaseModel):
    amount: Decimal

    @field_validator('amount', mode='before')
    @classmethod
    def convert_to_decimal(cls, v):
        """Handle float, int, and string inputs"""
        if isinstance(v, (int, float, str)):
            return Decimal(str(v))
        return v
```

### 6. Pattern Validation
Restricting string values with regex:

```python
class InvoiceExtraction(BaseModel):
    source_type: str = Field(
        ...,
        pattern="^(text|scanned)$",
        description="Must be 'text' or 'scanned'"
    )
```

### 7. Model Serialization
Converting to dict/JSON:

```python
model = MyModel(name="test", value=123)

# To dict
data = model.model_dump()

# To JSON string
json_str = model.model_dump_json()

# Exclude None values
data = model.model_dump(exclude_none=True)

# Only specific fields
data = model.model_dump(include={"name", "value"})
```

### 8. Nested Models
Models can contain other models:

```python
class InvoiceExtraction(BaseModel):
    vendor_rfc: Optional[ExtractionField] = None
    line_items: List[LineItemExtraction] = Field(default_factory=list)
```

### 9. Testing Validation Errors
Using pytest to test validation:

```python
import pytest
from pydantic import ValidationError

def test_rejects_invalid_value():
    with pytest.raises(ValidationError):
        MyModel(invalid_field="value")

def test_rejects_out_of_range():
    with pytest.raises(ValidationError):
        MyModel(confidence=1.5)  # Max is 1.0
```

### 10. Floating Point Comparison in Tests
Use pytest.approx for float comparisons:

```python
import pytest

def test_float_calculation():
    result = calculate_average()
    assert result == pytest.approx(0.85)  # Handles precision
```
