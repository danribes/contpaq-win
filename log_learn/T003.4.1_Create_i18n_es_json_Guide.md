# Learning Guide: T003.4.1 - Create desktop-app/src/renderer/i18n/es.json

## Overview

This guide covers creating internationalization (i18n) resource files for a React application, specifically for Spanish language support.

## Concepts Covered

### 1. i18n JSON Structure

Organize translations hierarchically by feature:

```json
{
  "app": { "name": "...", "description": "..." },
  "buttons": { "save": "...", "cancel": "..." },
  "errors": { "generic": "...", "network": "..." }
}
```

Benefits:
- Easy to find and update strings
- Clear ownership by feature
- Prevents key collisions

### 2. Key Naming Conventions

Use consistent naming:

```json
{
  "invoice": {
    "title": "Factura",           // Section title
    "number": "Número de Factura", // Field label
    "notFound": "Factura no encontrada" // Message
  }
}
```

Patterns:
- `title` - Section/page titles
- `label` - Form field labels
- `placeholder` - Input placeholders
- `message` - Informational text
- `error` - Error messages

### 3. Spanish Localization

#### Formal vs Informal

Use formal "usted" for professional apps:

```json
{
  "dialogs": {
    "confirm": "¿Está seguro?",     // ✅ Formal
    "confirm": "¿Estás seguro?"     // ❌ Informal
  }
}
```

#### Mexican Spanish Terminology

Use terms common in Mexico:

| English | Mexican Spanish | Other Spanish |
|---------|----------------|---------------|
| Invoice | Factura | Factura |
| Tax ID | RFC | NIF (Spain) |
| VAT | IVA | IVA |
| Provider | Proveedor | Proveedor |

### 4. Error Messages

Make errors actionable:

```json
{
  "errors": {
    "networkError": "Error de conexión. Verifique su conexión a internet.",
    "invalidPdf": "El archivo no es un PDF válido. Por favor seleccione un archivo PDF.",
    "serviceUnavailable": "Servicio no disponible. Intente nuevamente en unos momentos."
  }
}
```

Good error messages:
- Explain what happened
- Suggest how to fix it
- Are not technical jargon

### 5. Pluralization (Advanced)

For strings that change with quantity:

```json
{
  "invoice": {
    "count_one": "{{count}} factura",
    "count_other": "{{count}} facturas"
  }
}
```

Or use functions in the provider:

```typescript
function pluralize(count: number, singular: string, plural: string) {
  return count === 1 ? singular : plural;
}
```

### Using with React (Preview)

```typescript
// hooks/useTranslation.ts
import es from '../i18n/es.json';

type TranslationKeys = keyof typeof es;

export function useTranslation() {
  const t = (key: string): string => {
    const keys = key.split('.');
    let value: any = es;

    for (const k of keys) {
      value = value?.[k];
    }

    return value || key;
  };

  return { t };
}

// Usage in component
function MyComponent() {
  const { t } = useTranslation();

  return (
    <button>{t('buttons.save')}</button>  // "Guardar"
  );
}
```

## Best Practices

### 1. Avoid Concatenation

```json
// ❌ Bad - requires concatenation
{
  "greeting": "Hola",
  "name": "usuario"
}
// Usage: t('greeting') + ' ' + t('name')

// ✅ Good - complete phrase
{
  "greeting": "Hola, {{name}}"
}
// Usage: t('greeting', { name: 'Juan' })
```

### 2. Include Context

```json
{
  "buttons": {
    "close": "Cerrar",           // Generic
    "closeModal": "Cerrar ventana", // Specific context
    "closeSession": "Cerrar sesión" // Different meaning
  }
}
```

### 3. Use Sections for Related Strings

```json
{
  "invoice": {
    "title": "Factura",
    "fields": {
      "number": "Número",
      "date": "Fecha",
      "total": "Total"
    },
    "actions": {
      "create": "Crear factura",
      "delete": "Eliminar factura"
    }
  }
}
```

### 4. Document Special Cases

```json
{
  // Note: Use this only for RFC validation errors
  "validation": {
    "rfcFormat": "El RFC debe tener 12 o 13 caracteres"
  }
}
```

## Common Issues

### Issue: Missing Accent Marks
**Cause**: Encoding issues or typos
**Solution**: Use UTF-8 encoding, verify accents: á, é, í, ó, ú, ñ, ü

### Issue: Inconsistent Terminology
**Cause**: Multiple translators or copy-paste
**Solution**: Create a glossary and stick to it

### Issue: Hardcoded Strings in Code
**Cause**: Quick fixes bypassing i18n
**Solution**: Search code for Spanish text and move to JSON

## Summary

Creating an i18n file involves:
1. ✅ Organize strings by feature/section
2. ✅ Use consistent key naming
3. ✅ Write in formal Spanish (usted)
4. ✅ Use Mexican Spanish terminology
5. ✅ Make error messages helpful
6. ✅ Include all UI text
