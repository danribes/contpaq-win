# T006.2.5 Learning Guide: Graceful Shutdown in FastAPI

## Overview

This guide explains how to implement graceful startup and shutdown handlers in FastAPI applications using the modern lifespan context manager pattern.

## What is Graceful Shutdown?

Graceful shutdown ensures that when an application stops, it:
- Completes in-progress requests
- Closes database connections properly
- Releases file handles
- Unloads resources from memory
- Logs shutdown events

## Key Concepts

### 1. Lifespan Context Manager (Modern)

FastAPI 0.93+ uses the lifespan pattern:

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup code
    print("Starting up...")
    yield
    # Shutdown code
    print("Shutting down...")

app = FastAPI(lifespan=lifespan)
```

### 2. Deprecated: on_event Decorators

The old pattern (still works but deprecated):

```python
app = FastAPI()

@app.on_event("startup")
async def startup():
    print("Starting...")

@app.on_event("shutdown")
async def shutdown():
    print("Stopping...")
```

### 3. Why Lifespan is Better

| Feature | on_event | lifespan |
|---------|----------|----------|
| Resource sharing | Global variables | Yield context |
| Testing | Harder to mock | Easy to test |
| Error handling | Limited | Context manager |
| Type hints | Partial | Full support |

## Complete Implementation

### lifecycle.py

```python
import logging
from contextlib import asynccontextmanager
from typing import AsyncGenerator

logger = logging.getLogger("contpaq.ai.lifecycle")

async def startup_handler() -> None:
    """Initialize resources on startup."""
    logger.info("Starting up...")
    # Load AI models
    # Open database connections
    # Initialize caches

async def shutdown_handler() -> None:
    """Clean up resources on shutdown."""
    logger.info("Shutting down...")
    await cleanup_resources()

async def cleanup_resources() -> None:
    """Release application resources."""
    # Unload models
    # Close connections
    # Delete temp files

@asynccontextmanager
async def lifespan(app) -> AsyncGenerator[None, None]:
    """Lifespan context manager."""
    await startup_handler()
    yield
    await shutdown_handler()
```

### main.py Integration

```python
from fastapi import FastAPI
from lifecycle import lifespan

app = FastAPI(lifespan=lifespan)
```

## Best Practices

### 1. Keep Handlers Async

```python
# Good: Async for non-blocking
async def cleanup_resources():
    await db.close()

# Bad: Blocking in async context
def cleanup_resources():
    db.close()  # Blocks event loop
```

### 2. Log All Lifecycle Events

```python
async def startup_handler():
    logger.info("Starting up...")
    # ... work ...
    logger.info("Startup complete")
```

### 3. Separate Cleanup Function

```python
# Good: Separate, testable function
async def cleanup_resources():
    # Cleanup logic

async def shutdown_handler():
    await cleanup_resources()

# Bad: Everything in one function
async def shutdown_handler():
    # 100 lines of cleanup code
```

### 4. Handle Cleanup Errors

```python
async def cleanup_resources():
    try:
        await db.close()
    except Exception as e:
        logger.error(f"DB close failed: {e}")
    # Continue with other cleanup
```

## Testing Lifecycle Events

### Test Async Handlers

```python
import pytest
import asyncio

@pytest.mark.asyncio
async def test_startup_completes():
    from lifecycle import startup_handler
    await startup_handler()  # Should not raise

@pytest.mark.asyncio
async def test_shutdown_completes():
    from lifecycle import shutdown_handler
    await shutdown_handler()
```

### Test Lifespan Context

```python
def test_lifespan_is_context_manager():
    from lifecycle import lifespan
    from unittest.mock import MagicMock

    ctx = lifespan(MagicMock())
    assert hasattr(ctx, '__aenter__')
    assert hasattr(ctx, '__aexit__')
```

## Common Use Cases

### Loading AI Models

```python
model = None

async def startup_handler():
    global model
    logger.info("Loading AI model...")
    model = await load_model("layoutlmv3")
    logger.info("Model loaded")

async def cleanup_resources():
    global model
    if model:
        del model
        logger.info("Model unloaded")
```

### Database Connections

```python
from databases import Database

database = Database("postgresql://...")

@asynccontextmanager
async def lifespan(app):
    await database.connect()
    yield
    await database.disconnect()
```

## Signals and Shutdown

Uvicorn handles SIGTERM/SIGINT and triggers the shutdown event:

```
SIGTERM → uvicorn → lifespan __aexit__ → shutdown_handler
```

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| Shutdown hangs | Blocking code | Use async operations |
| Resources not cleaned | Error in cleanup | Wrap in try/except |
| Model not unloaded | Reference held | Delete global references |
