# Learning Guide: T002.4.4 - Scanned PDFs and OCR

## Text-Based vs Scanned PDFs

### Text-Based PDF

```
%PDF-1.4
...
4 0 obj
<< /Length 100 >>
stream
BT
/F1 12 Tf
100 700 Td
(Hello World) Tj  ← Actual text stored
ET
endstream
endobj
```

- Text is stored as character codes
- Directly extractable with PyMuPDF
- Searchable, copyable
- Small file sizes

### Scanned PDF (Image-Based)

```
%PDF-1.4
...
5 0 obj
<< /Type /XObject
   /Subtype /Image
   /Width 100 /Height 150
   /ColorSpace /DeviceGray
   /BitsPerComponent 8
   /Filter /FlateDecode >>
stream
... binary image data ...  ← Pixels, not text
endstream
endobj
```

- Text is "drawn" as pixels in an image
- Requires OCR for extraction
- Not searchable without processing
- Large file sizes

## Detecting PDF Type

### Method 1: Check for Text Streams

```python
def has_text_content(pdf_path):
    with open(pdf_path, "rb") as f:
        content = f.read()
    # Text-based PDFs have BT (Begin Text) markers
    return b"BT" in content and b"Tj" in content
```

### Method 2: Check for Image Objects

```python
def has_image_content(pdf_path):
    with open(pdf_path, "rb") as f:
        content = f.read()
    return b"/Subtype /Image" in content
```

### Method 3: Using PyMuPDF

```python
import fitz

def detect_pdf_type(pdf_path):
    doc = fitz.open(pdf_path)
    page = doc[0]

    text = page.get_text().strip()
    images = page.get_images()

    if len(text) > 50:
        return "text-based"
    elif images:
        return "scanned"
    else:
        return "unknown"
```

## Image XObject in PDF

### Structure

```
5 0 obj
<< /Type /XObject         % Object type
   /Subtype /Image        % Subtype: Image
   /Width 100             % Pixel width
   /Height 150            % Pixel height
   /ColorSpace /DeviceGray  % Color model
   /BitsPerComponent 8    % Bits per pixel
   /Filter /FlateDecode   % Compression
   /Length 1234 >>        % Stream length
stream
... compressed pixel data ...
endstream
endobj
```

### Color Spaces

| ColorSpace | Description | Bytes/Pixel |
|------------|-------------|-------------|
| /DeviceGray | Grayscale | 1 |
| /DeviceRGB | Full color | 3 |
| /DeviceCMYK | Print color | 4 |

### Common Filters

| Filter | Description |
|--------|-------------|
| /FlateDecode | zlib compression |
| /DCTDecode | JPEG compression |
| /CCITTFaxDecode | Fax/TIFF compression |
| /JBIG2Decode | JBIG2 compression |

## OCR Processing Workflow

### 1. Extract Image from PDF

```python
import fitz

doc = fitz.open("scanned.pdf")
page = doc[0]

# Get page as image
pix = page.get_pixmap(dpi=300)
image_bytes = pix.tobytes("png")
```

### 2. Run OCR

```python
import pytesseract
from PIL import Image
import io

# Load image
image = Image.open(io.BytesIO(image_bytes))

# Extract text with Spanish language
text = pytesseract.image_to_string(
    image,
    lang="spa",
    config="--psm 6"  # Assume uniform text block
)
```

### 3. Get Bounding Boxes

```python
# Get detailed output with positions
data = pytesseract.image_to_data(
    image,
    lang="spa",
    output_type=pytesseract.Output.DICT
)

# Extract words with coordinates
for i, word in enumerate(data["text"]):
    if word.strip():
        x, y, w, h = (
            data["left"][i],
            data["top"][i],
            data["width"][i],
            data["height"][i]
        )
        conf = data["conf"][i]
        print(f"{word}: ({x}, {y}, {w}, {h}) conf={conf}%")
```

## Tesseract Configuration

### Page Segmentation Modes (PSM)

| PSM | Description |
|-----|-------------|
| 0 | Orientation and script detection only |
| 3 | Fully automatic page segmentation |
| 6 | Assume a single uniform block of text |
| 11 | Sparse text (find as much text as possible) |

### Language Selection

```python
# Spanish
text = pytesseract.image_to_string(image, lang="spa")

# Multiple languages
text = pytesseract.image_to_string(image, lang="spa+eng")
```
