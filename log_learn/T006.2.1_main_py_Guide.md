# T006.2.1 Learning Guide: FastAPI Main Application

## Overview

This guide explains how to create the main entry point for a FastAPI application, including proper configuration, metadata setup, and router integration.

## What is main.py?

The `main.py` file is the entry point for a FastAPI application. It:
- Creates the FastAPI application instance
- Configures application metadata
- Includes all routers
- Sets up middleware (CORS, logging, etc.)
- Defines startup/shutdown events

## Key Concepts

### 1. Creating the FastAPI Application

```python
from fastapi import FastAPI

app = FastAPI(
    title="My API",
    description="API description",
    version="1.0.0",
)
```

### 2. Application Metadata

FastAPI uses metadata for OpenAPI documentation:

| Parameter | Purpose |
|-----------|---------|
| `title` | API title in docs |
| `description` | Markdown-formatted description |
| `version` | API version (semver) |
| `docs_url` | Swagger UI path (default: /docs) |
| `redoc_url` | ReDoc path (default: /redoc) |
| `openapi_url` | Schema path (default: /openapi.json) |

### 3. Including Routers

```python
from api.routes import router

app.include_router(router)

# With prefix and tags
app.include_router(
    router,
    prefix="/api/v1",
    tags=["invoices"],
)
```

### 4. Running the Application

**Development:**
```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

**Production:**
```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --workers 4
```

### 5. Application Structure

```
ai-service/
├── src/
│   ├── main.py          # Entry point
│   ├── api/
│   │   ├── __init__.py
│   │   └── routes.py    # Route definitions
│   ├── models/          # Pydantic models
│   ├── services/        # Business logic
│   └── utils/           # Utilities
└── tests/
```

## Best Practices

### 1. Separate Configuration

```python
# config.py
APP_TITLE = "My API"
APP_VERSION = "1.0.0"

# main.py
from config import APP_TITLE, APP_VERSION

app = FastAPI(title=APP_TITLE, version=APP_VERSION)
```

### 2. Modular Routers

```python
# Don't: All routes in main.py
# Do: Separate routers
from api.health import router as health_router
from api.invoices import router as invoices_router

app.include_router(health_router)
app.include_router(invoices_router, prefix="/invoices")
```

### 3. Documentation Quality

Use Markdown in the description:
```python
APP_DESCRIPTION = """
## Features
* Feature 1
* Feature 2

## Authentication
API Key required in header.
"""
```

## Testing main.py

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_app_has_title():
    assert app.title is not None

def test_health_accessible():
    response = client.get("/health")
    assert response.status_code == 200
```

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| ModuleNotFoundError | Wrong import path | Add src to PYTHONPATH |
| Port in use | Previous instance running | Kill process or use different port |
| Docs not showing | docs_url=None | Check FastAPI init params |
