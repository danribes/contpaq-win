# Learning Guide: T003.4.5 - Define all status messages in Spanish

## Overview

This guide covers best practices for defining status messages in a multilingual application, with focus on Spanish language conventions and user experience.

## Concepts Covered

### 1. Status Message Categories

Organize status messages by purpose:

```json
{
  "status": {
    // Loading/Progress states
    "loading": "Cargando...",
    "saving": "Guardando...",
    "processing": "Procesando...",

    // Result states
    "success": "Éxito",
    "error": "Error",
    "warning": "Advertencia",

    // Connection states
    "connecting": "Conectando...",
    "connected": "Conectado",
    "disconnected": "Desconectado"
  }
}
```

Categories:
- **Loading/Progress**: In-progress operations
- **Result**: Operation outcomes
- **Connection**: Network/service states
- **Entity states**: Domain-specific status

### 2. Spanish Verb Forms for Status

Different verb forms for different states:

| State Type | Spanish Form | Example |
|------------|--------------|---------|
| In-progress | Gerund (-ando/-endo) | Cargando, Procesando |
| Completed | Past Participle (-ado/-ido) | Conectado, Validada |
| Ready | Adjective | Listo |

```json
{
  "status": {
    // Gerund (in-progress)
    "loading": "Cargando...",      // -ando
    "processing": "Procesando...", // -ando

    // Past participle (completed)
    "connected": "Conectado",      // -ado
    "saved": "Guardado"            // -ado
  }
}
```

### 3. Ellipsis Convention

Use ellipsis ("...") for in-progress states:

```json
{
  "status": {
    // ✅ Correct - ellipsis for ongoing actions
    "loading": "Cargando...",
    "saving": "Guardando...",

    // ✅ Correct - no ellipsis for completed states
    "success": "Éxito",
    "ready": "Listo"
  }
}
```

### 4. Gender Agreement

Spanish adjectives must agree with the noun they describe:

```json
{
  "states": {
    // Feminine (for "factura")
    "uploaded": "Cargada",     // La factura está cargada
    "extracted": "Extraída",   // La factura está extraída
    "validated": "Validada",   // La factura está validada

    // Masculine (for "documento")
    "uploaded": "Cargado",     // El documento está cargado
    "processed": "Procesado"   // El documento está procesado
  }
}
```

### 5. Notification Types

Standard notification types with Spanish translations:

```json
{
  "status": {
    "success": "Éxito",
    "error": "Error",
    "warning": "Advertencia",
    "info": "Información"
  }
}
```

### Using Status Messages in React Components

```tsx
import { useTranslation } from '../i18n';

type StatusType = 'loading' | 'saving' | 'processing' | 'success' | 'error';

interface StatusIndicatorProps {
  status: StatusType;
}

function StatusIndicator({ status }: StatusIndicatorProps) {
  const { t } = useTranslation();

  const statusColors = {
    loading: 'text-blue-500',
    saving: 'text-blue-500',
    processing: 'text-blue-500',
    success: 'text-green-500',
    error: 'text-red-500',
  };

  return (
    <div className={`flex items-center ${statusColors[status]}`}>
      {(status === 'loading' || status === 'saving' || status === 'processing') && (
        <span className="animate-spin mr-2">⟳</span>
      )}
      <span>{t(`status.${status}`)}</span>
    </div>
  );
}
```

### Invoice State Badge Component

```tsx
import { useTranslation } from '../i18n';
import { InvoiceState } from '../types';

function StateBadge({ state }: StateBadgeProps) {
  const { t } = useTranslation();

  const stateStyles = {
    UPLOADED: 'bg-blue-100 text-blue-800',
    EXTRACTED: 'bg-yellow-100 text-yellow-800',

    </span>
  );
}
```

### Service Status Component

```tsx
function ServiceStatus({ service }: { service: string }) {
  const { t } = useTranslation();
  const status = useServiceStatus(service);

  const statusConfig = {
    starting: { icon: '⏳', color: 'text-yellow-500' },
    running: { icon: '✓', color: 'text-green-500' },
    stopped: { icon: '○', color: 'text-gray-500' },
    error: { icon: '✕', color: 'text-red-500' },
  };

  const config = statusConfig[status];

  return (
    <div className="flex items-center gap-2">
      <span className={config.color}>{config.icon}</span>
      <span>{t(`services.${service}`)}</span>
      <span className="text-sm text-gray-500">
        {t(`services.${status}`)}
      </span>
    </div>
  );
}
```

## Best Practices

### 1. Consistent Terminology

Use the same Spanish terms throughout:

| English | Spanish | Notes |
|---------|---------|-------|
| Loading | Cargando | Not "Cargamiento" |
| Processing | Procesando | Not "En proceso" |
| Success | Éxito | Not "Exitoso" |
| Error | Error | Same in both languages |
| Ready | Listo | Not "Preparado" |

### 2. Keep Status Messages Short

```json
{
  "status": {
    // ✅ Good - short and clear
    "loading": "Cargando...",

    // ❌ Bad - too verbose
    "loading": "El sistema está cargando los datos, por favor espere..."
  }
}
```

### 3. Use Appropriate Accents

```json
{
  "status": {
    // ✅ Correct accents
    "success": "Éxito",
    "info": "Información",

    // ❌ Missing accents (incorrect)
    "success": "Exito",
    "info": "Informacion"
  }
}
```

### 4. Separate Loading and Loaded States

```json
{
  "status": {
    // In-progress (with ellipsis)
    "connecting": "Conectando...",

    // Completed (no ellipsis)
    "connected": "Conectado"
  }
}
```

## Summary

Defining status messages involves:
1. ✅ Use appropriate Spanish verb forms (gerund vs participle)
2. ✅ Add ellipsis for in-progress states
3. ✅ Ensure gender agreement with nouns
4. ✅ Keep messages short and clear
5. ✅ Use consistent terminology
6. ✅ Include proper Spanish accents
