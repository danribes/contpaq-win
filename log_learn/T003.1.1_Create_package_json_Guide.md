# Learning Guide: T003.1.1 - Electron/React Package Configuration

## What is package.json?

`package.json` is the manifest file for Node.js projects. It defines:
- Project metadata (name, version, description)
- Dependencies and their versions
- Scripts for common tasks
- Build configuration

## Electron Application Structure

### Main Process vs Renderer Process

```
desktop-app/
├── src/
│   ├── main/          # Main process (Node.js)
│   │   └── index.ts   # Electron app entry
│   └── renderer/      # Renderer process (React)
│       └── index.tsx  # React app entry
├── package.json       # Project configuration
└── dist/              # Built output
    ├── main/
    └── renderer/
```

### Process Communication

```
┌─────────────────────┐     IPC      ┌─────────────────────┐
│   Main Process      │◄────────────►│  Renderer Process   │
│   (Node.js)         │              │  (Chromium/React)   │
├─────────────────────┤              ├─────────────────────┤
│ - System access     │              │ - UI rendering      │
│ - File operations   │              │ - User interaction  │
│ - Native APIs       │              │ - React components  │
│ - Spawn processes   │              │ - Tailwind CSS      │
└─────────────────────┘              └─────────────────────┘
```

## Key Dependencies Explained

### Electron (^28.0.0)

Desktop app framework combining Chromium + Node.js.

```javascript
// main/index.ts
const { app, BrowserWindow } = require('electron');

app.whenReady().then(() => {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js')
    }
  });
  win.loadFile('dist/renderer/index.html');
});
```

### React + React-DOM (^18.2.0)

UI library for building component-based interfaces.

```tsx
// renderer/App.tsx
import React from 'react';

function App() {
  return (
    <div className="p-4 bg-gray-100">
      <h1 className="text-2xl font-bold">ContPAQ-Win</h1>
    </div>
  );
}
```

### React-PDF (^7.7.0)

PDF viewing component for React.

```tsx
import { Document, Page } from 'react-pdf';

function PDFViewer({ file }) {
  return (
    <Document file={file}>
      <Page pageNumber={1} />
    </Document>
  );
}
```

### Better-SQLite3 (^9.4.0)

Synchronous SQLite database for Electron.

```javascript
const Database = require('better-sqlite3');
const db = new Database('invoices.db');

const invoice = db.prepare(`
  SELECT * FROM invoices WHERE id = ?
`).get(invoiceId);
```

### Tailwind CSS (^3.4.0)

Utility-first CSS framework.

```html
<div class="flex items-center justify-between p-4 bg-white shadow-md">
  <h1 class="text-xl font-semibold text-gray-800">Invoice</h1>
  <button class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600">
    Process
  </button>
</div>
```

## Scripts Configuration

### Development Scripts

```json
{
  "scripts": {
    "dev": "concurrently \"npm run dev:renderer\" \"npm run dev:main\"",
    "dev:renderer": "vite",
    "dev:main": "tsc -w -p tsconfig.main.json"
  }
}
```

- `vite`: Hot-reload for renderer
- `tsc -w`: Watch mode for main process

### Build Scripts

```json
{
  "scripts": {
    "build": "npm run build:renderer && npm run build:main",
    "build:renderer": "vite build",
    "build:main": "tsc -p tsconfig.main.json"
  }
}
```

### Package Script

```json
{
  "scripts": {
    "package": "electron-builder"
  }
}
```

## Version Specifiers

| Symbol | Meaning | Example |
|--------|---------|---------|
| ^18.2.0 | Compatible with 18.x.x | 18.2.0 to 18.9.9 |
| ~18.2.0 | Patch updates only | 18.2.0 to 18.2.9 |
| 18.2.0 | Exact version | Only 18.2.0 |
| >=18.2.0 | At least version | 18.2.0 and higher |

