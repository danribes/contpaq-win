# T008.2.2 Learning Guide: Stop Bridge Service

## Overview

This guide covers implementing graceful process shutdown in Node.js/Electron applications following TDD principles.

## Key Concepts

### 1. Unix Process Signals

Unix signals are used for inter-process communication. Key signals for process termination:

| Signal | Number | Description |
|--------|--------|-------------|
| SIGTERM | 15 | Graceful termination request (can be caught) |
| SIGKILL | 9 | Force termination (cannot be caught) |
| SIGINT | 2 | Interrupt (Ctrl+C) |

### 2. Graceful Shutdown Pattern

The standard pattern for graceful shutdown:

```
SIGTERM → Wait for cleanup → SIGKILL (if necessary)
```

This allows processes to:
- Save state to disk
- Close database connections
- Release resources
- Notify dependent services

### 3. Node.js Process Termination

```typescript
import { ChildProcess } from 'child_process';

// Graceful termination request
process.kill('SIGTERM');

// Force termination (cannot be ignored)
process.kill('SIGKILL');

// Check if process is still alive
if (!process.killed) {
  // Process still running
}
```

## Code Patterns

### Graceful Shutdown Implementation

```typescript
async stopService(): Promise<void> {
  if (this.status === 'stopped') return;

  this.status = 'stopping';

  if (!this.process) {
    this.status = 'stopped';
    return;
  }

  return new Promise((resolve) => {
    let isResolved = false;
    let shutdownTimeout: NodeJS.Timeout | null = null;
    let forceKillTimeout: NodeJS.Timeout | null = null;

    const cleanup = () => {
      if (isResolved) return;
      isResolved = true;
      if (shutdownTimeout) clearTimeout(shutdownTimeout);
      if (forceKillTimeout) clearTimeout(forceKillTimeout);
      this.process = null;
      this.status = 'stopped';
      resolve();
    };

    // Listen for exit
    this.process.once('exit', cleanup);

    // Send SIGTERM
    try {
      this.process.kill('SIGTERM');
    } catch {
      cleanup();
      return;
    }

    // Set force kill timeout
    shutdownTimeout = setTimeout(() => {
      if (isResolved) return;

      try {
        this.process!.kill('SIGKILL');
      } catch { /* ignore */ }

      // Grace period for SIGKILL
      forceKillTimeout = setTimeout(() => {
        if (!isResolved) {
          this.process!.removeListener('exit', cleanup);
          cleanup();
        }
      }, 1000);
    }, this.shutdownTimeoutMs);
  });
}
```

### Key Implementation Details

1. **Idempotency**: Check if already stopped before doing anything
2. **No-op for missing process**: Handle case where process crashed
3. **Single resolution**: Use `isResolved` flag to prevent double-resolution
4. **Timeout cleanup**: Always clear timeouts to prevent memory leaks
5. **Exception handling**: Catch errors from `kill()` (process may be dead)

## Testing Strategies

### 1. Test SIGTERM is Sent First

```typescript
it('should send SIGTERM first', async () => {
  const process = await startService();

  process.kill.mockImplementation(() => {
    process.emit('exit', 0, 'SIGTERM');
    return true;
  });

  await manager.stopService();

  expect(process.kill.mock.calls[0][0]).toBe('SIGTERM');
});
```

### 2. Test Force Kill After Timeout

```typescript
it('should send SIGKILL after timeout', async () => {
  const manager = new ProcessManager({ shutdownTimeoutMs: 100 });
  const process = await startService();

  const killCalls: string[] = [];
  process.kill.mockImplementation((signal: string) => {
    killCalls.push(signal);
    if (signal === 'SIGKILL') {
      process.emit('exit', null, 'SIGKILL');
    }
    return true;
  });

  await manager.stopService();

  expect(killCalls).toEqual(['SIGTERM', 'SIGKILL']);
}, 10000);
```

### 3. Test Status Transitions

```typescript
it('should transition through STOPPING to STOPPED', async () => {
  const process = await startService();

  let statusWhenKilled: string;
  process.kill.mockImplementation(() => {
    statusWhenKilled = manager.getStatus();
    process.emit('exit', 0);
    return true;
  });

  await manager.stopService();

  expect(statusWhenKilled).toBe('stopping');
  expect(manager.getStatus()).toBe('stopped');
});
```

### 4. Test Exception Handling

```typescript
it('should handle kill throwing error', async () => {
  const process = await startService();

  process.kill.mockImplementation(() => {
    throw new Error('Process already terminated');
  });

  await expect(manager.stopService()).resolves.toBeUndefined();
  expect(manager.getStatus()).toBe('stopped');
});
```

## Common Pitfalls

### 1. Not Clearing Timeouts

**Problem**: Memory leaks and unexpected behavior from lingering timeouts.

**Solution**: Always clear timeouts in cleanup:

```typescript
const cleanup = () => {
  if (shutdownTimeout) clearTimeout(shutdownTimeout);
  if (forceKillTimeout) clearTimeout(forceKillTimeout);
  // ... rest of cleanup
};
```

### 2. Double Resolution

**Problem**: Promise resolves multiple times causing errors.

**Solution**: Use a flag:

```typescript
let isResolved = false;

const cleanup = () => {
  if (isResolved) return;  // Guard against double-call
  isResolved = true;
  // ...
};
```

### 3. Not Handling Missing Process

**Problem**: Calling `kill()` on null throws.

**Solution**: Check for process existence:

```typescript
if (!this.process) {
  this.status = 'stopped';
  return;
}
```

### 4. Not Removing Event Listeners

**Problem**: Event listener fires after cleanup, causing errors.

**Solution**: Remove listener before force cleanup:

```typescript
process.removeListener('exit', cleanup);
cleanup();
```

## Best Practices

1. **Always Use SIGTERM First**: Give processes a chance to clean up
2. **Set Reasonable Timeout**: 5 seconds is common (not too short, not too long)
3. **Log Force Kills**: Warning when SIGKILL is needed helps debugging
4. **Make Stop Idempotent**: Multiple calls should be safe
5. **Handle All Edge Cases**: Already stopped, no process, kill() throws
