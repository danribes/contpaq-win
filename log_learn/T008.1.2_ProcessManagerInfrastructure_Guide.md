# T008.1.2 Learning Guide: ProcessManager Infrastructure

## Overview

This guide explains the infrastructure patterns added to ProcessManager for event handling, path resolution, error tracking, and configuration management.

## Key Concepts

### 1. Event Emitter Pattern

The ProcessManager uses a custom event emitter for notifying listeners about status changes.

```typescript
// Type definitions
export type ProcessManagerEventType = 'statusChange' | 'error' | 'restart';

export interface StatusChangeEvent {
  service: 'ai' | 'bridge';
  status: ServiceStatus;
  previousStatus: ServiceStatus;
  timestamp: Date;
}

export type EventListener = (event: StatusChangeEvent) => void;

// Implementation using Map<Set>
private eventListeners: Map<ProcessManagerEventType, Set<EventListener>> = new Map();

// Subscribe
on(event: ProcessManagerEventType, listener: EventListener): void {
  const listeners = this.eventListeners.get(event);
  if (listeners) {
    listeners.add(listener);
  }
}

// Unsubscribe
off(event: ProcessManagerEventType, listener: EventListener): void {
  const listeners = this.eventListeners.get(event);
  if (listeners) {
    listeners.delete(listener);
  }
}

// Emit
private emit(event: ProcessManagerEventType, payload: StatusChangeEvent): void {
  const listeners = this.eventListeners.get(event);
  if (listeners) {
    listeners.forEach(listener => listener(payload));
  }
}
```

**Why this pattern?**
- Decouples status changes from UI updates
- Allows multiple components to react to changes
- Standard pattern in event-driven architectures

### 2. Path Resolution for Electron

Electron apps need different paths in development vs production:

```typescript
getAIServicePath(): string {
  const appPath = app.getAppPath();
  if (app.isPackaged) {
    // Production: resources bundled with app
    return path.join(process.resourcesPath, 'ai-service');
  }
  // Development: sibling directory
  return path.join(appPath, '..', 'ai-service');
}

getPythonPath(): string {
  if (app.isPackaged) {
    // Production: bundled Python
    return path.join(process.resourcesPath, 'python', 'python.exe');
  }
  // Development: system Python
  return process.platform === 'win32' ? 'python' : 'python3';
}
```

**Key considerations:**
- `app.isPackaged` - true when running from built executable
- `app.getAppPath()` - path to main.js
- `process.resourcesPath` - path to bundled resources in production

### 3. Error Tracking

Track the last error for each service:

```typescript
// State
private aiLastError: string | null = null;
private bridgeLastError: string | null = null;

// Getters/Setters
getLastError(service: 'ai' | 'bridge'): string | null {
  return service === 'ai' ? this.aiLastError : this.bridgeLastError;
}

clearError(service: 'ai' | 'bridge'): void {
  if (service === 'ai') {
    this.aiLastError = null;
  } else {
    this.bridgeLastError = null;
  }
}

private setError(service: 'ai' | 'bridge', error: string): void {
  if (service === 'ai') {
    this.aiLastError = error;
  } else {
    this.bridgeLastError = error;
  }
}
```

**Usage in health checks:**
```typescript
async checkHealth(service: 'ai' | 'bridge'): Promise<ServiceHealth> {
  // ...
  const lastError = service === 'ai' ? this.aiLastError : this.bridgeLastError;
  return {
    status,
    lastError: lastError ?? undefined,
    // ...
  };
}
```

### 4. Immutable Configuration

Return copies of config to prevent accidental mutation:

```typescript
getConfig(): ProcessManagerConfig {
  return { ...this.config };  // Shallow copy
}
```

**Test for immutability:**
```typescript
it('should return a copy of config (immutable)', () => {
  const config1 = manager.getConfig();
  const config2 = manager.getConfig();
  expect(config1).not.toBe(config2); // Different references
  expect(config1).toEqual(config2);  // Same values
});
```

### 5. Uptime Tracking

Calculate uptime on-demand rather than storing:

```typescript
// Track start times
private aiStartTime: Date | null = null;
private bridgeStartTime: Date | null = null;

// Update in status helper
private updateStatus(service: 'ai' | 'bridge', newStatus: ServiceStatus): void {
  if (service === 'ai') {
    this.aiServiceStatus = newStatus;
    if (newStatus === ServiceStatus.RUNNING) {
      this.aiStartTime = new Date();
    } else if (newStatus === ServiceStatus.STOPPED) {
      this.aiStartTime = null;
    }
  }
  // ...
}

// Calculate in health check
async checkHealth(service: 'ai' | 'bridge'): Promise<ServiceHealth> {
  const startTime = service === 'ai' ? this.aiStartTime : this.bridgeStartTime;

  let uptime: number | undefined;
  if (startTime && status === ServiceStatus.RUNNING) {
    uptime = Date.now() - startTime.getTime();  // ms since start
  }

  return { status, uptime, /* ... */ };
}
```

### 6. Status Update Helper

Centralize status changes with event emission:

```typescript
private updateStatus(service: 'ai' | 'bridge', newStatus: ServiceStatus): void {
  const previousStatus = service === 'ai'
    ? this.aiServiceStatus
    : this.bridgeServiceStatus;

  // Update status
  if (service === 'ai') {
    this.aiServiceStatus = newStatus;
  } else {
    this.bridgeServiceStatus = newStatus;
  }

  // Track timing
  if (newStatus === ServiceStatus.RUNNING) {
    // Set start time
  } else if (newStatus === ServiceStatus.STOPPED) {
    // Clear start time
  }

  // Emit event
  this.emit('statusChange', {
    service,
    status: newStatus,
    previousStatus,
    timestamp: new Date(),
  });
}
```

**Benefits:**
- Single point for status updates
- Automatic event emission
- Automatic uptime tracking
- Reduces code duplication in start/stop methods

## Testing Patterns

### Testing Event Emission

```typescript
it('should emit statusChange event when AI service starts', async () => {
  const listener = jest.fn();
  manager.on('statusChange', listener);

  await manager.startAIService();

  expect(listener).toHaveBeenCalled();
  expect(listener).toHaveBeenCalledWith(
    expect.objectContaining({
      service: 'ai',
      status: ServiceStatus.RUNNING,
    })
  );
});
```

### Testing Unsubscribe

```typescript
it('should allow unsubscribing from events with off', async () => {
  const listener = jest.fn();
  manager.on('statusChange', listener);
  manager.off('statusChange', listener);

  await manager.startAIService();

  expect(listener).not.toHaveBeenCalled();
});
```
