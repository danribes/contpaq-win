# Learning Guide: T003.4.4 - Define all button labels in Spanish

## Overview

This guide covers best practices for defining button labels in a multilingual application, with focus on Spanish language and user interface consistency.

## Concepts Covered

### 1. Button Label Categories

Organize button labels by function:

```json
{
  "buttons": {
    // CRUD operations
    "save": "Guardar",
    "edit": "Editar",
    "delete": "Eliminar",

    // Confirmation actions
    "confirm": "Confirmar",
    "cancel": "Cancelar",

    // Navigation
    "back": "Volver",
    "next": "Siguiente",
    "previous": "Anterior",

    // File operations
    "selectFile": "Seleccionar Archivo",
    "upload": "Cargar",
    "download": "Descargar"
  }
}
```

Categories:
- **CRUD**: Create, Read, Update, Delete operations
- **Confirmation**: Dialog actions (confirm, cancel)
- **Navigation**: Movement between views/pages
- **File**: File-related operations
- **Domain**: Application-specific actions

### 2. Spanish Button Label Conventions

Use imperative verb forms (command form):

| English | Spanish | Form |
|---------|---------|------|
| Save | Guardar | Infinitive as imperative |
| Cancel | Cancelar | Infinitive as imperative |
| Edit | Editar | Infinitive as imperative |
| Delete | Eliminar | Infinitive as imperative |

```json
{
  "buttons": {
    // ✅ Correct - infinitive form
    "save": "Guardar",

    // ❌ Avoid - conjugated forms
    "save": "Guarda",      // 2nd person informal
    "save": "Guarde"       // 2nd person formal
  }
}
```

### 3. Concise Labels

Button labels should be short and scannable:

```json
{
  "buttons": {
    // ✅ Good - short and clear
    "send": "Enviar",

    // ❌ Bad - too verbose
    "send": "Hacer clic para enviar el documento"
  }
}
```

Guidelines:
- Maximum 30 characters
- Prefer single words when possible
- Include context only when necessary

### 4. Consistency Patterns

Maintain consistent verb usage:

```json
{
  "buttons": {
    // File operations - consistent "ar" verb pattern
    "upload": "Cargar",
    "download": "Descargar",
    "export": "Exportar",

    // State changes - consistent pattern
    "validate": "Validar",
    "process": "Procesar",
    "cancel": "Cancelar"
  }
}
```

### 5. Context-Specific Buttons

Provide specific labels for specific actions:

```json
{
  "buttons": {
    // Generic
    "send": "Enviar",

    // Specific - with context
    "sendToContpaqi": "Enviar a ContPAQi"
  }
}
```

### Using Button Labels in React Components

```tsx
import { useTranslation } from '../i18n';

function ActionButtons() {
  const { t } = useTranslation();

  return (
    <div className="flex gap-2">
      <button className="btn btn-primary">
        {t('buttons.save')}
      </button>
      <button className="btn btn-secondary">
        {t('buttons.cancel')}
      </button>
    </div>
  );
}
```

### Button Component with Dynamic Labels

```tsx
interface ButtonProps {
  labelKey: string;
  onClick: () => void;
  variant?: 'primary' | 'secondary' | 'danger';
}

function Button({ labelKey, onClick, variant = 'primary' }: ButtonProps) {
  const { t } = useTranslation();

  const variants = {
    primary: 'bg-blue-500 text-white',
    secondary: 'bg-gray-200 text-gray-800',
    danger: 'bg-red-500 text-white',
  };

  return (
    <button
      className={`px-4 py-2 rounded ${variants[variant]}`}
      onClick={onClick}
    >
      {t(`buttons.${labelKey}`)}
    </button>
  );
}

// Usage
<Button labelKey="save" onClick={handleSave} />
<Button labelKey="delete" onClick={handleDelete} variant="danger" />
```

## Best Practices

### 1. Naming Convention

```json
{
  "buttons": {
    // Use camelCase
    "sendToContpaqi": "...",   // ✅
    "send_to_contpaqi": "...", // ❌
    "SendToContpaqi": "...",   // ❌

    // Use descriptive names
    "validate": "...",         // ✅
    "btn1": "..."              // ❌
  }
}
```

### 2. Avoid Abbreviations

```json
{
  "buttons": {
    // ✅ Full words
    "confirm": "Confirmar",
    "previous": "Anterior",

    // ❌ Abbreviations
    "conf": "Conf.",
    "prev": "Ant."
  }
}
```

### 3. Accessibility Considerations

```tsx
// Include aria-label for icon-only buttons
<button
  className="icon-button"
  aria-label={t('buttons.refresh')}
>
  <RefreshIcon />
</button>
```

### 4. Consistent Terminology

Use the same Spanish terms throughout:

| Action | Always Use | Don't Use |
|--------|------------|-----------|
| Cancel | Cancelar | Anular, Deshacer |
| Delete | Eliminar | Borrar, Quitar |
| Edit | Editar | Modificar |
| Save | Guardar | Salvar |
| Send | Enviar | Mandar |

Defining button labels involves:
1. ✅ Use Spanish infinitive verb forms

6. ✅ Consider accessibility
