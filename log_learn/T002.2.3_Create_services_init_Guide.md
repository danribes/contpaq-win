# Learning Guide: T002.2.3 - Service Layer Architecture

## What is a Service Layer?

The service layer contains the core business logic of an application. It sits between the API layer (HTTP endpoints) and the data layer (models, database).

```
┌─────────────────┐
│   API Layer     │  ← HTTP endpoints, request handling
│   (routes.py)   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Service Layer   │  ← Business logic, processing
│ (services/)     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   Data Layer    │  ← Models, database, external APIs
│   (models/)     │
└─────────────────┘
```

## Why Separate Services from API?

### Without Service Layer (Bad)
```python
# api/routes.py - Everything in one place
@app.post("/extract")
async def extract_invoice(file: UploadFile):
    # PDF detection logic here
    pdf = fitz.open(...)
    text = ""
    for page in pdf:
        text += page.get_text()

    # OCR logic here
    if len(text) < 100:
        image = convert_to_image(...)
        text = pytesseract.image_to_string(...)

    # AI extraction logic here
    model = load_model(...)
    result = model.predict(...)

    return result
```

Problems:
- Hard to test (need HTTP requests)
- Hard to reuse logic
- Hard to maintain (1000+ line files)

### With Service Layer (Good)
```python
# api/routes.py - Just HTTP handling
@app.post("/extract")
async def extract_invoice(file: UploadFile):
    content = await file.read()
    result = await extraction_service.extract(content)
    return result

# services/extraction_service.py - Business logic
class ExtractionService:
    def __init__(self, pdf_extractor, ocr_service, ai_extractor):
        self.pdf = pdf_extractor
        self.ocr = ocr_service
        self.ai = ai_extractor

    async def extract(self, pdf_bytes: bytes) -> InvoiceExtraction:
        pdf_type = self.pdf.detect_type(pdf_bytes)

        if pdf_type == "scanned":
            text = self.ocr.extract(pdf_bytes)
        else:
            text = self.pdf.extract_text(pdf_bytes)

        return self.ai.extract_fields(text)
```

Benefits:
- Easy to test (no HTTP needed)
- Reusable across endpoints
- Clear responsibilities

## Service Design Principles

### 1. Stateless Services

Services should not hold state between calls:
```python
# Bad - Stateful
class PDFExtractor:
    def __init__(self):
        self.last_pdf = None  # State!

    def extract(self, pdf):
        self.last_pdf = pdf
        ...

# Good - Stateless
class PDFExtractor:
    def extract(self, pdf: bytes) -> TextResult:
        # Each call is independent
        ...
```

### 2. Dependency Injection

Services receive dependencies through constructor:
```python
class ExtractionService:
    def __init__(
        self,
        pdf_extractor: PDFExtractor,
        ocr_service: OCRService,
        ai_extractor: AIExtractor
    ):
        self.pdf = pdf_extractor
        self.ocr = ocr_service
        self.ai = ai_extractor
```

Benefits:
- Easy to test with mocks
- Easy to swap implementations
- Clear dependencies

### 3. Async Support

Services should work with async/await for FastAPI:
```python
class PDFExtractor:
    async def extract_text(self, pdf_bytes: bytes) -> TextResult:
        # Can use async file I/O, HTTP calls, etc.
        ...
```

### 4. Configuration via Environment

Services read config from environment:
```python
class OCRService:
    def __init__(self, config: Settings):
        self.tesseract_path = config.TESSERACT_PATH
        self.language = config.OCR_LANGUAGE
```

## Testing Services

### Unit Tests
```python
def test_pdf_type_detection():
    extractor = PDFExtractor()

    with open("fixtures/text_based.pdf", "rb") as f:
        pdf_type = extractor.detect_type(f.read())

    assert pdf_type == "text_based"
```

### Integration Tests
```python
async def test_full_extraction():
    # Use real services
    service = ExtractionService(
        pdf_extractor=PDFExtractor(),
        ocr_service=OCRService(tesseract_path="/usr/bin/tesseract"),
        ai_extractor=AIExtractor(model_path="./models/layoutlm")
    )

    with open("fixtures/invoice.pdf", "rb") as f:
        result = await service.extract(f.read())

    assert result.vendor_rfc.value == "ABC123456789"
```

### Mocking for Tests
```python
async def test_extraction_with_mock():
    # Mock the AI extractor
    mock_ai = Mock()
    mock_ai.extract_fields.return_value = InvoiceExtraction(...)

    service = ExtractionService(
        pdf_extractor=PDFExtractor(),
        ocr_service=OCRService(...),
        ai_extractor=mock_ai  # Use mock
    )

    result = await service.extract(pdf_bytes)
    mock_ai.extract_fields.assert_called_once()
```

## Common Patterns

### Factory Pattern
```python
# services/__init__.py
def create_extraction_service(config: Settings) -> ExtractionService:
    """Factory function to create configured service"""
    return ExtractionService(
        pdf_extractor=PDFExtractor(),
        ocr_service=OCRService(config.TESSERACT_PATH),
        ai_extractor=AIExtractor(config.MODEL_PATH)
    )
```

### Context Manager for Resources
```python
class AIExtractor:
    async def __aenter__(self):
        self.model = await load_model_async(self.model_path)
        return self

    async def __aexit__(self, *args):
        await self.model.cleanup()

# Usage
async with AIExtractor(model_path) as extractor:
    result = await extractor.extract_fields(text)
```
