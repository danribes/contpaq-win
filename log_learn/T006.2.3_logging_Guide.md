# T006.2.3 Learning Guide: Request Logging Middleware

## Overview

This guide explains how to create custom middleware in FastAPI/Starlette for logging HTTP requests with timing information.

## What is Middleware?

Middleware is code that runs before and/or after each request. It can:
- Log requests
- Modify requests/responses
- Handle authentication
- Add headers
- Measure timing

## Key Concepts

### 1. BaseHTTPMiddleware

Starlette provides `BaseHTTPMiddleware` as a simple base class:

```python
from starlette.middleware.base import BaseHTTPMiddleware

class MyMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        # Before request
        response = await call_next(request)
        # After request
        return response
```

### 2. Middleware Execution Order

Middleware is added in reverse order - last added runs first:

```python
app.add_middleware(A)  # Runs second (inner)
app.add_middleware(B)  # Runs first (outer)

# Request flow: B -> A -> handler -> A -> B
```

### 3. Python Logging

```python
import logging

logger = logging.getLogger("myapp.module")
logger.setLevel(logging.INFO)

# Add handler
handler = logging.StreamHandler()
formatter = logging.Formatter("%(asctime)s - %(name)s - %(message)s")
handler.setFormatter(formatter)
logger.addHandler(handler)
```

## Request Logging Middleware

### Complete Implementation

```python
import logging
import time
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import Response

logger = logging.getLogger("contpaq.ai.request")
logger.setLevel(logging.INFO)

class RequestLoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next) -> Response:
        start_time = time.time()

        method = request.method
        path = request.url.path

        response = await call_next(request)

        duration_ms = (time.time() - start_time) * 1000
        logger.info(f"{method} {path} - {response.status_code} - {duration_ms:.2f}ms")

        return response
```

### Adding to FastAPI App

```python
from fastapi import FastAPI
from middleware.logging import RequestLoggingMiddleware

app = FastAPI()
app.add_middleware(RequestLoggingMiddleware)
```

## Best Practices

### 1. Use Named Loggers

```python
# Good: Specific name for filtering
logger = logging.getLogger("contpaq.ai.request")

# Bad: Root logger
logger = logging.getLogger()
```

### 2. Measure Time Correctly

```python
# Good: Measure wall-clock time
start = time.time()
response = await call_next(request)
duration = time.time() - start

# Better: Use perf_counter for precision
start = time.perf_counter()
response = await call_next(request)
duration = time.perf_counter() - start
```

### 3. Don't Log Sensitive Data

```python
# Bad: May log passwords
logger.info(f"Request body: {await request.body()}")

# Good: Log only safe metadata
logger.info(f"{method} {path} - {status}")
```

## Testing Middleware

### Using caplog Fixture

```python
def test_request_logged(client, caplog):
    with caplog.at_level(logging.INFO):
        client.get("/health")

    # Check log messages
    messages = [r.message for r in caplog.records]
    assert any("GET" in msg for msg in messages)
```

### Checking Middleware Registration

```python
def test_middleware_configured():
    middleware_names = [m.cls.__name__ for m in app.user_middleware]
    assert "RequestLoggingMiddleware" in middleware_names
```

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| No logs appear | Logger not configured | Add handler to logger |
| Duplicate logs | Multiple handlers added | Check `if not logger.handlers` |
| Timing wrong | Using `datetime` | Use `time.time()` or `time.perf_counter()` |
| Body already read | Reading body twice | Stream body once |

## Production Considerations

### Log Handlers

```python
# File handler for production
file_handler = logging.FileHandler("/var/log/app/requests.log")
logger.addHandler(file_handler)

# Rotating file handler
from logging.handlers import RotatingFileHandler
handler = RotatingFileHandler(
    "requests.log",
    maxBytes=10_000_000,  # 10MB
    backupCount=5
)
```

### Structured Logging (JSON)

```python
import json

class JSONFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "timestamp": self.formatTime(record),
            "level": record.levelname,
            "message": record.message,
        })
```
