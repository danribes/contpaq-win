# Learning Guide: T002.2.4 - REST API Layer with FastAPI

## What is an API Layer?

The API layer is the HTTP interface of your application. It handles:
- Receiving HTTP requests
- Validating input data
- Calling business logic (services)
- Returning HTTP responses

```
┌─────────────────────────────────────────────────────────┐
│                    HTTP Client                          │
│              (Desktop App, Browser, curl)               │
└────────────────────────┬────────────────────────────────┘
                         │ HTTP Request
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    API Layer                            │
│                   (FastAPI routes)                      │
│  - Parse request body                                   │
│  - Validate input (Pydantic)                           │
│  - Call services                                        │
│  - Format response                                      │
└────────────────────────┬────────────────────────────────┘
                         │ Function call
                         ▼
┌─────────────────────────────────────────────────────────┐
│                  Service Layer                          │
│              (Business logic)                           │
└─────────────────────────────────────────────────────────┘
```

## FastAPI Overview

FastAPI is a modern Python web framework for building APIs:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
async def health_check():
    return {"status": "healthy"}
```

### Key Features

1. **Automatic validation** via Pydantic
2. **Auto-generated docs** (OpenAPI/Swagger)
3. **Async support** for high performance
4. **Type hints** for better IDE support

## FastAPI Route Patterns

### Basic Route

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
async def health_check():
    """Health check endpoint"""
    return {
        "status": "healthy",
        "timestamp": datetime.utcnow().isoformat(),
        "version": "0.1.0"
    }
```

### Route with Request Body

```python
from fastapi import FastAPI, UploadFile, File
from pydantic import BaseModel

class ExtractionResponse(BaseModel):
    vendor_rfc: str
    total: float
    confidence: float

@app.post("/extract", response_model=ExtractionResponse)
async def extract_invoice(file: UploadFile = File(...)):
    """Extract data from PDF invoice"""
    content = await file.read()
    result = await extraction_service.extract(content)
    return result
```

### Route with Path Parameters

```python
@app.get("/invoices/{invoice_id}")
async def get_invoice(invoice_id: int):
    """Get invoice by ID"""
    return {"id": invoice_id, "status": "found"}
```

### Route with Query Parameters

```python
@app.get("/invoices")
async def list_invoices(
    state: str = None,
    limit: int = 10,
    offset: int = 0
):
    """List invoices with optional filtering"""
    return {"invoices": [], "total": 0}
```

## Request Validation

FastAPI uses Pydantic for automatic validation:

```python
from pydantic import BaseModel, Field

class RFCValidationRequest(BaseModel):
    rfc: str = Field(..., min_length=12, max_length=13)

@app.post("/validate/rfc")
async def validate_rfc(request: RFCValidationRequest):
    # request.rfc is already validated
    is_valid = rfc_service.validate(request.rfc)
    return {"valid": is_valid}
```

### Validation Errors

FastAPI returns automatic error responses:

```json
{
  "detail": [
    {
      "loc": ["body", "rfc"],
      "msg": "ensure this value has at least 12 characters",
      "type": "value_error.any_str.min_length"
    }
  ]
}
```

## Response Models

Define response structure with Pydantic:

```python
from pydantic import BaseModel
from typing import List, Optional

class HealthResponse(BaseModel):
    status: str
    timestamp: str
    version: str
    models_loaded: bool
    ocr_available: bool

@app.get("/health", response_model=HealthResponse)
async def health_check():
    return HealthResponse(
        status="healthy",
        timestamp=datetime.utcnow().isoformat(),
        version="0.1.0",
        models_loaded=True,
        ocr_available=True
    )
```

## Error Handling

### HTTP Exceptions

```python
from fastapi import HTTPException

@app.post("/extract")
async def extract_invoice(file: UploadFile):
    if not file.filename.endswith(".pdf"):
        raise HTTPException(
            status_code=400,
            detail="El archivo debe ser un PDF"  # Spanish error
        )
    ...
```

### Custom Exception Handler

```python
from fastapi import Request
from fastapi.responses import JSONResponse

@app.exception_handler(ExtractionError)
async def extraction_error_handler(request: Request, exc: ExtractionError):
    return JSONResponse(
        status_code=422,
        content={
            "error": "extraction_failed",
            "message": "No se pudo extraer datos del PDF",  # Spanish
            "details": str(exc)
        }
    )
```

## API Router Organization

For larger APIs, use routers:

```python
# api/routes.py
from fastapi import APIRouter

router = APIRouter()

@router.get("/health")
async def health():
    ...

@router.post("/extract")
async def extract():
    ...

# main.py
from fastapi import FastAPI
from api.routes import router

app = FastAPI()
app.include_router(router)
```

## Security: Localhost Binding

For desktop apps, bind only to localhost:

```python
# main.py
import uvicorn

if __name__ == "__main__":
    uvicorn.run(
        "main:app",
        host="127.0.0.1",  # Localhost only!
        port=8000,
        reload=False
    )
```

This ensures:
- Only local applications can access the API
- No network exposure
- Safe for desktop deployment

## CORS Configuration

For Electron apps, configure CORS:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],  # Electron renderer
    allow_methods=["GET", "POST"],
    allow_headers=["*"],
)
```

## Testing API Endpoints

### Using pytest and httpx

```python
import pytest
from httpx import AsyncClient
from main import app

@pytest.mark.asyncio
async def test_health_endpoint():
    async with AsyncClient(app=app, base_url="http://test") as client:
        response = await client.get("/health")

    assert response.status_code == 200
    assert response.json()["status"] == "healthy"
```

### Using TestClient (sync)

```python
from fastapi.testclient import TestClient
from main import app

def test_health():
    client = TestClient(app)
    response = client.get("/health")
    assert response.status_code == 200
```
