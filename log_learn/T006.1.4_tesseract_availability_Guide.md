# T006.1.4 Learning Guide: Tesseract OCR Detection

## Overview

This guide explains how to detect and verify Tesseract OCR availability in a Python application, which is critical for invoice processing systems that need to handle scanned documents.

## What is Tesseract?

Tesseract is an open-source OCR (Optical Character Recognition) engine that:
- Converts images to text
- Supports 100+ languages including Spanish
- Is the standard for Python-based OCR solutions
- Requires separate installation from application code

## Key Concepts

### 1. Finding Executable Path

```python
import shutil
import os

def _get_tesseract_path():
    # Method 1: Check if in system PATH
    path = shutil.which("tesseract")
    if path:
        return path

    # Method 2: Check common Windows locations
    windows_paths = [
        "C:\\Program Files\\Tesseract-OCR\\tesseract.exe",
        "C:\\Program Files (x86)\\Tesseract-OCR\\tesseract.exe",
    ]
    for path in windows_paths:
        if os.path.exists(path):
            return path

    return None
```

**Why two methods?**
- Linux/macOS: Tesseract is typically in PATH after installation
- Windows: Often installed in Program Files, not always in PATH

### 2. Getting Tesseract Version

```python
import subprocess

def get_tesseract_version():
    tesseract_path = _get_tesseract_path()
    if not tesseract_path:
        return None

    try:
        result = subprocess.run(
            [tesseract_path, "--version"],
            capture_output=True,
            text=True,
            timeout=5,
        )
        # Parse output: "tesseract 5.3.0\n..."
        # Extract version string
        ...
    except (subprocess.TimeoutExpired, OSError):
        return None
```

**Key practices:**
- Always use `timeout` to prevent hanging
- Use `capture_output=True` instead of deprecated `stdout=PIPE`
- Handle both stdout and stderr (Tesseract outputs to stderr!)

### 3. Checking Language Support

```python
def check_spanish_language_available():
    tesseract_path = _get_tesseract_path()
    if not tesseract_path:
        return False

    result = subprocess.run(
        [tesseract_path, "--list-langs"],
        capture_output=True,
        text=True,
        timeout=5,
    )
    languages = result.stdout.lower().split()
    return "spa" in languages
```

Language codes:
- `spa` - Spanish
- `eng` - English
- `spa_old` - Old Spanish

### 4. Cross-Platform Considerations

| Platform | Default Path | Installation Method |
|----------|--------------|---------------------|
| Windows | `C:\Program Files\Tesseract-OCR\` | Windows Installer |
| Linux | `/usr/bin/tesseract` | `apt install tesseract-ocr` |
| macOS | `/usr/local/bin/tesseract` | `brew install tesseract` |

### 5. Testing with Mocks

```python
from unittest.mock import patch

def test_detects_tesseract_in_path():
    with patch('shutil.which') as mock_which:
        mock_which.return_value = "/usr/bin/tesseract"
        result = check_ocr_available()
        assert result is True
```

Mock subprocess for version check:
```python
with patch('subprocess.run') as mock_run:
    mock_run.return_value.stdout = "tesseract 5.3.0"
    version = get_tesseract_version()
    assert version == "5.3.0"
```

## Best Practices

1. **Graceful Degradation**: Return False, don't raise exceptions
2. **Timeout All Subprocess Calls**: Prevent hanging
3. **Cache Results**: OCR availability rarely changes during runtime
4. **Check Language Packs**: Spanish (spa) required for Mexican invoices
5. **Cross-Platform Paths**: Check multiple common locations

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| False negative | Not in PATH | Check common install paths |
| Timeout | Slow disk | Increase timeout |
| Wrong version | Multiple installs | Use explicit path from config |
| Missing language | Not installed | `apt install tesseract-ocr-spa` |
