# T005.3 Learning Guide: Database Seed Data

## Overview
This guide covers best practices for creating and managing seed data in SQLite databases for development and testing.

## What is Seed Data?

Seed data is initial data loaded into a database for:
- Development testing
- Demo environments
- Integration testing
- Application bootstrapping

## Seed Data Best Practices

### 1. Use Meaningful Test Data
```sql
-- Bad: Generic data
INSERT INTO vendors (id, rfc, business_name) VALUES ('1', 'XXX', 'Test');

-- Good: Realistic data
INSERT INTO vendors (id, rfc, business_name, address)
VALUES (
    'vendor-001-uuid',
    'ABC123456789',
    'Tecnología Avanzada S.A. de C.V.',
    'Av. Insurgentes Sur 1234, CDMX'
);
```

### 2. Cover All States
```sql
-- Invoice in each processing state
INSERT INTO invoices (..., state, ...) VALUES (..., 'UPLOADED', ...);
INSERT INTO invoices (..., state, ...) VALUES (..., 'EXTRACTED', ...);
INSERT INTO invoices (..., state, ...) VALUES (..., 'VALIDATED', ...);
INSERT INTO invoices (..., state, ...) VALUES (..., 'POSTED', ...);
```

### 3. Maintain Referential Integrity
```sql
-- First: Create vendor
INSERT INTO vendors (id, rfc, ...) VALUES ('vendor-001-uuid', ...);

-- Then: Create invoice referencing vendor
INSERT INTO invoices (id, vendor_id, ...) VALUES ('invoice-001-uuid', 'vendor-001-uuid', ...);
```

### 4. Use Consistent ID Formats
```sql
-- Pattern: {entity}-{number}-uuid
'vendor-001-uuid'
'invoice-002-uuid'
'item-003-uuid'
```

## Mexican RFC Format

### Persona Moral (Company)
12 characters: `ABC123456789`
- 3 letters (company initials)
- 6 digits (founding date YYMMDD)
- 3 alphanumeric (homoclave)

### Persona Física (Individual)
13 characters: `GARO850101ABC`
- 4 letters (name initials)
- 6 digits (birthdate YYMMDD)
- 3 alphanumeric (homoclave)

## Seed Data Patterns

### 1. Base Entities First
```sql
-- Order matters for FK constraints
-- 1. Independent tables (vendors)
INSERT INTO vendors ...;

-- 2. Dependent tables (invoices reference vendors)
INSERT INTO invoices ...;

-- 3. Child tables (line_items reference invoices)
INSERT INTO line_items ...;
```

### 2. Comprehensive Related Data
```sql
-- For one "complete" invoice, include:
-- - The invoice record
-- - Associated line items
-- - Extraction results
-- - ContPAQi entry (if posted)
```

### 3. Edge Cases
```sql
-- Include edge cases in seed data
-- - Invoice with NULL vendor_id (not yet extracted)
-- - Scanned vs text-based invoices
-- - High and low confidence extractions
-- - Failed ContPAQi posting
```

## Loading Seed Data

### SQLite Command Line
```bash
# Create database and load schema
sqlite3 database.db < migrations/001_initial_schema.sql

# Load seed data
sqlite3 database.db < seed/sample_data.sql
```

### Python Script
```python
import sqlite3

def load_seed_data(db_path):
    conn = sqlite3.connect(db_path)

    with open('migrations/001_initial_schema.sql') as f:
        conn.executescript(f.read())

    with open('seed/sample_data.sql') as f:
        conn.executescript(f.read())

    conn.commit()
    conn.close()
```

### Idempotent Loading
```sql
-- Use INSERT OR IGNORE for re-runnable seeds
INSERT OR IGNORE INTO vendors (id, rfc, ...)
VALUES ('vendor-001-uuid', 'ABC123456789', ...);

-- Or DELETE before INSERT
DELETE FROM vendors WHERE id = 'vendor-001-uuid';
INSERT INTO vendors (id, rfc, ...) VALUES ('vendor-001-uuid', ...);
```

## Testing with Seed Data

### Fixture Pattern
```python
@pytest.fixture
def db_with_seed():
    """Create database with schema and seed."""
    conn = sqlite3.connect(':memory:')
    conn.executescript(schema_sql)
    conn.executescript(seed_sql)
    yield conn
    conn.close()

def test_vendor_count(db_with_seed):
    cursor = db_with_seed.execute("SELECT COUNT(*) FROM vendors")
    assert cursor.fetchone()[0] == 4
```

### Validation Tests
```python
def test_rfc_format(db_with_seed):
    """Verify RFC values are valid."""
    cursor = db_with_seed.execute("SELECT rfc FROM vendors")
    for (rfc,) in cursor:
        assert 12 <= len(rfc) <= 13

def test_state_values(db_with_seed):
    """Verify state values are valid."""
    valid_states = {'UPLOADED', 'EXTRACTED', 'VALIDATED', 'POSTED'}
    cursor = db_with_seed.execute("SELECT DISTINCT state FROM invoices")
    for (state,) in cursor:
        assert state in valid_states
```
