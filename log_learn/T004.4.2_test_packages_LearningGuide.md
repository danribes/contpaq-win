# T004.4.2 Learning Guide: .NET Testing Packages

## Overview
This guide covers the essential testing packages for .NET test projects: xUnit, Moq, FluentAssertions, and code coverage tools.

## Key Packages

### 1. xUnit
The most popular .NET testing framework.

```xml
<PackageReference Include="xunit" Version="2.6.4" />
<PackageReference Include="xunit.runner.visualstudio" Version="2.5.6" />
<PackageReference Include="Microsoft.NET.Test.Sdk" Version="17.8.0" />
```

#### Key Features
```csharp
// Fact - single test
[Fact]
public void Should_Add_Numbers()
{
    var result = Calculator.Add(2, 3);
    Assert.Equal(5, result);
}

// Theory - parameterized test
[Theory]
[InlineData(1, 2, 3)]
[InlineData(0, 0, 0)]
[InlineData(-1, 1, 0)]
public void Should_Add_Various_Numbers(int a, int b, int expected)
{
    var result = Calculator.Add(a, b);
    Assert.Equal(expected, result);
}
```

### 2. Moq
The most popular mocking framework for .NET.

```xml
<PackageReference Include="Moq" Version="4.20.70" />
```

#### Key Features
```csharp
// Create mock
var mockRepository = new Mock<IVendorRepository>();

// Setup behavior
mockRepository
    .Setup(r => r.GetByRfc("ABC123"))
    .ReturnsAsync(new Vendor { Rfc = "ABC123", Name = "Test Vendor" });

// Setup with callback
mockRepository
    .Setup(r => r.Create(It.IsAny<Vendor>()))
    .ReturnsAsync((Vendor v) => v)
    .Callback<Vendor>(v => Console.WriteLine($"Created: {v.Name}"));

// Verify calls
mockRepository.Verify(r => r.GetByRfc("ABC123"), Times.Once);
mockRepository.Verify(r => r.Create(It.IsAny<Vendor>()), Times.Never);

// Get mock object
var repository = mockRepository.Object;
```

#### Common Patterns
```csharp
// Match any argument
It.IsAny<string>()

// Match specific condition
It.Is<string>(s => s.Length > 0)

// Setup sequence
mockService
    .SetupSequence(s => s.GetNext())
    .Returns("First")
    .Returns("Second")
    .Throws<InvalidOperationException>();

// Verify parameter
mockService.Verify(s => s.Process(
    It.Is<Request>(r => r.Id == expectedId)));
```

### 3. FluentAssertions
Expressive assertion library with readable syntax.

```xml
<PackageReference Include="FluentAssertions" Version="6.12.0" />
```

#### Key Features
```csharp
using FluentAssertions;

// String assertions
name.Should().NotBeNullOrEmpty();
name.Should().StartWith("Hello");
name.Should().Contain("world");

// Numeric assertions
count.Should().BePositive();
count.Should().BeInRange(1, 10);
result.Should().BeApproximately(3.14, 0.01);

// Collection assertions
list.Should().NotBeEmpty();
list.Should().HaveCount(5);
list.Should().Contain("item");
list.Should().BeInAscendingOrder();
list.Should().OnlyContain(x => x.Length > 0);

// Object assertions
vendor.Should().NotBeNull();
vendor.Should().BeEquivalentTo(expected);
vendor.Name.Should().Be("Expected Name");

// Exception assertions
action.Should().Throw<ArgumentException>()
    .WithMessage("*invalid*");

action.Should().NotThrow();
```

## Package Configuration

### PrivateAssets
Prevents transitive dependency:
```xml
<PackageReference Include="xunit.runner.visualstudio" Version="2.5.6">
  <PrivateAssets>all</PrivateAssets>
  <IncludeAssets>runtime; build; native; contentfiles; analyzers; buildtransitive</IncludeAssets>
</PackageReference>
```

### Why These Settings?
- **xunit.runner.visualstudio**: Only needed at test runtime
- **coverlet.collector**: Only needed during test execution
- Prevents these packages from being included in consuming projects

## Testing Best Practices

### AAA Pattern
```csharp
[Fact]
public async Task CreateVendor_WithValidData_ReturnsVendor()
{
    // Arrange
    var mockRepo = new Mock<IVendorRepository>();
    mockRepo.Setup(r => r.Create(It.IsAny<Vendor>()))
        .ReturnsAsync((Vendor v) => v);
    var service = new VendorService(mockRepo.Object);
    var request = new CreateVendorRequest { Rfc = "ABC123" };

    // Act
    var result = await service.CreateAsync(request);

    // Assert
    result.Should().NotBeNull();
    result.Rfc.Should().Be("ABC123");
}
```

### Test Naming Convention
```
MethodName_Condition_ExpectedResult

Examples:
- GetByRfc_WhenExists_ReturnsVendor
- CreateAsync_WithInvalidRfc_ThrowsValidationException
- Process_WhenServiceDown_ReturnsError
```

## Common Patterns

### Test Data Builder
```csharp
public class VendorBuilder
{
    private string _rfc = "DEFAULT123";
    private string _name = "Default Vendor";

    public VendorBuilder WithRfc(string rfc)
    {
        _rfc = rfc;
        return this;
    }

    public VendorBuilder WithName(string name)
    {
        _name = name;
        return this;
    }

    public Vendor Build() => new Vendor
    {
        Rfc = _rfc,
        Name = _name
    };
}

// Usage
var vendor = new VendorBuilder()
    .WithRfc("ABC123")
    .WithName("Test Company")
    .Build();
```

## Running Tests

```bash
# Run all tests
dotnet test

# Run with verbosity
dotnet test -v normal

# Run specific test
dotnet test --filter "MethodName=CreateVendor"

# Run with coverage
dotnet test --collect:"XPlat Code Coverage"

# Watch mode
dotnet watch test
```
