# T007.3 Learning Guide: COM Interop in .NET

## Overview

This guide explains how to create COM interop stubs in .NET for Windows-specific SDK integration, specifically for ContPAQi accounting software.

## What is COM Interop?

COM (Component Object Model) is a Windows technology for inter-process communication. COM Interop allows .NET code to call COM components (and vice versa).

## Key Concepts

### 1. COM Object Access Methods

| Method | Description | Use Case |
|--------|-------------|----------|
| Early Binding | Type library import | Best performance |
| Late Binding | Dynamic/reflection | Flexible, slower |
| P/Invoke | Native DLL calls | Low-level access |

### 2. Type Library Import

```csharp
// In .csproj
<ItemGroup>
  <COMReference Include="MyComLibrary">
    <Guid>{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}</Guid>
    <VersionMajor>1</VersionMajor>
    <WrapperTool>tlbimp</WrapperTool>
  </COMReference>
</ItemGroup>
```

### 3. Dynamic COM Access

```csharp
// Late binding with dynamic
dynamic comObject = Activator.CreateInstance(
    Type.GetTypeFromProgID("MyApp.MyClass"));
comObject.DoSomething();
```

### Stub Implementation

```csharp
public class ContPAQiSdk : IContPAQiSdk
{
    private bool _disposed;
    private bool _isInitialized;

    public bool IsInitialized => _isInitialized;

    public bool Initialize()
    {
        // Stub: will use COM interop
        return false;
    }

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    protected virtual void Dispose(bool disposing)
    {
        if (_disposed) return;

        if (disposing)
        {
            Terminate();
        }

        // Release COM objects
        // Marshal.ReleaseComObject(comObj);

        _disposed = true;
    }

    ~ContPAQiSdk()
    {
        Dispose(false);
    }
}
```

## SDK Detection

### Registry Checking

```csharp
public static bool IsSdkInstalled()
{
    try
    {
        // Check 64-bit registry
        using var key = Registry.LocalMachine.OpenSubKey(
            @"SOFTWARE\Company\Product");
        if (key != null) return true;

        // Check 32-bit registry (WOW6432Node)
        using var key32 = Registry.LocalMachine.OpenSubKey(
            @"SOFTWARE\WOW6432Node\Company\Product");
        return key32 != null;
    }
    catch
    {
        return false;
    }
}
```

### File System Checking

```csharp
public static bool IsSdkDllPresent()
{
    var paths = new[]
    {
        @"C:\Program Files (x86)\Company\SDK.dll",
        @"C:\Program Files\Company\SDK.dll"
    };

    return paths.Any(File.Exists);
}
```

## COM Resource Management

### Proper Cleanup

```csharp
// Always release COM objects
if (comObject != null)
{
    Marshal.ReleaseComObject(comObject);
    comObject = null;
}

// For multiple references
while (Marshal.ReleaseComObject(comObject) > 0) { }
```

### Using Statement Pattern

```csharp
public class SdkWrapper : IDisposable
{
    private object? _comObject;

    public void Initialize()
    {
        _comObject = Activator.CreateInstance(
            Type.GetTypeFromProgID("ContPAQi.SDK"));
    }

    public void Dispose()
    {
        if (_comObject != null)
        {
            Marshal.ReleaseComObject(_comObject);
            _comObject = null;
        }
    }
}

// Usage
using var sdk = new SdkWrapper();
sdk.Initialize();
```

## Error Handling

### COM Exception Handling

```csharp
try
{
    var result = comObject.DoSomething();
}
catch (COMException ex)
{
    // HRESULT in ex.ErrorCode
    Console.WriteLine($"COM Error: 0x{ex.ErrorCode:X8}");
}
catch (InvalidCastException)
{
    // Interface not supported
}
catch (UnauthorizedAccessException)
{
    // Permission denied
}
```

## Best Practices

### 1. Interface Abstraction

```csharp
// Good: Interface allows mocking
public class MyService
{
    private readonly IContPAQiSdk _sdk;

    public MyService(IContPAQiSdk sdk)
    {
        _sdk = sdk;
    }
}

// Test with mock
var mock = new Mock<IContPAQiSdk>();
var service = new MyService(mock.Object);
```

### 2. Stub First Development

1. Define interface with all needed methods
2. Create stub implementation returning defaults
3. Write tests against interface
4. Implement real COM calls later

### 3. Thread Safety

```csharp
// COM objects may require STA thread
[STAThread]
static void Main()
{
    // Or use Task with STA
    var task = Task.Factory.StartNew(
        () => UseCom(),
        CancellationToken.None,
        TaskCreationOptions.None,
        new StaTaskScheduler());
}
```
