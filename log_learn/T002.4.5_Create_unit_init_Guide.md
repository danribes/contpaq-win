# Learning Guide: T002.4.5 - Unit Tests Organization

## Unit Tests vs Integration Tests

### Unit Tests

```python
# Test a single function in isolation
def test_calculate_iva():
    result = calculate_iva(1000)
    assert result == 160  # 16% IVA
```

- Test ONE thing at a time
- No external dependencies
- Fast (milliseconds)
- Mocked collaborators

### Integration Tests

```python
# Test multiple components working together
def test_extract_invoice_from_pdf():
    result = extract_invoice(sample_pdf_path)
    assert result.vendor_rfc is not None
    assert result.total > 0
```

- Test component interactions
- May use real dependencies
- Slower (seconds)
- Database, files, network

## Running Tests Selectively

### Run All Tests

```bash
pytest ai-service/tests/
```

### Run Only Unit Tests

```bash
pytest ai-service/tests/unit/
```

### Run Only Integration Tests

```bash
pytest ai-service/tests/integration/
```

### Run by Marker

```python
# Mark slow tests
@pytest.mark.slow
def test_full_extraction():
    pass

# Run without slow tests
# pytest -m "not slow"
```

## Unit Test Best Practices

### 1. Arrange-Act-Assert Pattern

```python
def test_rfc_validation():
    # Arrange
    rfc = "ABC123456789"

    # Act
    result = validate_rfc(rfc)

    # Assert
    assert result.is_valid == True
    assert result.type == "moral"
```

### 2. One Assertion Per Test (When Possible)

```python
# Good - focused tests
def test_rfc_is_valid():
    assert validate_rfc("ABC123456789").is_valid

def test_rfc_type_is_moral():
    assert validate_rfc("ABC123456789").type == "moral"

# Acceptable - related assertions
def test_rfc_validation_returns_correct_result():
    result = validate_rfc("ABC123456789")
    assert result.is_valid
    assert result.type == "moral"
```

### 3. Use Fixtures for Setup

```python
@pytest.fixture
def sample_settings():
    return Settings(HOST="127.0.0.1", PORT=8000)

def test_settings_port(sample_settings):
    assert sample_settings.PORT == 8000
```

### 4. Mock External Dependencies

```python
from unittest.mock import patch, MagicMock

def test_ocr_extraction():
    # Mock pytesseract
    with patch("pytesseract.image_to_string") as mock_ocr:
        mock_ocr.return_value = "FACTURA\nRFC: ABC123"

        result = extract_with_ocr(image_path)

        mock_ocr.assert_called_once()
        assert "FACTURA" in result
```

### 5. Test Edge Cases

```python
def test_rfc_empty_string():
    result = validate_rfc("")
    assert not result.is_valid

def test_rfc_too_short():
    result = validate_rfc("ABC")
    assert not result.is_valid

def test_rfc_too_long():
    result = validate_rfc("ABC12345678901234")
    assert not result.is_valid
```

## Naming Conventions

### Test Files

```
test_<module_name>.py
test_config.py
test_pdf_extractor.py
```

### Test Functions

```python
def test_<what_is_being_tested>_<expected_behavior>():
    pass

def test_validate_rfc_returns_true_for_valid_input():
    pass

def test_validate_rfc_returns_false_for_empty_string():
    pass
```

### Test Classes

```python
class TestRfcValidation:
    def test_valid_moral_rfc(self):
        pass

    def test_valid_fisica_rfc(self):
        pass

    def test_invalid_rfc_too_short(self):
        pass
```
