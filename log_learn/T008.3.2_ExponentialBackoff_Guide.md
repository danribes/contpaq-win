# T008.3.2 Learning Guide: Exponential Backoff

## Overview

Exponential backoff is a standard algorithm for progressively increasing wait times between retry attempts. This guide covers implementing exponential backoff for service restarts.

## Key Concepts

### 1. Exponential Backoff Formula

```
delay = baseDelay × 2^(attemptNumber - 1)
```

| Attempt | Calculation | Delay (base=1s) |
|---------|-------------|-----------------|
| 1 | 1000 × 2^0 | 1000ms (1s) |
| 2 | 1000 × 2^1 | 2000ms (2s) |
| 3 | 1000 × 2^2 | 4000ms (4s) |
| 4 | 1000 × 2^3 | 8000ms (8s) |
| 5 | 1000 × 2^4 | 16000ms (16s) |

### 2. Why Exponential Backoff?

Benefits:
- **Prevents Thundering Herd**: Spaces out retries
- **Gives Time to Recover**: Allows transient issues to resolve
- **Reduces Load**: Less aggressive than constant retry
- **Self-Healing**: Many issues resolve with time

Without backoff:
```
Crash → Restart → Crash → Restart → Crash → ... (immediate loop)
```

With backoff:
```
Crash → Wait 1s → Restart → Wait 2s → Restart → Wait 4s → ...
```

### 3. JavaScript setTimeout

```typescript
setTimeout(() => {
  // Code to run after delay
}, delayMs);
```

Important: setTimeout is non-blocking - execution continues immediately.

## Code Patterns

### Basic Exponential Backoff

```typescript
function calculateBackoffDelay(
  attempt: number,
  baseDelayMs: number
): number {
  return baseDelayMs * Math.pow(2, attempt - 1);
}

// Usage
const delay = calculateBackoffDelay(1, 1000); // 1000ms
const delay2 = calculateBackoffDelay(2, 1000); // 2000ms
const delay3 = calculateBackoffDelay(3, 1000); // 4000ms
```

### With Maximum Cap

```typescript
function calculateBackoffDelay(
  attempt: number,
  baseDelayMs: number,
  maxDelayMs: number = 30000
): number {
  const delay = baseDelayMs * Math.pow(2, attempt - 1);
  return Math.min(delay, maxDelayMs);
}
```

### With Jitter (Randomization)

```typescript
function calculateBackoffDelayWithJitter(
  attempt: number,
  baseDelayMs: number
): number {
  const baseDelay = baseDelayMs * Math.pow(2, attempt - 1);
  // Add random jitter (±20%)
  const jitter = baseDelay * 0.2 * (Math.random() * 2 - 1);
  return Math.round(baseDelay + jitter);
}
```

### Delayed Restart Implementation

```typescript
private handleAutoRestart(service: string): void {
  const restartCount = this.getRestartCount(service);

  // Check limits
  if (restartCount >= this.config.maxRestarts) {
    this.emitMaxRestartsExceeded(service);
    return;
  }

  // Increment count
  this.incrementRestartCount(service);
  const newCount = this.getRestartCount(service);

  // Calculate backoff delay
  const delay = this.config.restartBackoffMs * Math.pow(2, newCount - 1);

  console.log(`[${service}] Restarting in ${delay}ms...`);

  // Emit event with delay info
  this.emitRestartEvent(service, newCount, delay);

  // Schedule restart
  setTimeout(() => {
    this.startService(service).catch(console.error);
  }, delay);
}
```

## Testing Strategies

### 1. Use Jest Fake Timers

```typescript
beforeEach(() => {
  jest.useFakeTimers();
});

afterEach(() => {
  jest.useRealTimers();
});

it('should delay restart by backoff', async () => {
  // Start service
  await manager.startService();

  // Trigger crash
  mockProcess.emit('exit', 1, null);

  // Not restarted immediately
  jest.advanceTimersByTime(500);
  expect(spawnCount).toBe(1);

  // Restarted after delay
  jest.advanceTimersByTime(600);
  expect(spawnCount).toBe(2);
});
```

### 2. Test Progressive Delays

```typescript
it('should increase delay exponentially', async () => {
  await manager.startService();

  // First crash: 1s delay
  processes[0].emit('exit', 1, null);
  jest.advanceTimersByTime(1100);
  expect(spawnCount).toBe(2);

  // Wait for spawn
  jest.advanceTimersByTime(10);

  // Second crash: 2s delay
  processes[1].emit('exit', 1, null);
  jest.advanceTimersByTime(1500);
  expect(spawnCount).toBe(2); // Not yet
  jest.advanceTimersByTime(600);
  expect(spawnCount).toBe(3); // Now restarted
});
```

### 3. Test Event Data

```typescript
it('should include delay in event', async () => {
  const listener = jest.fn();
  manager.on('restart', listener);

  await manager.startService();
  processes[0].emit('exit', 1, null);
  jest.advanceTimersByTime(1100);

  expect(listener).toHaveBeenCalledWith(
    expect.objectContaining({
      delay: 1000,
    })
  );
});
```

## Common Pitfalls

### 1. Forgetting to Use Fake Timers

**Problem**: Tests wait real time (very slow).

**Solution**: Always use `jest.useFakeTimers()` for delay tests.

### 2. Not Advancing Time for Spawn

**Problem**: Process appears stuck after restart.

**Solution**: Advance time for spawn event too:
```typescript
jest.advanceTimersByTime(1100); // Backoff
jest.advanceTimersByTime(10);   // Spawn event
```

### 3. Incorrect Attempt Calculation

**Problem**: Off-by-one errors in backoff.

**Solution**: Be clear about when counting starts:
- Count starts at 0 before first restart? Use `Math.pow(2, count)`
- Count starts at 1 after first restart? Use `Math.pow(2, count - 1)`

### 4. Not Capping Maximum Delay

**Problem**: Delays grow unbounded (2^10 = 1024 seconds).

**Solution**: Add a maximum cap:
```typescript
const delay = Math.min(
  baseDelay * Math.pow(2, count - 1),
  30000 // 30 second max
);
```

## Best Practices

1. **Start Small**: 1 second base is reasonable
2. **Cap Maximum**: Don't let delay grow forever (30s-60s max)
3. **Consider Jitter**: Add randomization for distributed systems
4. **Log Delays**: Include delay in logs and events
5. **Reset on Success**: Reset backoff after stable period
6. **Track Per-Service**: Independent backoff for each service
