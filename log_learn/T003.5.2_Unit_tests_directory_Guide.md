# Learning Guide: T003.5.2 - Create desktop-app/tests/unit/ directory

## Overview

This guide covers organizing unit tests for an Electron/React application with TypeScript.

## Concepts Covered

### 1. Unit Test Directory Structure

Organize tests by feature type:

```
tests/
├── setup.ts           # Global test configuration
├── unit/              # Unit tests (isolated)
│   ├── components/    # React component tests
│   ├── hooks/         # React hooks tests
│   ├── utils/         # Utility function tests
│   └── services/      # Service layer tests
└── e2e/               # End-to-end tests (integration)
```

### 2. Test Setup File (setup.ts)

Global configuration loaded before each test:

```typescript
// tests/setup.ts
import '@testing-library/jest-dom';

// Mock browser APIs not available in jsdom
Object.defineProperty(window, 'matchMedia', {
  writable: true,
  value: jest.fn().mockImplementation((query: string) => ({
    matches: false,
    media: query,
    onchange: null,
    addEventListener: jest.fn(),
    removeEventListener: jest.fn(),
    dispatchEvent: jest.fn(),
  })),
});

// Clear mocks between tests
beforeEach(() => {
  jest.clearAllMocks();
});
```

### 3. Electron IPC Mocks

Mock the electron API for renderer process tests:

```typescript
// Mock window.electron for IPC
Object.defineProperty(window, 'electron', {
  writable: true,
  value: {
    invoke: jest.fn(),    // Request-response
    send: jest.fn(),      // Fire-and-forget
    on: jest.fn(),        // Subscribe
    removeListener: jest.fn(),
  },
});
```

### 4. Browser API Mocks

Mock APIs not available in jsdom:

```typescript
// ResizeObserver
global.ResizeObserver = jest.fn().mockImplementation(() => ({
  observe: jest.fn(),
  unobserve: jest.fn(),
  disconnect: jest.fn(),
}));

// IntersectionObserver
global.IntersectionObserver = jest.fn().mockImplementation(() => ({
  observe: jest.fn(),
  unobserve: jest.fn(),
  disconnect: jest.fn(),
}));
```

## Code Examples

### Component Test Example

```typescript
// tests/unit/components/Button.test.tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { Button } from '@renderer/components/Button';

describe('Button', () => {
  it('renders children correctly', () => {
    render(<Button>Click me</Button>);
    expect(screen.getByText('Click me')).toBeInTheDocument();
  });

  it('calls onClick when clicked', () => {
    const handleClick = jest.fn();
    render(<Button onClick={handleClick}>Click me</Button>);

    fireEvent.click(screen.getByText('Click me'));
    expect(handleClick).toHaveBeenCalledTimes(1);
  });

  it('is disabled when disabled prop is true', () => {
    render(<Button disabled>Click me</Button>);
    expect(screen.getByText('Click me')).toBeDisabled();
  });
});
```

### Hook Test Example

```typescript
// tests/unit/hooks/useTranslation.test.tsx
import { renderHook } from '@testing-library/react';
import { useTranslation } from '@renderer/i18n';
import { I18nProvider } from '@renderer/i18n';

const wrapper = ({ children }: { children: React.ReactNode }) => (
  <I18nProvider>{children}</I18nProvider>
);

describe('useTranslation', () => {
  it('returns translation function', () => {
    const { result } = renderHook(() => useTranslation(), { wrapper });
    expect(typeof result.current.t).toBe('function');
  });

  it('translates keys correctly', () => {
    const { result } = renderHook(() => useTranslation(), { wrapper });
    expect(result.current.t('buttons.save')).toBe('Guardar');
  });

  it('returns key when translation not found', () => {
    const { result } = renderHook(() => useTranslation(), { wrapper });
    expect(result.current.t('nonexistent.key')).toBe('nonexistent.key');
  });
});
```

### Utility Test Example

```typescript
// tests/unit/utils/format.test.ts
import { formatCurrency, formatRFC, formatDate } from '@renderer/utils/format';

describe('formatCurrency', () => {
  it('formats positive amounts', () => {

  it('uppercases RFC', () => {

```

### Service Test Example

```typescript
// tests/unit/services/aiService.test.ts
import { extractInvoice, checkHealth } from '@renderer/services/aiService';

// Mock electron IPC
const mockInvoke = jest.fn();
window.electron = { invoke: mockInvoke } as any;

describe('aiService', () => {
  beforeEach(() => {
    mockInvoke.mockClear();
  });

  describe('checkHealth', () => {
    it('returns health status', async () => {
      mockInvoke.mockResolvedValue({
        status: 'healthy',
        version: '1.0.0',
      });

      const result = await checkHealth();

      expect(mockInvoke).toHaveBeenCalledWith('ai:health');
      expect(result.status).toBe('healthy');
    });

    it('handles errors', async () => {
      mockInvoke.mockRejectedValue(new Error('Connection failed'));

      await expect(checkHealth()).rejects.toThrow('Connection failed');
    });
  });
});
```

## Best Practices

### 1. Test File Naming

```
src/
├── components/
│   ├── Button.tsx
│   └── Button.test.tsx    # Co-located (optional)
tests/
└── unit/
    └── components/
        └── Button.test.tsx  # Separate directory
```

### 2. Test Organization

```typescript
describe('ComponentName', () => {
  // Setup
  beforeEach(() => {});
  afterEach(() => {});

  // Group related tests
  describe('rendering', () => {
    it('renders correctly', () => {});
    it('renders with props', () => {});
  });

  describe('interactions', () => {
    it('handles click', () => {});
    it('handles input', () => {});
  });

  describe('edge cases', () => {
    it('handles empty data', () => {});
    it('handles errors', () => {});
  });
});
```

### 3. Mock Organization

```typescript
// tests/mocks/electron.ts
export const mockElectron = {
  invoke: jest.fn(),
  send: jest.fn(),
  on: jest.fn(),
  removeListener: jest.fn(),
};

// In test file
import { mockElectron } from '../mocks/electron';
window.electron = mockElectron;
```

### 4. Testing Library Best Practices

```typescript
// ✅ Good - Query by role/text (accessible)
screen.getByRole('button', { name: 'Guardar' });
screen.getByText('Guardar');
screen.getByLabelText('Nombre');

// ❌ Avoid - Query by test ID (implementation detail)
screen.getByTestId('save-button');

// ❌ Avoid - Query by class/tag (brittle)
container.querySelector('.btn-primary');
```

## Directory Purpose Reference

| Directory | Purpose | Examples |
|-----------|---------|----------|
| `components/` | React component UI tests | Button, Modal, Form |
| `hooks/` | React custom hooks tests | useTranslation, useInvoice |
| `utils/` | Pure function tests | formatCurrency, validateRFC |
| `services/` | API client tests | aiService, bridgeService |

## Summary

Organizing unit tests involves:
1. ✅ Separate directories by feature type
2. ✅ Global setup file for common configuration
3. ✅ Mock browser and Electron APIs
4. ✅ Use @testing-library best practices
5. ✅ Clear test organization with describe blocks
6. ✅ Document test purpose in __init__.py files
