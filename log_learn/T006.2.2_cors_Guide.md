# T006.2.2 Learning Guide: CORS Configuration in FastAPI

## Overview

This guide explains how to configure Cross-Origin Resource Sharing (CORS) in FastAPI applications, with a focus on security-first localhost-only configurations.

## What is CORS?

CORS is a security feature that controls which domains can access your API from a browser. By default, browsers block cross-origin requests - CORS allows you to selectively enable them.

## Key Concepts

### 1. Same-Origin Policy

Browsers enforce that JavaScript can only make requests to the same origin (protocol + domain + port). CORS relaxes this restriction.

### 2. Preflight Requests

For "complex" requests, browsers send an OPTIONS request first to check permissions:
- Non-simple methods (PUT, DELETE)
- Custom headers
- Content-Type other than form data

### 3. CORS Headers

| Header | Purpose |
|--------|---------|
| Access-Control-Allow-Origin | Allowed origins |
| Access-Control-Allow-Methods | Allowed HTTP methods |
| Access-Control-Allow-Headers | Allowed request headers |
| Access-Control-Allow-Credentials | Allow cookies/auth |

## FastAPI CORS Configuration

### Basic Setup

```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### Security-First (Localhost Only)

```python
ALLOWED_ORIGINS = [
    "http://localhost:3000",
    "http://localhost:8080",
    "http://127.0.0.1:3000",
    "http://127.0.0.1:8080",
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=ALLOWED_ORIGINS,
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS"],
    allow_headers=["*"],
)
```

### Never Use in Production

```python
# DANGEROUS - allows any origin
allow_origins=["*"]
```

## Best Practices

### 1. Explicit Origins

```python
# Good: Specific origins
ALLOWED_ORIGINS = ["http://localhost:3000"]

# Bad: Wildcard
ALLOWED_ORIGINS = ["*"]
```

### 2. Environment-Based Config

```python
import os

if os.getenv("ENV") == "production":
    ALLOWED_ORIGINS = ["https://myapp.com"]
else:
    ALLOWED_ORIGINS = ["http://localhost:3000"]
```

### 3. Credentials Handling

```python
# If using cookies/auth headers
allow_credentials=True

# Note: Cannot use allow_origins=["*"] with credentials=True
```

## Testing CORS

### Test Middleware Exists

```python
def test_cors_middleware_configured():
    middleware_classes = [m.cls.__name__ for m in app.user_middleware]
    assert "CORSMiddleware" in middleware_classes
```

### Test CORS Headers

```python
def test_cors_headers_present(client):
    response = client.get(
        "/health",
        headers={"Origin": "http://localhost:3000"}
    )
    assert "access-control-allow-origin" in response.headers
```

### Test Preflight

```python
def test_preflight_request(client):
    response = client.options(
        "/api/data",
        headers={
            "Origin": "http://localhost:3000",
            "Access-Control-Request-Method": "POST",
        }
    )
    assert response.status_code == 200
```

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| CORS error in browser | Origin not in allow_origins | Add origin to list |
| Credentials not sent | allow_credentials=False | Set to True |
| Preflight fails | OPTIONS not handled | CORSMiddleware handles this |
| Wildcard with credentials | Invalid combination | Use explicit origins |
