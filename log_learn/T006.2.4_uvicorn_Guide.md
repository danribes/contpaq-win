# T006.2.4 Learning Guide: Uvicorn Production Configuration

## Overview

This guide explains how to configure uvicorn for production deployment of FastAPI applications, with special considerations for AI/ML workloads.

## What is Uvicorn?

Uvicorn is an ASGI (Asynchronous Server Gateway Interface) server implementation. It runs FastAPI applications and handles HTTP requests.

## Key Configuration Options

### 1. Host and Port

```python
UVICORN_CONFIG = {
    "host": "127.0.0.1",  # Localhost only (secure)
    "port": 8000,
}
```

| Host Value | Use Case |
|------------|----------|
| `127.0.0.1` | Local only (secure) |
| `0.0.0.0` | All interfaces (exposed) |
| Specific IP | Bind to specific interface |

### 2. Worker Configuration

```python
"workers": 1,  # Number of worker processes
```

**For AI Services:**
- Use `workers: 1` because AI models share memory
- Multiple workers = multiple model copies = OOM

**For Regular APIs:**
```python
"workers": os.cpu_count() or 1,  # One per CPU core
```

### 3. Timeout Settings

```python
"timeout_keep_alive": 120,  # Seconds before closing idle connection
```

**AI Considerations:**
- OCR processing: 10-60 seconds
- Model inference: 5-30 seconds
- PDF parsing: 1-10 seconds
- Set timeout > longest expected operation

### 4. Logging

```python
"log_level": "info",     # critical, error, warning, info, debug, trace
"access_log": True,      # Log each request
```

### 5. Performance Limits

```python
"limit_concurrency": 10,     # Max concurrent connections
"limit_max_requests": 1000,  # Restart worker after N requests
```

## Complete Production Configuration

```python
import os

IS_PRODUCTION = os.getenv("ENV") == "production"

UVICORN_CONFIG = {
    "app": "main:app",
    "host": "127.0.0.1",
    "port": int(os.getenv("PORT", 8000)),
    "workers": 1,
    "log_level": "info" if IS_PRODUCTION else "debug",
    "access_log": True,
    "timeout_keep_alive": 120,
    "limit_concurrency": 10,
    "limit_max_requests": 1000,
    "reload": not IS_PRODUCTION,
}
```

## Running Uvicorn

### Command Line

```bash
# Development
uvicorn main:app --reload --host 127.0.0.1 --port 8000

# Production
uvicorn main:app --host 127.0.0.1 --port 8000 --workers 1 --log-level info
```

### Programmatic

```python
import uvicorn
from uvicorn_config import UVICORN_CONFIG

uvicorn.run(**UVICORN_CONFIG)
```

### With Config File

```bash
uvicorn main:app --config uvicorn_config.py
```

## Best Practices

### 1. Single Worker for AI

```python
# WRONG for AI services
"workers": os.cpu_count()  # Each worker loads own model!

# CORRECT for AI services
"workers": 1  # Share model memory
```

### 2. Localhost Binding

```python
# Security: Don't expose directly
"host": "127.0.0.1"

# Use reverse proxy (nginx) for external access
```

### 3. Environment-Based Config

```python
import os

UVICORN_CONFIG = {
    "log_level": os.getenv("LOG_LEVEL", "info"),
    "reload": os.getenv("ENV") != "production",
}
```

### 4. Graceful Shutdown

Uvicorn handles SIGTERM gracefully by default. For additional cleanup, use FastAPI shutdown events.

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| Port in use | Previous instance | `lsof -i :8000` and kill |
| OOM with multiple workers | Each worker loads model | Use `workers: 1` |
| Connection reset | Timeout too short | Increase `timeout_keep_alive` |
| Slow startup | Model loading | Normal for AI; consider warmup |

## Production Checklist

- [ ] Host bound to localhost (127.0.0.1)
- [ ] Workers = 1 for AI workloads
- [ ] Timeout adequate for longest operation
- [ ] Log level = info (not debug)
- [ ] Reload = False
- [ ] Reverse proxy configured (nginx)
