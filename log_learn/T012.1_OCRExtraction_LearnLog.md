## Key Learnings

### 1. PDF to Image Conversion with PyMuPDF
Converting PDF pages to images for OCR:

```python
import fitz  # PyMuPDF
from PIL import Image

doc = fitz.open("file.pdf")
page = doc[0]

# Calculate zoom for desired DPI (default PDF is 72 DPI)
dpi = 300
zoom = dpi / 72.0
matrix = fitz.Matrix(zoom, zoom)

# Render page to pixmap
pixmap = page.get_pixmap(matrix=matrix)

# Convert to PIL Image
image = Image.frombytes(
    "RGB",
    [pixmap.width, pixmap.height],
    pixmap.samples
)
```

### 2. DPI Selection for OCR
**Why 300 DPI?**
- Tesseract recommends 300 DPI for optimal accuracy
- Lower DPI (72-150): Faster but less accurate
- Higher DPI (400+): Diminishing returns, slower processing
- 300 DPI is the sweet spot for invoice text

### 3. Tesseract Output Modes
pytesseract offers several output modes:

```python
import pytesseract

# Simple string output
text = pytesseract.image_to_string(image, lang='spa')

# Detailed output with bounding boxes
data = pytesseract.image_to_data(image, lang='spa', output_type=Output.DICT)
# Returns: {
#   'text': ['word1', 'word2', ...],
#   'left': [x1, x2, ...],      # x coordinate
#   'top': [y1, y2, ...],       # y coordinate
#   'width': [w1, w2, ...],     # box width
#   'height': [h1, h2, ...],    # box height
#   'conf': [95, 88, ...],      # confidence (0-100, -1 for no text)
#   'level': [1, 5, ...],       # hierarchy level
# }

# HOCR format (HTML with positions)
hocr = pytesseract.image_to_pdf_or_hocr(image, extension='hocr')
```

### 4. Tesseract Confidence Scores
Understanding confidence values:
- **0-100**: Confidence percentage (higher = more certain)
- **-1**: Special value meaning "no text detected"
- **> 60**: Generally reliable
- **< 30**: Should be flagged for review

```python
# Filter low-confidence results
for i, text in enumerate(data['text']):
    confidence = data['conf'][i]
    if confidence == -1 or not text.strip():
        continue  # Skip empty/invalid
    if confidence < 30:
        print(f"Low confidence: {text} ({confidence}%)")
```

### 6. Bounding Box Coordinate Conversion
Tesseract returns coordinates as (left, top, width, height).
Converting to (x0, y0, x1, y1) format:

```python
x = data['left'][i]      # x0 (left edge)
y = data['top'][i]       # y0 (top edge)
w = data['width'][i]     # width
h = data['height'][i]    # height

bbox = {
    'x0': float(x),
    'y0': float(y),
    'x1': float(x + w),  # right edge
    'y1': float(y + h),  # bottom edge
}
```

### 7. Error Handling Pattern
Consistent error handling across services:

```python
def process_pdf(self, pdf_path):
    path = Path(pdf_path) if isinstance(pdf_path, str) else pdf_path

    if not path.exists():
        raise FileNotFoundError(f"PDF file not found: {path}")

    try:
        doc = fitz.open(str(path))
    except Exception as e:
        raise ValueError(f"Invalid PDF file: {path}. Error: {e}")

    try:
        # Process document
        return self._extract(doc)
    finally:
        doc.close()
```
