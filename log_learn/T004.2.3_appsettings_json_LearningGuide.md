# T004.2.3 Learning Guide: ASP.NET Core appsettings.json

## Overview
This guide covers ASP.NET Core configuration with appsettings.json, focusing on Serilog structured logging configuration.

## Key Concepts

### 1. Configuration Hierarchy
ASP.NET Core loads configuration from multiple sources in order:
```
1. appsettings.json
2. appsettings.{Environment}.json
3. User secrets (Development)
4. Environment variables
5. Command-line arguments
```

Later sources override earlier ones.

### 2. Serilog JSON Configuration
Serilog can be fully configured in appsettings.json:

```json
{
  "Serilog": {
    "Using": ["Serilog.Sinks.Console"],
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft": "Warning"
      }
    },
    "WriteTo": [
      { "Name": "Console" }
    ]
  }
}
```

### 3. Configuration Sections Explained

#### Using
Declares which Serilog sink assemblies to load:
```json
"Using": [
  "Serilog.Sinks.Console",
  "Serilog.Sinks.File"
]
```

#### MinimumLevel
Controls log verbosity:
- **Default**: Base level for all loggers
- **Override**: Per-namespace overrides

```json
"MinimumLevel": {
  "Default": "Information",
  "Override": {
    "Microsoft": "Warning",        // Framework logs
    "System": "Warning",           // System logs
    "MyApp.Verbose": "Debug"       // App-specific
  }
}
```

Log levels (least to most restrictive):
1. Verbose
2. Debug
3. Information
4. Warning
5. Error
6. Fatal

#### WriteTo
Configures output sinks:
```json
"WriteTo": [
  {
    "Name": "Console",
    "Args": {
      "outputTemplate": "[{Timestamp:HH:mm:ss}] {Message}{NewLine}"
    }
  },
  {
    "Name": "File",
    "Args": {
      "path": "logs/app-.log",
      "rollingInterval": "Day"
    }
  }
]
```

#### Enrich
Adds contextual information to all log events:
```json
"Enrich": [
  "FromLogContext",
  "WithMachineName",
  "WithThreadId"
]
```

### 4. Reading Configuration in Code
```csharp
builder.Host.UseSerilog((context, services, configuration) =>
    configuration.ReadFrom.Configuration(context.Configuration));
```

`context.Configuration` includes appsettings.json and all other config sources.

### 5. AllowedHosts
Security setting for host filtering:
```json
"AllowedHosts": "*"                    // Allow all hosts
"AllowedHosts": "localhost;127.0.0.1"  // Specific hosts only
```

## Best Practices

### 1. Log Level Strategy
| Source | Recommended Level | Reason |
|--------|------------------|--------|
| Microsoft | Warning | Reduce framework noise |
| Microsoft.Hosting.Lifetime | Information | See startup/shutdown |
| System | Warning | Reduce system noise |
| Your App | Information | Full application visibility |
| Sensitive Areas | Debug | Detailed troubleshooting |

### 2. File Sink Configuration
```json
{
  "Name": "File",
  "Args": {
    "path": "logs/app-.log",           // - replaced with date
    "rollingInterval": "Day",          // Daily log files
    "retainedFileCountLimit": 30,      // Keep 30 days
    "fileSizeLimitBytes": 100000000,   // 100MB limit
    "rollOnFileSizeLimit": true        // Create new file at limit
  }
}
```

### 3. Output Templates
Common template tokens:
- `{Timestamp}` - Event time
- `{Level}` - Log level
- `{Message}` - Log message
- `{Exception}` - Exception details
- `{Properties}` - All properties
- `{NewLine}` - Line break

Example templates:
```
# Console (compact)
"[{Timestamp:HH:mm:ss} {Level:u3}] {Message:lj}{NewLine}{Exception}"

# File (detailed)
"{Timestamp:yyyy-MM-dd HH:mm:ss.fff zzz} [{Level:u3}] {Message:lj}{NewLine}{Exception}"
```

### 4. Environment-Specific Configuration
Create environment-specific files:
- `appsettings.json` - Base configuration
- `appsettings.Development.json` - Development overrides
- `appsettings.Production.json` - Production overrides

```json
// appsettings.Development.json
{
  "Serilog": {
    "MinimumLevel": {
      "Default": "Debug"
    }
  }
}
```

## Common Patterns

### Conditional Enrichment
```json
"Enrich": [
  "FromLogContext",
  {
    "Name": "WithProperty",
    "Args": {
      "name": "Application",
      "value": "ContPAQWinBridge"
    }
  }
]
```

### Multiple File Sinks
```json
"WriteTo": [
  {
    "Name": "File",
    "Args": {
      "path": "logs/all-.log",
      "rollingInterval": "Day"
    }
  },
  {
    "Name": "File",
    "Args": {
      "path": "logs/errors-.log",
      "rollingInterval": "Day",
      "restrictedToMinimumLevel": "Error"
    }
  }
]
```
