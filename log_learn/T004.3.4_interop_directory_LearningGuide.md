# T004.3.4 Learning Guide: COM Interop in .NET

## Overview
This guide covers COM (Component Object Model) interop in .NET for integrating with legacy Windows COM components like ContPAQi SDK.

## Key Concepts

### 1. What is COM Interop?
COM Interop allows .NET code to call COM components and vice versa:

```
.NET Application → COM Interop Layer → COM Component (ContPAQi SDK)
```

### 2. System.Runtime.InteropServices
The primary namespace for COM interop:

```csharp
using System.Runtime.InteropServices;

// Import COM type library
[ComImport]
[Guid("00000000-0000-0000-0000-000000000000")]
public interface ISomeComInterface
{
    void SomeMethod();
}

// P/Invoke for native DLL
[DllImport("somelib.dll")]
public static extern int SomeFunction(string param);
```

### 3. COM Object Lifecycle
COM objects use reference counting - proper cleanup is essential:

```csharp
public class ComWrapper : IDisposable
{
    private object? _comObject;
    private bool _disposed;

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    protected virtual void Dispose(bool disposing)
    {
        if (_disposed) return;

        if (_comObject != null)
        {
            Marshal.ReleaseComObject(_comObject);
            _comObject = null;
        }

        _disposed = true;
    }

    ~ComWrapper() => Dispose(false);
}
```

### 4. Late Binding vs Early Binding

#### Late Binding (dynamic)
```csharp
// More flexible, less type-safe
dynamic comObject = Activator.CreateInstance(
    Type.GetTypeFromProgID("ContPAQi.SDK.Comercial"));
comObject.Conectar();
```

#### Early Binding (type library)
```csharp
// Type-safe, requires reference to type library
// Add reference to ContPAQi SDK type library (.tlb)
var sdk = new ContPAQiSDKLib.cSDKClass();
sdk.Conectar();
```

### 5. Error Handling
COM errors are thrown as COMException:

```csharp
try
{
    comObject.SomeOperation();
}
catch (COMException ex)
{
    // ex.ErrorCode contains HRESULT
    // ex.Message contains error description
    Console.WriteLine($"COM Error: 0x{ex.ErrorCode:X8} - {ex.Message}");
}
```

## ContPAQi SDK Integration

### Typical SDK Structure
ContPAQi SDK typically exposes:
- Main SDK class for connection/initialization
- Document classes (Factura, Poliza, etc.)
- Catalog classes (Proveedor, Producto, etc.)

### Connection Pattern
```csharp
public class ContPAQiConnection
{
    private dynamic? _sdk;

    public bool Connect(string companyPath)
    {
        try
        {
            _sdk = Activator.CreateInstance(
                Type.GetTypeFromProgID("ContPAQi.SDK.Comercial"));

            int result = _sdk.InicializarSDK();
            if (result != 0) return false;

            result = _sdk.AbreEmpresa(companyPath);
            return result == 0;
        }
        catch (COMException)
        {
            return false;
        }
    }

    public void Disconnect()
    {
        if (_sdk != null)
        {
            _sdk.CierraEmpresa();
            _sdk.TerminaSDK();
            Marshal.ReleaseComObject(_sdk);
            _sdk = null;
        }
    }
}
```

### SDK Detection
Check registry for ContPAQi installation:

```csharp
public bool IsSdkInstalled()
{
    using var key = Registry.LocalMachine.OpenSubKey(
        @"SOFTWARE\Computación en Acción, SA de CV\ContPAQi");
    return key != null;
}
```

## Best Practices

### 1. Always Release COM Objects
```csharp
// Good - explicit release
try
{
    var comObj = GetComObject();
    // Use comObj...
}
finally
{
    if (comObj != null)
        Marshal.ReleaseComObject(comObj);
}

// Better - using IDisposable wrapper
using var wrapper = new ComWrapper();
// Use wrapper...
```

### 2. Use try-finally for Cleanup
```csharp
object? comObject = null;
try
{
    comObject = CreateComObject();
    // Use comObject
}
finally
{
    if (comObject != null)
    {
        Marshal.FinalReleaseComObject(comObject);
    }
}
```

### 3. Thread Considerations
COM objects often require STA (Single-Threaded Apartment):

```csharp
[STAThread]
static void Main()
{
    // COM operations here
}

// Or for async contexts
var thread = new Thread(() =>
{
    // COM operations
});
thread.SetApartmentState(ApartmentState.STA);
thread.Start();
```

### 4. Result Wrappers
Wrap SDK results for cleaner error handling:

```csharp
public record SdkResult<T>
{
    public bool Success { get; init; }
    public SdkErrorCode ErrorCode { get; init; }
    public string? ErrorMessage { get; init; }
    public T? Data { get; init; }
}
```

## Common Patterns

### SDK Wrapper Class
```csharp
public class ContPAQiSdkWrapper : IDisposable
{
    private dynamic? _sdk;
    private bool _isConnected;

    public SdkResult<bool> Connect(string company)
    {
        try
        {
            _sdk = Activator.CreateInstance(
                Type.GetTypeFromProgID("ContPAQi.SDK"));
            // Initialize...
            return SdkResult<bool>.Ok(true);
        }
        catch (COMException ex)
        {
            return SdkResult<bool>.Fail(
                SdkErrorCode.Unknown,
                ex.Message);
        }
    }

    public void Dispose()
    {
        if (_sdk != null)
        {
            Marshal.ReleaseComObject(_sdk);
            _sdk = null;
        }
    }
}
```
