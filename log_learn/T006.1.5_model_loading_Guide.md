# T006.1.5 Learning Guide: AI Model Loading Checks

## Overview

This guide explains how to implement model availability checks for a HuggingFace transformer model (like LayoutLMv3) in a health check endpoint. This is essential for production systems that need to verify AI models are ready before processing requests.

## What is a HuggingFace Model?

HuggingFace transformer models typically consist of:
- `config.json`: Model architecture configuration
- `pytorch_model.bin` OR `model.safetensors`: Model weights
- `tokenizer.json` (optional): Tokenizer configuration
- `vocab.txt` (optional): Vocabulary file

## Key Concepts

### 1. Model Path Configuration

```python
import os

DEFAULT_MODEL_PATH = "./models/layoutlm"

def get_model_path() -> str:
    return os.environ.get("MODEL_PATH", DEFAULT_MODEL_PATH)
```

**Best practices:**
- Use environment variables for configuration
- Provide sensible defaults for development
- Use relative paths that work across environments

### 2. Checking Model Files

```python
def check_model_files() -> bool:
    model_path = get_model_path()

    # Check directory exists
    if not os.path.exists(model_path) or not os.path.isdir(model_path):
        return False

    # Check required files
    config_path = os.path.join(model_path, "config.json")
    if not os.path.exists(config_path):
        return False

    # Check for model weights (multiple formats)
    weights_files = [
        os.path.join(model_path, "pytorch_model.bin"),
        os.path.join(model_path, "model.safetensors"),
    ]
    has_weights = any(os.path.exists(f) for f in weights_files)

    return has_weights
```

**Key points:**
- Check both directory AND files
- Support multiple weight file formats
- SafeTensors is the newer, more secure format

### 3. Detailed Status Reporting

```python
def get_model_status() -> dict:
    model_path = get_model_path()
    exists = os.path.exists(model_path) and os.path.isdir(model_path)

    has_config = False
    has_weights = False

    if exists:
        has_config = os.path.exists(os.path.join(model_path, "config.json"))
        # ... check weights ...

    return {
        "path": model_path,
        "exists": exists,
        "has_config": has_config,
        "has_weights": has_weights,
        "ready": exists and has_config and has_weights,
    }
```

**Why detailed status?**
- Helps debugging deployment issues
- Shows exactly which file is missing
- Useful for monitoring dashboards

### 4. Integration with Health Endpoint

```python
class HealthResponse(BaseModel):

@router.get("/health")
```

## Model File Formats

| Format | Extension | Description |
|--------|-----------|-------------|
| PyTorch | `.bin` | Traditional pickle-based format |
| SafeTensors | `.safetensors` | Secure, fast loading format |
| TensorFlow | `.h5` | Keras/TF format (not used here) |

## Testing Without Real Models

```python
from unittest.mock import patch

def test_check_model_files_false_when_missing():
    with patch('os.path.exists') as mock_exists:
        mock_exists.return_value = False
        result = check_model_files()
        assert result is False

def test_with_model_directory():
    def mock_exists(path):
        if "models" in path:
            return True
        return False

    with patch('os.path.exists', side_effect=mock_exists):
        with patch('os.path.isdir', return_value=True):
            result = check_model_files()
```

## Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| False on valid model | Wrong path | Check MODEL_PATH env var |
| Missing weights | Only config.json | Download full model |
| Permission error | File access denied | Check file permissions |
| Path not found | Relative vs absolute | Use absolute path in production |

## Deployment Considerations

1. **Development**: Models may not be present, handle gracefully
2. **CI/CD**: Tests should pass without actual models (use mocks)
3. **Production**: Model files should be verified at startup
4. **Docker**: Mount model directory as volume

## Model Loading (Future)

After checking files exist, actual model loading would be:
```python
from transformers import AutoModel, AutoConfig

def load_model():
    model_path = get_model_path()
    config = AutoConfig.from_pretrained(model_path)
    model = AutoModel.from_pretrained(model_path)
    return model
```
