# Learning Guide: T003.3.1 - Create desktop-app/src/renderer/index.html

## Overview

This guide covers creating an HTML entry point for a React application running in an Electron renderer process.

## Concepts Covered

### 1. HTML Entry Point in Electron

In Electron applications, the renderer process needs an HTML file that:
- Serves as the entry point loaded by `BrowserWindow.loadFile()`
- Contains a mount point for React
- References the JavaScript bundle

```javascript
// Main process loads the HTML
mainWindow.loadFile('src/renderer/index.html');
```

### 2. Modern HTML5 Structure

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>App Title</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="./index.tsx"></script>
  </body>
</html>
```

Key elements:
- **DOCTYPE**: Declares HTML5 document type
- **lang attribute**: Accessibility and SEO
- **charset**: Character encoding (UTF-8 for international text)
- **viewport**: Responsive design meta tag

### 3. React Mount Point

React needs a DOM element to render into:

```html
<div id="root"></div>
```

This is referenced in the React entry point:

```tsx
// index.tsx
import { createRoot } from 'react-dom/client';

const root = createRoot(document.getElementById('root')!);
root.render(<App />);
```

### 4. Content Security Policy (CSP)

CSP restricts resource loading for security:

```html
<meta http-equiv="Content-Security-Policy"
      content="default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'" />
```

| Directive | Value | Purpose |
|-----------|-------|---------|
| default-src | 'self' | Default: only same-origin resources |
| script-src | 'self' | Scripts: only from same origin |
| style-src | 'self' 'unsafe-inline' | Styles: same origin + inline (for Tailwind) |

### 5. Module Script Loading

ES modules provide better code organization:

```html
<script type="module" src="./index.tsx"></script>
```

Benefits:
- Strict mode by default
- Top-level await support
- Better tree-shaking
- Works with Vite's dev server

### 6. Localization Setup

Setting the language attribute for Spanish users:

```html
<html lang="es">
```

Benefits:
- Screen readers use correct pronunciation
- Search engines understand content language
- CSS `:lang()` selector works

## Code Example

### Complete index.html

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <!-- Character encoding -->
    <meta charset="UTF-8" />

    <!-- Responsive viewport -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <!-- Security: Content Security Policy -->
    <meta http-equiv="Content-Security-Policy"
          content="default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'" />

    <!-- SEO/Accessibility -->
    <meta name="description" content="ContPAQ Win - Sistema de gestión de facturas" />

    <!-- Page title -->
    <title>ContPAQ Win</title>
  </head>
  <body>
    <!-- React mount point -->
    <div id="root"></div>

    <!-- Application entry point (processed by Vite) -->
    <script type="module" src="./index.tsx"></script>
  </body>
</html>
```

## Best Practices

### 1. Keep HTML Minimal
Let React handle all dynamic content. The HTML file should only:
- Set up the document structure
- Provide security headers
- Define the mount point
- Load the script

### 2. Self-Closing Tags
For void elements in HTML5:
```html
<meta charset="UTF-8" />  <!-- Self-closing is optional but consistent -->
```

### 3. Charset First
Always put charset meta tag first in `<head>`:
```html
<head>
  <meta charset="UTF-8" />  <!-- First! -->
  <meta name="viewport" ... />
```

### 4. No Blocking Resources
Avoid render-blocking resources in `<head>`:
- Use `type="module"` for scripts
- Load CSS through JavaScript imports
- Let the bundler handle optimization

## Common Issues

### Issue: React Not Rendering
**Cause**: Missing or incorrect root element
**Solution**: Ensure `<div id="root"></div>` exists

### Issue: CSP Blocking Scripts
**Cause**: Too restrictive CSP
**Solution**: Include `'self'` in script-src

### Issue: Styles Not Applying
**Cause**: CSP blocking inline styles
**Solution**: Add `'unsafe-inline'` to style-src (needed for Tailwind)

### Issue: Module Script Not Loading
**Cause**: Server not serving correct MIME type
**Solution**: Vite handles this automatically; ensure Vite is running

## Testing Approach

Test HTML files by checking for required elements:

```python
def test_has_root_div(self):
    """Verify React mount point exists."""
    with open(HTML_PATH, 'r') as f:
        content = f.read()
    assert 'id="root"' in content or "id='root'" in content
```
