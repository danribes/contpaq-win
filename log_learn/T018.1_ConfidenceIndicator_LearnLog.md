# T018.1 Learning Log: Confidence Indicator Component

## Date: 2025-12-18

## Key Learnings

### 1. Leveraging Existing Type Utilities

**Pattern**: Reuse existing type definitions and utility functions:
```typescript
import { CONFIDENCE_THRESHOLDS, getConfidenceLevel, type ConfidenceLevel } from '../types';

// Use existing utility
const level = getConfidenceLevel(confidence); // 'high' | 'medium' | 'low'
```

**Benefits**:
- Single source of truth for thresholds
- Consistent logic across codebase
- DRY principle

### 2. Configuration Object Pattern

**Pattern**: Use typed configuration objects for variants:
```typescript
const DOT_COLORS: Record<ConfidenceLevel, string> = {
  high: 'bg-green-500',
  medium: 'bg-orange-500',
  low: 'bg-red-500',
};

const SIZE_CLASSES: Record<ConfidenceIndicatorSize, string> = {
  sm: 'w-2 h-2',
  md: 'w-3 h-3',
  lg: 'w-4 h-4',
};
```

**Benefits**:
- Type-safe lookups
- Easy to add new variants
- Self-documenting code

### 3. Value Normalization

**Pattern**: Normalize input values to expected range:
```typescript
function normalizeConfidence(confidence: number): number {
  if (confidence < 0) return 0;
  if (confidence > 100) return 100;
  return Math.round(confidence);
}
```

**Benefits**:
- Defensive programming
- Handles edge cases gracefully
- Prevents UI bugs with invalid data

### 4. Tooltip Positioning with Tailwind

**Pattern**: Use transform utilities for centered tooltips:
```tsx
<div className="absolute bottom-full left-1/2 transform -translate-x-1/2 mb-2">
  {/* Tooltip content */}
  {/* Arrow */}
  <div className="absolute top-full left-1/2 transform -translate-x-1/2 border-4 border-transparent border-t-gray-800" />
</div>
```

**Key classes**:
- `absolute`: Position relative to parent
- `bottom-full`: Place above parent
- `left-1/2 -translate-x-1/2`: Center horizontally
- `border-t-gray-800`: Create arrow using border trick

### 5. Testing Hover States

**Pattern**: Use fireEvent for hover interactions:
```typescript
it('should show tooltip on hover', async () => {
  render(<ConfidenceIndicator confidence={85} />);
  const indicator = screen.getByTestId('confidence-indicator');

  fireEvent.mouseEnter(indicator);

  await waitFor(() => {
    expect(screen.getByTestId('confidence-tooltip')).toBeInTheDocument();
  });
});
```

**Note**: Use `waitFor` for state changes after events.

### 6. Boundary Value Testing

**Pattern**: Test exact boundary values and edge cases:
```typescript
// Test exactly at thresholds
it('should display green for exactly 90%', () => {...});
it('should display orange for exactly 70%', () => {...});

// Test boundary - 0.1
it('should display orange for 89%', () => {...});
it('should display red for 69%', () => {...});

// Test with decimals that round to boundary
it('should handle boundary value 89.9 (rounds to 90 = high)', () => {...});
```

### 7. Accessibility in Visual Indicators

**Pattern**: Add ARIA labels for visual-only information:
```tsx
<div
  aria-label={`Confianza: ${normalizedConfidence}% - ${label}`}
>
  <span className="bg-green-500 rounded-full" />
</div>
```

**Why it matters**: Screen readers can't see colors, so the aria-label provides the semantic information that the color conveys.

## Best Practices Applied

1. **Single Responsibility**: Component only handles confidence display
2. **Configurable**: Props allow customization without code changes
3. **Localized**: Spanish text for target audience
4. **Accessible**: ARIA labels for screen readers
5. **Defensive**: Normalizes out-of-range values
6. **Testable**: Clear data-testid attributes for testing

## Design Decisions

1. **Why round percentages?**: Avoid displaying confusing decimals like "85.3%"
2. **Why show tooltip on hover?**: Keep UI clean while providing details on demand
3. **Why Spanish text?**: Target audience is Mexican accountants
4. **Why inline-flex?**: Allow indicator to flow with text content
5. **Why cursor-pointer?**: Indicate interactivity (hover shows tooltip)

## Color Semantics

The color scheme follows universal conventions:
- **Green**: Good/Safe/Proceed - High confidence means trust
- **Orange/Yellow**: Caution/Warning - Medium confidence needs attention
- **Red**: Danger/Stop - Low confidence requires action

## Potential Improvements

1. Add animation/pulse for low confidence to draw attention
2. Support color-blind friendly mode (patterns/shapes)
3. Add click handler for "verify" action
