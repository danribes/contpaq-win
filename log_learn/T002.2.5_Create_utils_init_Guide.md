# Learning Guide: T002.2.5 - Utility Functions and Pure Functions

## What is a Utils Package?

A utils (utilities) package contains shared helper functions that are used across multiple parts of an application. These are typically:

- **Generic** - Not tied to specific business logic
- **Reusable** - Used by multiple modules
- **Simple** - Single-purpose functions
- **Well-tested** - Critical building blocks

```
src/
├── models/      # Data structures
├── services/    # Business logic
├── api/         # HTTP endpoints
└── utils/       # Shared helpers ← This package
```

## Pure Functions

Utilities should ideally be **pure functions** - functions that:

1. **Same input → Same output** (deterministic)
2. **No side effects** (don't modify external state)

### Pure Function Example

```python
# Pure - always returns same result for same input
def get_confidence_level(score: float) -> str:
    if score >= 0.9:
        return "high"
    elif score >= 0.7:
        return "medium"
    else:
        return "low"

# Test is simple
assert get_confidence_level(0.95) == "high"
assert get_confidence_level(0.95) == "high"  # Always true
```

### Impure Function Example

```python
import random

# Impure - result depends on external state
def get_random_confidence_level() -> str:
    score = random.random()  # Side effect: reads random state
    if score >= 0.9:
        return "high"
    return "low"

# Hard to test - result changes each call
```

## Why Pure Functions Matter

### 1. Easy to Test

```python
def test_confidence_level_high():
    assert get_confidence_level(0.95) == "high"
    assert get_confidence_level(0.90) == "high"
    assert get_confidence_level(0.899) == "medium"
```

No mocking needed, no setup, no teardown.

### 2. Easy to Reason About

```python
# I can understand this without knowing any context
result = format_currency(1234.56, "MXN")
# result is always "$1,234.56 MXN" for these inputs
```

### 3. Safe to Parallelize

```python
# Pure functions can run in parallel safely
results = [get_confidence_level(s) for s in scores]
# No race conditions possible
```

### 4. Cacheable

```python
from functools import lru_cache

@lru_cache(maxsize=100)
def expensive_calculation(x: int) -> int:
    # Result is cached because function is pure
    return x ** 2
```

## Our Planned Utilities

### confidence.py (T018.2)

```python
# utils/confidence.py

# Constants
HIGH_CONFIDENCE_THRESHOLD = 0.90
MEDIUM_CONFIDENCE_THRESHOLD = 0.70

# Color mapping for UI
CONFIDENCE_COLORS = {
    "high": "#22c55e",    # Green
    "medium": "#f97316",  # Orange
    "low": "#ef4444",     # Red
}

def get_confidence_level(score: float) -> str:
    """
    Map a confidence score (0.0-1.0) to a level.

    Args:
        score: Confidence score between 0.0 and 1.0

    Returns:
        "high" if score >= 0.90
        "medium" if score >= 0.70
        "low" otherwise
    """
    if score >= HIGH_CONFIDENCE_THRESHOLD:
        return "high"
    elif score >= MEDIUM_CONFIDENCE_THRESHOLD:
        return "medium"
    else:
        return "low"

def get_confidence_color(score: float) -> str:
    """Get the hex color for a confidence score."""
    level = get_confidence_level(score)
    return CONFIDENCE_COLORS[level]
```

### Future Utilities

#### Date Formatting (Mexican Locale)
```python
# utils/formatting.py

def format_date_mx(date: datetime) -> str:
    """Format date in Mexican style: 16 de diciembre de 2025"""
    months = ["enero", "febrero", "marzo", ...]
    return f"{date.day} de {months[date.month-1]} de {date.year}"
```

#### Currency Formatting
```python
def format_currency_mx(amount: float) -> str:
    """Format amount as Mexican pesos: $1,234.56"""
    return f"${amount:,.2f}"
```

#### File Helpers
```python
def get_file_hash(content: bytes) -> str:
    """Calculate SHA-256 hash of file content."""
    import hashlib
    return hashlib.sha256(content).hexdigest()
```

### Validators

```python
# utils/validators.py

def is_valid_rfc(rfc: str) -> bool:
    """Validate Mexican RFC format."""
    import re
    # 12 chars for companies, 13 for individuals
    pattern = r'^[A-Z&Ñ]{3,4}[0-9]{6}[A-Z0-9]{3}$'
    return bool(re.match(pattern, rfc.upper()))
```

## Testing Utilities

### Simple Unit Tests

```python
# tests/test_confidence.py

import pytest
from utils.confidence import get_confidence_level, get_confidence_color

class TestConfidenceLevel:
    def test_high_confidence(self):
        assert get_confidence_level(0.95) == "high"
        assert get_confidence_level(0.90) == "high"

    def test_medium_confidence(self):
        assert get_confidence_level(0.85) == "medium"
        assert get_confidence_level(0.70) == "medium"

    def test_low_confidence(self):
        assert get_confidence_level(0.69) == "low"
        assert get_confidence_level(0.0) == "low"

    def test_edge_cases(self):
        assert get_confidence_level(0.899999) == "medium"
        assert get_confidence_level(0.900001) == "high"

class TestConfidenceColor:
    def test_returns_green_for_high(self):
        assert get_confidence_color(0.95) == "#22c55e"

    def test_returns_orange_for_medium(self):
        assert get_confidence_color(0.75) == "#f97316"

    def test_returns_red_for_low(self):
        assert get_confidence_color(0.50) == "#ef4444"
```

### Property-Based Testing

```python
from hypothesis import given, strategies as st

@given(st.floats(min_value=0.9, max_value=1.0))
def test_high_scores_always_high(score):
    assert get_confidence_level(score) == "high"

@given(st.floats(min_value=0.0, max_value=0.69999))
def test_low_scores_always_low(score):
    assert get_confidence_level(score) == "low"
```

## Best Practices

### 1. Type Hints
```python
def get_confidence_level(score: float) -> str:
    ...
```

### 2. Docstrings
```python
def format_currency(amount: float, currency: str = "MXN") -> str:
    """
    Format a number as currency.

    Args:
        amount: The numeric amount
        currency: Currency code (default: MXN)

    Returns:
        Formatted string like "$1,234.56 MXN"

    Examples:
        >>> format_currency(1234.56)
        '$1,234.56 MXN'
    """
```

### 3. No Hidden Dependencies
```python
# Bad - hidden dependency on global state
_config = None
def get_threshold():
    return _config.threshold  # Where does _config come from?

# Good - explicit parameter
def get_threshold(config: Config) -> float:
    return config.threshold
```

### 4. Single Responsibility
```python
# Bad - does too many things
def process_invoice(pdf, validate=True, extract=True, format=True):
    ...

# Good - single purpose
def validate_invoice(invoice: Invoice) -> ValidationResult:
    ...
```
