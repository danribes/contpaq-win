# Learning Guide: T002.1.2 - requirements.txt Dependencies

## What is requirements.txt?

`requirements.txt` is a file that lists Python packages needed to run your application. It allows reproducible installations across different machines.

## Why requirements.txt vs. pyproject.toml?

| Aspect | requirements.txt | pyproject.toml |
|--------|------------------|----------------|
| Format | Simple text | TOML |
| Versions | Usually pinned | Often flexible |
| Purpose | Deployment/CI | Package definition |
| Best for | Reproducibility | Library development |

**Best Practice**: Use both!
- `pyproject.toml` for package metadata and optional dependencies
- `requirements.txt` for exact versions in deployment

## Dependency Categories in Our Project

### 1. Web Framework

```
fastapi==0.109.0
uvicorn==0.27.0
```

**FastAPI** is a modern Python web framework:
- Automatic API documentation (Swagger/OpenAPI)
- Type hints for validation
- Async support out of the box
- High performance (on par with Node.js)

**Uvicorn** is the ASGI server that runs FastAPI:
```bash
uvicorn src.main:app --host 127.0.0.1 --port 8000
```

### 2. PDF Processing

```
PyMuPDF==1.23.8
```

**PyMuPDF** (aka `fitz`) handles PDF operations:
```python
import fitz  # PyMuPDF

doc = fitz.open("invoice.pdf")
for page in doc:
    text = page.get_text()       # Extract text
    images = page.get_images()   # Get embedded images
```

Why PyMuPDF over alternatives?
| Library | Speed | Features | License |
|---------|-------|----------|---------|
| PyMuPDF | Fast | Full | AGPL |
| PyPDF2 | Slow | Basic | BSD |
| pdfminer | Medium | Text only | MIT |

### 3. OCR (Optical Character Recognition)

```
pytesseract==0.3.10
Pillow==10.2.0
```

**pytesseract** is a wrapper for Google's Tesseract OCR:
```python
from PIL import Image
import pytesseract

# Convert image to text
text = pytesseract.image_to_string(Image.open("scanned.png"), lang='spa')
```

**Pillow** handles image manipulation:
```python
from PIL import Image

img = Image.open("page.png")
img = img.convert('L')           # Grayscale
img = img.point(lambda x: 0 if x < 128 else 255)  # Threshold
```

### 4. AI/ML - Document Understanding

```
transformers==4.36.0
torch==2.1.2+cpu
```

**Transformers** provides pre-trained AI models:
```python
from transformers import AutoProcessor, AutoModelForTokenClassification

# Load LayoutLMv3 for document understanding
processor = AutoProcessor.from_pretrained("microsoft/layoutlmv3-base")
model = AutoModelForTokenClassification.from_pretrained("microsoft/layoutlmv3-base")
```

**PyTorch** is the ML framework:
- `+cpu` suffix means CPU-only (no CUDA/GPU)
- Reduces installation size from ~2GB to ~200MB
- Sufficient for inference on invoice documents

### 5. Data Validation

```
pydantic==2.5.3
pydantic-settings==2.1.0
```

**Pydantic** validates and serializes data:
```python
from pydantic import BaseModel, Field

class Invoice(BaseModel):
    rfc: str = Field(..., pattern=r'^[A-Z]{3,4}\d{6}[A-Z0-9]{3}$')
    total: float = Field(..., gt=0)
    confidence: float = Field(..., ge=0, le=1)

# Automatic validation
invoice = Invoice(rfc="ABC123456XYZ", total=1500.00, confidence=0.95)
```

## Version Pinning Strategies

### Exact Pinning (What We Use)
```
fastapi==0.109.0
```
- ✅ Reproducible builds
- ✅ No surprise breakages
- ❌ Manual updates needed

### Compatible Release
```
fastapi~=0.109.0
```
- Allows 0.109.x but not 0.110.0
- Good balance of stability and updates

### Minimum Version
```
fastapi>=0.109.0
```
- ✅ Always gets latest
- ❌ May break unexpectedly

## Installing Dependencies

### Basic Installation
```bash
cd ai-service
pip install -r requirements.txt
```

### Virtual Environment (Recommended)
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
```

### With pip-tools (Advanced)
```bash
pip install pip-tools
pip-compile requirements.in   # Generate locked versions
pip-sync requirements.txt     # Install exactly what's specified
```

## Dependency Resolution

When you run `pip install`, it resolves dependencies:

```
fastapi==0.109.0
├── starlette>=0.35.0
├── pydantic>=1.7.4
└── typing-extensions>=4.8.0

transformers==4.36.0
├── huggingface-hub>=0.19.3
├── tokenizers>=0.14.0
└── safetensors>=0.3.1
```

Conflicts can occur if two packages need incompatible versions.

## Windows-Specific Notes

### PyTorch CPU Installation
```
torch==2.1.2+cpu
```

On Windows, install from PyTorch's index:
```bash
pip install torch==2.1.2+cpu -f https://download.pytorch.org/whl/cpu/torch_stable.html
```

### Tesseract Installation
pytesseract requires Tesseract OCR to be installed separately:
1. Download from: https://github.com/UB-Mannheim/tesseract/wiki
2. Add to PATH: `C:\Program Files\Tesseract-OCR`
3. Set in Python:
```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```
