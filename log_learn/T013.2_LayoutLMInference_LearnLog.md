### 2. BIO Tagging for NER
Standard format for Named Entity Recognition:

```python
# B = Beginning of entity
# I = Inside (continuation of) entity
# O = Outside (not part of any entity)

BIO_LABELS = [
    "O",  # Outside
    "B-VENDOR_RFC", "I-VENDOR_RFC",
    "B-INVOICE_NUMBER", "I-INVOICE_NUMBER",
    # etc.
]

# Example tokens: ["RFC:", "ABC123456789"]

```

### 3. Bounding Box Normalization
LayoutLM uses 0-1000 coordinate space:

```python
def normalize_bbox(bbox, image_width, image_height):
    """Normalize bbox to 0-1000 range."""
    x0 = int((bbox["x0"] / image_width) * 1000)
    y0 = int((bbox["y0"] / image_height) * 1000)
    x1 = int((bbox["x1"] / image_width) * 1000)
    y1 = int((bbox["y1"] / image_height) * 1000)
    return [x0, y0, x1, y1]
```

### 5. Token Classification Inference
Running the model and getting predictions:

```python
import torch

def run_inference(model_input):
    with torch.no_grad():  # Disable gradient computation
        outputs = model(**model_input)

    # Get prediction from logits
    logits = outputs.logits.detach().cpu().numpy()
    predictions = logits.argmax(axis=-1)

    return {"logits": logits, "predictions": predictions}
```

### 6. Grouping BIO Tokens
Combining B- and I- tokens into complete entities:

```python
def parse_bio_tokens(tokens, predictions):
    fields = {}
    current_field = None
    current_tokens = []

    for token, label in zip(tokens, predictions):
        if label.startswith("B-"):
            # Save previous field
            if current_field:
                fields[current_field] = " ".join(current_tokens)
            # Start new field
            current_field = label[2:]  # Remove "B-"
            current_tokens = [token]
        elif label.startswith("I-") and current_field:
            # Continue current field
            current_tokens.append(token)
        else:
            # Outside - save and reset
            if current_field:
                fields[current_field] = " ".join(current_tokens)
            current_field = None
            current_tokens = []

    return fields
```

### 9. Confidence Score Aggregation
Calculating overall confidence from multiple scores:

```python
def calculate_field_confidence(token_scores: List[float]) -> float:
    """Mean confidence from all tokens in field."""
    if not token_scores:
        return 0.0
    return sum(token_scores) / len(token_scores)
```
