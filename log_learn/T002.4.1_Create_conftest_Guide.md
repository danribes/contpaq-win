# Learning Guide: T002.4.1 - Pytest conftest.py and Fixtures

## What is conftest.py?

`conftest.py` is a special file recognized by pytest that provides:
- **Shared fixtures** accessible to all test files in the directory
- **Hooks** for customizing pytest behavior
- **Plugin configuration** and test discovery rules

```
ai-service/
└── tests/
    ├── conftest.py          ← Shared fixtures for all tests
    ├── unit/
    │   └── test_config.py   ← Can use fixtures from conftest.py
    └── integration/
        └── test_api.py      ← Can also use fixtures from conftest.py
```

## Pytest Fixtures Explained

### What is a Fixture?

A fixture is a function that provides test data or sets up test state:

```python
import pytest

@pytest.fixture
def sample_user():
    """Provide a sample user for testing."""
    return {"name": "Test User", "email": "test@example.com"}

def test_user_has_email(sample_user):
    # Fixture is automatically passed as argument
    assert "email" in sample_user
```

### Fixture Scopes

```python
@pytest.fixture(scope="function")  # Default - run for each test
def per_test_data():
    return {}

@pytest.fixture(scope="class")  # Run once per test class
def per_class_data():
    return {}

@pytest.fixture(scope="module")  # Run once per module
def per_module_data():
    return {}

@pytest.fixture(scope="session")  # Run once per test session
def per_session_data():
    return {}
```

### Fixture Dependencies

Fixtures can depend on other fixtures:

```python
@pytest.fixture
def base_settings():
    return {"host": "localhost"}

@pytest.fixture
def test_settings(base_settings):
    # Uses base_settings fixture
    base_settings["port"] = 8001
    return base_settings
```

## Common Fixture Patterns

### 1. Resource Setup and Teardown

```python
@pytest.fixture
def temp_file():
    """Create a temporary file, clean up after test."""
    import tempfile
    fd, path = tempfile.mkstemp()

    yield path  # Provide to test

    # Cleanup after test completes
    os.unlink(path)
```

### 2. Database Connection

```python
@pytest.fixture
def db_session():
    """Provide database session with rollback."""
    connection = create_connection()
    transaction = connection.begin()

    yield connection

    transaction.rollback()
    connection.close()
```

### 3. Test Client (FastAPI)

```python
from fastapi.testclient import TestClient

@pytest.fixture
def client():
    """Provide FastAPI test client."""
    from src.main import app
    return TestClient(app)

def test_health_endpoint(client):
    response = client.get("/health")
    assert response.status_code == 200
```

### 4. Autouse Fixtures

```python
@pytest.fixture(autouse=True)
def reset_cache():
    """Automatically runs for every test."""
    yield
    cache.clear()
```

## Our conftest.py Structure

### FIXTURES_DIR Constant

```python
from pathlib import Path

FIXTURES_DIR = Path(__file__).parent / "fixtures"
```

This provides a consistent path to test fixture files (sample PDFs, etc.).

### test_settings Fixture

```python
@pytest.fixture
def test_settings():
    return {
        "HOST": "127.0.0.1",
        "PORT": 8001,  # Different port to avoid conflicts
        "LOG_LEVEL": "DEBUG",
        "TESSERACT_PATH": "/usr/bin/tesseract",
        "MODEL_PATH": str(FIXTURES_DIR / "models"),
    }
```

- Returns dict instead of Settings object for flexibility
- Uses different port (8001) to avoid conflicts with running services
- DEBUG log level for verbose test output

### temp_env_file Fixture

```python
@pytest.fixture
def temp_env_file(test_settings):
    fd, path = tempfile.mkstemp(suffix=".env")
    try:
        with os.fdopen(fd, "w") as f:
            for key, value in test_settings.items():
                f.write(f"{key}={value}\n")
        yield path
    finally:
        os.unlink(path)
```

- Depends on test_settings fixture
- Creates actual .env file for integration tests
- Always cleans up using try/finally

### sample_pdf_path Fixture

```python
@pytest.fixture
def sample_pdf_path():
    pdf_path = FIXTURES_DIR / "sample_invoice.pdf"
    return pdf_path  # Return path even if doesn't exist
```

- Returns Path object for file operations
- Returns expected path even if file doesn't exist yet
- Tests can skip if file not present

### reset_settings_cache Fixture

```python
@pytest.fixture(autouse=True)
def reset_settings_cache():
    try:
        from src.config import get_settings
        get_settings.cache_clear()
    except ImportError:
        pass
    yield
    try:
        from src.config import get_settings
        get_settings.cache_clear()
    except ImportError:
        pass
```

- `autouse=True` means it runs for every test automatically
- Clears `lru_cache` on get_settings function
- Prevents test pollution from cached configuration

## Best Practices

### 1. Keep Fixtures Focused

```python
# Good - focused fixture
@pytest.fixture
def admin_user():
    return User(role="admin")

# Bad - too broad
@pytest.fixture
def test_data():
    return {
        "users": [...],
        "products": [...],
        "orders": [...],
    }
```

### 2. Use Meaningful Names

```python
# Good
@pytest.fixture
def authenticated_client():
    ...

# Bad
@pytest.fixture
def client2():
    ...
```

### 3. Document with Docstrings

```python
@pytest.fixture
def sample_invoice():
    """
    Provide a sample invoice dict for testing.

    Returns:
        dict: Invoice with all required fields populated.
    """
    return {...}
```

### 4. Clean Up Resources

```python
@pytest.fixture
def temp_dir():
    dir_path = tempfile.mkdtemp()
    yield dir_path
    shutil.rmtree(dir_path)  # Always clean up
```

## Using Fixtures in Tests

### Basic Usage

```python
def test_settings_port(test_settings):
    assert test_settings["PORT"] == 8001
```

### Multiple Fixtures

```python
def test_with_env_file(temp_env_file, test_settings):
    # Both fixtures are available
    assert os.path.exists(temp_env_file)
    assert test_settings["PORT"] == 8001
```

### Fixture with pytest.mark.parametrize

```python
@pytest.mark.parametrize("port", [8001, 8002, 8003])
def test_different_ports(test_settings, port):
    test_settings["PORT"] = port
    assert test_settings["PORT"] == port
```
