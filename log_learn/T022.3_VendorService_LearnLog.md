## Concepts Learned

### 1. Service Layer Pattern
Services encapsulate business logic and data access:

```csharp
public class VendorService : IVendorService
{
    private readonly ISdkService _sdkService;
    private readonly ILogger<VendorService> _logger;

    public VendorService(ISdkService sdkService, ILogger<VendorService> logger)
    {
        _sdkService = sdkService ?? throw new ArgumentNullException(nameof(sdkService));
        _logger = logger ?? throw new ArgumentNullException(nameof(logger));
    }

    public async Task<VendorDto?> GetByRfcAsync(string rfc)
    {
        // Business logic here
    }
}
```

Benefits:
- Separates data access from controllers
- Testable with mocked dependencies
- Ready for SDK integration

### 3. Async Method with Synchronous Implementation
Use `Task.CompletedTask` for async stubs:

```csharp
public async Task<VendorDto?> GetByRfcAsync(string rfc)
{
    // Synchronous logic
    var vendor = _testVendors.FirstOrDefault(v => v.Rfc == rfc);

    // Make method async-compatible
    await Task.CompletedTask;

    return vendor;
}
```

Why async stub:
- Method signature ready for SDK (which will be async)
- No changes needed when SDK is integrated
- Consistent API for consumers

### 4. LINQ Query Pattern
Use LINQ for filtering test data:

```csharp
public async Task<IEnumerable<VendorDto>> SearchAsync(string searchTerm, int limit)
{
    var results = _testVendors
        .Where(v =>
            v.Rfc.Contains(searchTerm, StringComparison.OrdinalIgnoreCase) ||
            v.Name.Contains(searchTerm, StringComparison.OrdinalIgnoreCase))
        .Take(limit);

    return results.ToList();
}
```

Key points:
- Case-insensitive comparison
- Multiple field search
- Limit with `Take()`

### 5. Code Generation for IDs
Generate sequential codes for new records:

```csharp
private static int _vendorCounter = 4;

public async Task<VendorDto> CreateAsync(CreateVendorRequest vendor)
{
    var newCode = $"PROV{_vendorCounter++:D3}";

    var created = new VendorDto
    {
        Code = newCode,  // PROV004, PROV005, etc.
        Rfc = vendor.Rfc,
        Name = vendor.Name
    };

    return created;
}
```

Format specifier `D3`: Pads with zeros to 3 digits.

### 6. Delegation Pattern
Reuse methods to avoid duplication:

```csharp
public async Task<bool> ExistsAsync(string rfc)
{
    // Delegate to GetByRfcAsync
    var vendor = await GetByRfcAsync(rfc);
    return vendor != null;
}
```

Benefits:
- Single source of truth for lookup logic
- Consistent behavior
- Less code to maintain

## Best Practices Identified

1. **Null-safe string handling**: Check `string.IsNullOrWhiteSpace()` before operations
2. **Normalize inputs**: Convert to uppercase for RFC comparison
3. **Return empty collection**: Never return null for collection methods
4. **Log operations**: Debug for entry, Info for results
5. **Static test data**: Use `static readonly` for shared test data
