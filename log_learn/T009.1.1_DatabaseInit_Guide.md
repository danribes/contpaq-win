# T009.1.1 Learning Guide: Database Initialization

## Overview

This guide covers implementing SQLite database initialization and connection management in an Electron desktop application using better-sqlite3.

## Key Concepts

### 1. better-sqlite3

better-sqlite3 is a synchronous SQLite3 library for Node.js that's ideal for Electron apps:

```typescript
import Database from 'better-sqlite3';

// Open database
const db = new Database('/path/to/database.db');

// Execute query
db.exec('CREATE TABLE users (id TEXT PRIMARY KEY, name TEXT)');

// Prepare and run statements
const stmt = db.prepare('SELECT * FROM users WHERE id = ?');
const user = stmt.get('user-123');

// Close connection
db.close();
```

### 2. SQLite PRAGMAs

PRAGMAs configure SQLite behavior per-connection:

```typescript
// Enable Write-Ahead Logging for concurrency
db.pragma('journal_mode = WAL');

// Enable foreign key constraints
db.pragma('foreign_keys = ON');

// Check current setting
const result = db.pragma('foreign_keys');
```

### 3. Migration Pattern

Idempotent migrations using `IF NOT EXISTS`:

```sql
-- Idempotent table creation
CREATE TABLE IF NOT EXISTS vendors (
    id TEXT PRIMARY KEY,
    rfc TEXT UNIQUE NOT NULL
);

-- Idempotent index creation
CREATE INDEX IF NOT EXISTS idx_vendor_rfc ON vendors(rfc);
```

## Code Patterns

### Basic DatabaseService

```typescript
import Database from 'better-sqlite3';

export class DatabaseService {
  private db: Database.Database | null = null;

  constructor(private dbPath: string) {}

  async initialize(): Promise<void> {
    if (this.db) return; // Already initialized

    // Create parent directories
    const dir = path.dirname(this.dbPath);
    if (!fs.existsSync(dir)) {
      fs.mkdirSync(dir, { recursive: true });
    }

    // Open connection
    this.db = new Database(this.dbPath);

    // Configure
    this.db.pragma('journal_mode = WAL');
    this.db.pragma('foreign_keys = ON');

    // Run migrations
    await this.runMigrations();
  }

  async close(): Promise<void> {
    if (this.db) {
      this.db.close();
      this.db = null;
    }
  }

  getConnection(): Database.Database {
    if (!this.db) throw new Error('Not initialized');
    return this.db;
  }
}
```

### Running SQL Files

```typescript
private async runMigrations(): Promise<void> {
  const sql = fs.readFileSync(migrationPath, 'utf-8');
  this.db.exec(sql); // Executes multiple statements
}
```

## Testing Strategies

### 1. Temporary Database Files

```typescript
import * as os from 'os';
import * as fs from 'fs';

let tempDir: string;

beforeAll(() => {
  tempDir = fs.mkdtempSync(path.join(os.tmpdir(), 'test-'));
});

afterAll(() => {
  fs.rmSync(tempDir, { recursive: true });
});

beforeEach(() => {
  testDbPath = path.join(tempDir, `test-${Date.now()}.db`);
});
```

### 2. Testing Table Schema

```typescript
it('should create table with correct columns', async () => {
  await db.initialize();
  const conn = db.getConnection();

  const columns = conn.prepare('PRAGMA table_info(vendors)').all();
  const names = columns.map(c => c.name);

  expect(names).toContain('id');
  expect(names).toContain('rfc');
});
```

### 3. Testing Foreign Keys

```typescript
it('should enforce foreign key constraints', async () => {
  const conn = db.getConnection();

  expect(() => {
    conn.prepare('INSERT INTO invoices (vendor_id) VALUES (?)').run('bad-id');
  }).toThrow(/FOREIGN KEY constraint failed/);
});
```

### 4. Testing Cascade Delete

```typescript
it('should cascade delete', async () => {
  // Create parent and child records
  conn.prepare('INSERT INTO invoices (id) VALUES (?)').run('inv-1');
  conn.prepare('INSERT INTO line_items (invoice_id) VALUES (?)').run('inv-1');

  // Delete parent
  conn.prepare('DELETE FROM invoices WHERE id = ?').run('inv-1');

  // Child should be gone
  const child = conn.prepare('SELECT * FROM line_items WHERE invoice_id = ?').get('inv-1');
  expect(child).toBeUndefined();
});
```

## Common Pitfalls

### 1. Foreign Keys Not Enabled

**Problem**: Foreign key constraints don't work.

**Solution**: Enable per-connection (SQLite requirement):
```typescript
db.pragma('foreign_keys = ON');
```

### 2. Not Closing Connections

**Problem**: Resource leaks, locked database files.

**Solution**: Always close in cleanup:
```typescript
afterEach(async () => {
  await db.close();
});
```

### 3. WAL Mode Files

**Problem**: Extra files (.wal, .shm) after tests.

**Solution**: Close cleanly or delete temp directory:
```typescript
fs.rmSync(tempDir, { recursive: true, force: true });
```

## Best Practices

1. **Use WAL Mode**: Better concurrency for desktop apps
2. **Enable Foreign Keys**: Per-connection enforcement
3. **Idempotent Migrations**: Use `IF NOT EXISTS`
4. **Temp Directories for Tests**: Isolated test databases
5. **Graceful Cleanup**: Always close connections
6. **Path Resolution**: Support both dev and production paths
