# Learning Guide: T002.3.4 - Environment Files and Configuration

## What is .env.example?

`.env.example` is a template file that:
- Documents all environment variables
- Provides safe default values
- Can be committed to version control
- Serves as onboarding documentation

```
.env.example  ← Committed (template with defaults)
.env          ← NOT committed (actual secrets)
```

## Why Two Files?

### .env.example (Committed)
```env
# Database connection
DATABASE_URL=postgresql://localhost/myapp

# API keys (use your own)
API_KEY=your-api-key-here
```

### .env (Not Committed)
```env
# Actual values for this machine
DATABASE_URL=postgresql://user:secret@prod-server/myapp
API_KEY=sk-abc123-real-key
```

## .gitignore Configuration

```gitignore
# Environment files
.env
.env.local
.env.*.local

# But NOT .env.example
!.env.example
```

## Anatomy of a Good .env.example

### 1. Header Comment
```env
# ContPAQ-Win AI Service - Environment Configuration
# Copy this file to .env and adjust values as needed.
# Do NOT commit .env to version control.
```

### 2. Grouped Sections
```env
# ===================
# Server Settings
# ===================
HOST=127.0.0.1
PORT=8000

# ===================
# Database
# ===================
DB_HOST=localhost
DB_PORT=5432
```

### 3. Explanatory Comments
```env
# Server host address
# Default: 127.0.0.1 (localhost only - recommended for security)
# Use 0.0.0.0 only for development when network access is needed
HOST=127.0.0.1
```

### 4. Platform-Specific Notes
```env
# Path to Tesseract OCR executable
# Windows: C:\Program Files\Tesseract-OCR\tesseract.exe
# Linux: /usr/bin/tesseract
# Mac (Homebrew): /usr/local/bin/tesseract
TESSERACT_PATH=C:\Program Files\Tesseract-OCR\tesseract.exe
```

## Developer Workflow

### Initial Setup
```bash
# 1. Clone repository
git clone https://github.com/company/project.git
cd project

# 2. Copy example to .env
cp ai-service/.env.example ai-service/.env

# 3. Edit with your values
code ai-service/.env  # or vim, nano, etc.

# 4. Run the application
cd ai-service
python -m uvicorn main:app
```

### Adding New Settings

When adding a new setting:

1. **Add to config.py**:
```python
class Settings(BaseSettings):
    NEW_SETTING: str = "default"
```

2. **Add to .env.example**:
```env
# Description of new setting
NEW_SETTING=default
```

3. **Update documentation** if needed

## Environment File Format

### Basic Format
```env
KEY=value
```

### With Quotes (optional)
```env
MESSAGE="Hello World"
PATH='C:\Program Files'
```

### Multi-line Values
```env
# Use quotes for multi-line
PRIVATE_KEY="-----BEGIN RSA KEY-----
MIIEpAIBAAKCAQEA...
-----END RSA KEY-----"
```

### Variable References (some tools support)
```env
BASE_URL=http://localhost
API_URL=${BASE_URL}/api
```

## Common Patterns

### Secrets Template
```env
# Replace with your actual API key
API_KEY=your-api-key-here
SECRET_KEY=generate-a-random-string
```

### Feature Flags
```env
# Enable/disable features (true/false)
ENABLE_DEBUG=false
ENABLE_CACHE=true
```

### URLs and Endpoints
```env
# External service URLs
DATABASE_URL=postgresql://localhost:5432/myapp
REDIS_URL=redis://localhost:6379
```

## Pydantic Settings Integration

### How Settings Loads .env

```python
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    HOST: str = "127.0.0.1"

    model_config = SettingsConfigDict(
        env_file=".env",           # ← Loads this file
        env_file_encoding="utf-8",
    )
```

### Priority Order

1. **Environment variables** (highest)
2. **.env file**
3. **Default values** (lowest)

```bash
# Environment variable wins
HOST=0.0.0.0 python main.py
# settings.HOST == "0.0.0.0" (ignores .env and default)
```

## Security Best Practices

### 1. Never Commit Secrets
```gitignore
.env
*.pem
*.key
credentials.json
```

### 2. Use Placeholder Values
```env
# BAD - actual secret in example
API_KEY=sk-abc123-real-key

# GOOD - placeholder
API_KEY=your-api-key-here
```

### 3. Document Security Settings
```env
# SECURITY: Keep this localhost in production!
# Changing to 0.0.0.0 exposes API to network
HOST=127.0.0.1
```

### 4. Validate on Startup
```python
def validate_settings():
    if settings.API_KEY == "your-api-key-here":
        raise ValueError("Please set a real API_KEY in .env")
```
