# T008.1.1 Learning Guide: Testing Electron Process Management

## Overview

This guide explains how to test process management code in Electron applications using Jest, particularly for managing external service processes.

## Key Concepts

### 1. Process Management in Electron

Electron's main process can spawn and manage child processes. The ProcessManager pattern encapsulates this:

```typescript
import { ChildProcess, spawn } from 'child_process';

export class ProcessManager {
  private aiServiceProcess: ChildProcess | null = null;

  async startAIService(): Promise<void> {
    this.aiServiceProcess = spawn('python', ['-m', 'uvicorn', 'main:app']);
  }
}
```

### 2. Service Status State Machine

```
STOPPED --> STARTING --> RUNNING --> STOPPING --> STOPPED
              |                          |
              v                          v
            ERROR <-------------------ERROR
```

```typescript
export enum ServiceStatus {
  STOPPED = 'stopped',
  STARTING = 'starting',
  RUNNING = 'running',
  STOPPING = 'stopping',
  ERROR = 'error',
}
```

### 3. Testing Strategy

#### Mock Native Modules

```typescript
// Mock child_process
jest.mock('child_process', () => ({
  spawn: jest.fn(),
  ChildProcess: jest.fn(),
}));

// Mock electron
jest.mock('electron', () => ({
  app: {
    getAppPath: jest.fn().mockReturnValue('/mock/path'),
    getPath: jest.fn().mockReturnValue('/mock/data'),
    isPackaged: false,
  },
}));
```

#### Test State Transitions

```typescript
it('should transition status to STARTING then RUNNING', async () => {
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.STOPPED);

  const startPromise = manager.startAIService();
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.STARTING);

  await startPromise;
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.RUNNING);
});
```

#### Test Idempotency

```typescript
it('should not start if already running', async () => {
  await manager.startAIService();
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.RUNNING);

  // Second call should be no-op
  await manager.startAIService();
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.RUNNING);
});
```

## Best Practices

### 1. Stub-First Development

Create stubs that satisfy interface contracts:

```typescript
async startAIService(): Promise<void> {
  if (this.aiServiceStatus === ServiceStatus.RUNNING) {
    return; // Guard clause
  }

  this.aiServiceStatus = ServiceStatus.STARTING;

  // Stub: simulate async start
  return new Promise((resolve) => {
    setTimeout(() => {
      this.aiServiceStatus = ServiceStatus.RUNNING;
      resolve();
    }, 100);
  });
}
```

### 2. Independent Service Tracking

```typescript
// Separate status for each service
private aiServiceStatus: ServiceStatus = ServiceStatus.STOPPED;
private bridgeServiceStatus: ServiceStatus = ServiceStatus.STOPPED;
```

### 3. Batch Operations

```typescript
async startAll(): Promise<void> {
  await Promise.all([
    this.startAIService(),
    this.startBridgeService(),
  ]);
}
```

### 4. Module Path Mapping in Jest

```json
// jest config in package.json
{
  "moduleNameMapper": {
    "^@main/(.*)$": "<rootDir>/src/main/$1",
    "^@renderer/(.*)$": "<rootDir>/src/renderer/$1"
  }
}
```

## Testing Patterns

### Testing Async Methods

```typescript
it('should return a Promise', () => {
  const result = manager.startAIService();
  expect(result).toBeInstanceOf(Promise);
  return result; // Let Jest handle the promise
});
```

### Testing Getters

```typescript
it('should have getAIServiceStatus method', () => {
  expect(manager.getAIServiceStatus).toBeDefined();
  expect(typeof manager.getAIServiceStatus).toBe('function');
});
```

### Testing Initial State

```typescript
it('should return STOPPED for initial AI service status', () => {
  expect(manager.getAIServiceStatus()).toBe(ServiceStatus.STOPPED);
});
```
