# T018.2 Learning Log: Confidence Utilities

## Date: 2025-12-18

## Key Learnings

### 1. Mirroring Logic Across Languages

**Pattern**: Keep business logic consistent between Python and TypeScript:

Python:
```python
CONFIDENCE_HIGH = 90
CONFIDENCE_MEDIUM = 70

def get_confidence_level(confidence: int) -> ConfidenceLevel:
    if confidence >= CONFIDENCE_HIGH:
        return ConfidenceLevel.HIGH
    if confidence >= CONFIDENCE_MEDIUM:
        return ConfidenceLevel.MEDIUM
    return ConfidenceLevel.LOW
```

TypeScript:
```typescript
export const CONFIDENCE_THRESHOLDS = {
  HIGH: 90,
  MEDIUM: 70,
} as const;

export function getConfidenceLevel(confidence: number): ConfidenceLevel {
  if (confidence >= CONFIDENCE_THRESHOLDS.HIGH) return 'high';
  if (confidence >= CONFIDENCE_THRESHOLDS.MEDIUM) return 'medium';
  return 'low';
}
```

**Benefits**:
- Single source of truth for thresholds
- Consistent behavior across full stack
- Easy to update in both places

### 2. Python Enum with String Value

**Pattern**: Use `str, Enum` for JSON-serializable enums:
```python
class ConfidenceLevel(str, Enum):
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
```

**Benefits**:
- Enum members are also strings: `ConfidenceLevel.HIGH == "high"`
- JSON serializable without custom encoder
- Type-safe while being practical

### 3. Supporting Multiple Scales

**Pattern**: Provide functions for both percentage (0-100) and decimal (0-1) scales:
```python
# For 0-100 scale (UI/user-facing)
def get_confidence_level(confidence: int | float) -> ConfidenceLevel:
    if confidence >= CONFIDENCE_HIGH:  # 90
        return ConfidenceLevel.HIGH

# For 0-1 scale (AI model output)
def get_confidence_level_decimal(confidence: float) -> ConfidenceLevel:
    if confidence >= CONFIDENCE_HIGH_DECIMAL:  # 0.90
        return ConfidenceLevel.HIGH
```

**Benefits**:
- Avoid conversion errors
- Clear intent at call site
- Match data source scale

### 4. Conversion Utilities

**Pattern**: Provide explicit conversion functions:
```python
def decimal_to_percentage(decimal: float) -> int:
    return round(decimal * 100)

def percentage_to_decimal(percentage: int | float) -> float:
    return percentage / 100
```

**Why?**: Prevent subtle bugs from inconsistent conversions scattered throughout codebase.

### 5. Normalization as Defensive Programming

**Pattern**: Normalize input to valid range:
```python
def normalize_confidence(confidence: int | float) -> int:
    if confidence < 0:
        return 0
    if confidence > 100:
        return 100
    return round(confidence)
```

**Why?**:
- Handle invalid data gracefully
- Prevent crashes from edge cases
- Consistent behavior regardless of input

### 6. Package Re-exports

**Pattern**: Re-export from package `__init__.py`:
```python
# src/utils/__init__.py
from .confidence import (
    get_confidence_level,
    ConfidenceLevel,
    CONFIDENCE_HIGH,
)

__all__ = [
    "get_confidence_level",
    "ConfidenceLevel",
    "CONFIDENCE_HIGH",
]
```

**Benefits**:
- Clean import paths: `from src.utils import get_confidence_level`
- Explicit public API
- IDE autocomplete works better

### 7. Localized Labels

**Pattern**: Keep translations close to the logic:
```python
CONFIDENCE_LABELS: Dict[ConfidenceLevel, str] = {
    ConfidenceLevel.HIGH: "Alto",
    ConfidenceLevel.MEDIUM: "Medio",
    ConfidenceLevel.LOW: "Bajo",
}
```

**Note**: For a full i18n solution, use a translation library. For MVP with single language target (Spanish), inline is acceptable.

## Best Practices Applied

1. **Pure Functions**: All functions have no side effects
2. **Type Hints**: Full type annotations for IDE support
3. **Docstrings**: Google-style docstrings with examples
4. **Comprehensive Tests**: 39 tests including edge cases
5. **Single Responsibility**: Module only handles confidence logic

## Design Decisions

1. **Why separate percentage/decimal functions?**: AI models typically output 0-1, UI shows 0-100
2. **Why Python Enum?**: Type safety + JSON serialization
3. **Why Spanish labels?**: Target audience is Mexican accountants
4. **Why export from __init__.py?**: Cleaner imports for consumers
