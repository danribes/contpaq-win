# T008.1.5 Learning Guide: Service Restart Patterns

## Overview

This guide explains how to implement robust service restart functionality with proper event emission, counter tracking, and error handling in Node.js/Electron applications.

## Key Concepts

### 1. True Restart vs Initial Start

A "true restart" is when a service was running and needs to be restarted. An "initial start" is when the service wasn't running:

```typescript
async restartService(): Promise<void> {
  // Track if this is a true restart
  const wasRunning = this.status === 'running' || this.status === 'starting';

  await this.stopService();

  if (wasRunning) {
    // Only for true restarts
    this.restartCount++;
    this.emitRestartEvent();
  }

  await this.startService();
}
```

### 2. Restart Counter Pattern

Track restart attempts for:
- Implementing max retry logic
- Monitoring service stability
- Triggering alerts after N restarts

```typescript
class ServiceManager {
  private restartCount: number = 0;

  getRestartCount(): number {
    return this.restartCount;
  }

  resetRestartCount(): void {
    this.restartCount = 0;
  }

  async restart(): Promise<void> {
    const wasRunning = this.isRunning();

    await this.stop();

    if (wasRunning) {
      this.restartCount++;
    }

    await this.start();
  }
}
```

### 3. Restart Event Pattern

Emit events to notify listeners of restart attempts:

```typescript
interface RestartEvent {
  service: string;
  restartCount: number;
  timestamp: Date;
}

class ServiceManager extends EventEmitter {
  private emitRestart(): void {
    this.emit('restart', {
      service: this.serviceName,
      restartCount: this.restartCount,
      timestamp: new Date(),
    });
  }
}
```

### 4. When to Emit Restart Event

Emit BEFORE the start attempt:

```typescript
async restart(): Promise<void> {
  await this.stop();

  this.restartCount++;
  this.emitRestart();  // Emit before start

  await this.start();  // May fail
}
```

**Why before start?**
- Listeners can track restart attempts even if start fails
- Useful for logging and monitoring
- Allows rate limiting based on restart attempts

### 5. Error Handling in Restart

Propagate errors but still track the restart attempt:

```typescript
async restart(): Promise<void> {
  const wasRunning = this.isRunning();

  await this.stop();

  // Track restart before attempting start
  if (wasRunning) {
    this.restartCount++;
    this.emitRestart();
  }

  // Error will propagate to caller
  await this.start();
}
```

## Advanced Patterns

### Max Restart Logic (for auto-restart)

```typescript
async autoRestart(): Promise<void> {
  const config = this.getConfig();

  if (this.restartCount >= config.maxRestartAttempts) {
    throw new Error(`Max restart attempts (${config.maxRestartAttempts}) exceeded`);
  }

  await this.restart();
}
```

### Exponential Backoff

```typescript
async restartWithBackoff(): Promise<void> {
  const config = this.getConfig();
  const delay = config.restartBackoffMs * Math.pow(2, this.restartCount);

  await new Promise(resolve => setTimeout(resolve, delay));
  await this.restart();
}
```

### Reset Counter on Successful Run

```typescript
// In health check or status update
if (this.status === 'running' && this.uptimeMs > STABLE_THRESHOLD) {
  this.resetRestartCount();
}
```

## TypeScript Patterns

### Union Event Types

When emitting different event types:

```typescript
type ServiceEvent = StatusChangeEvent | RestartEvent;

type EventListener = (event: ServiceEvent) => void;

private emit(eventType: string, event: ServiceEvent): void {
  const listeners = this.listeners.get(eventType);
  listeners?.forEach(listener => listener(event));
}
```

### Type Guards for Event Handling

```typescript
function isRestartEvent(event: ServiceEvent): event is RestartEvent {
  return 'restartCount' in event;
}

manager.on('restart', (event) => {
  if (isRestartEvent(event)) {
    console.log(`Restart #${event.restartCount}`);
  }
});
```

## Testing Patterns

### Testing Counter Increment

```typescript
it('should increment on restart', async () => {
  await startService();
  expect(manager.getRestartCount()).toBe(0);

  await manager.restart();
  expect(manager.getRestartCount()).toBe(1);
});
```

### Testing No Increment on Initial Start

```typescript
it('should not increment for initial start', async () => {
  expect(manager.getStatus()).toBe('stopped');
  expect(manager.getRestartCount()).toBe(0);

  await manager.restart();  // This is actually just a start

  expect(manager.getRestartCount()).toBe(0);  // No increment
});
```

### Testing Event Emission

```typescript
it('should emit restart event', async () => {
  await startService();

  const listener = jest.fn();
  manager.on('restart', listener);

  await manager.restart();

  expect(listener).toHaveBeenCalledWith(
    expect.objectContaining({
      service: 'ai',
      restartCount: 1,
    })
  );
});
```

## Best Practices

1. **Track true restarts**: Only increment counter when service was actually running
2. **Emit before start**: Allows tracking restart attempts even on failure
3. **Propagate errors**: Let callers handle failures appropriately
4. **Provide reset**: Allow counter reset for manual recovery
5. **Include metadata**: Include restart count, service name, timestamp in events
