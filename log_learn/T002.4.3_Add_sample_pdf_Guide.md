# Learning Guide: T002.4.3 - PDF File Format Basics

## PDF File Structure

PDF (Portable Document Format) is a text-based format with binary content.

### Basic PDF Structure

```
%PDF-1.4              ← Header (version)
1 0 obj               ← Objects (numbered)
...
endobj
...
xref                  ← Cross-reference table
...
trailer               ← Document metadata
startxref             ← Offset to xref
%%EOF                 ← End of file marker
```

### Key Components

1. **Header**: `%PDF-1.x` - Version declaration
2. **Objects**: Numbered content (pages, fonts, images)
3. **Cross-reference (xref)**: Index of object locations
4. **Trailer**: Root catalog reference
5. **EOF marker**: `%%EOF`

## Text-Based vs Scanned PDFs

### Text-Based PDF

```
4 0 obj
<< /Length 100 >>
stream
BT                    ← Begin Text
/F1 12 Tf             ← Set font
100 700 Td            ← Position
(Hello World) Tj      ← Draw text
ET                    ← End Text
endstream
endobj
```

- Text is stored as text operators
- Extractable with PyMuPDF, pdfplumber
- Small file sizes
- Searchable

### Scanned PDF (Image-Based)

```
4 0 obj
<< /Type /XObject /Subtype /Image
   /Width 2480 /Height 3508
   /Filter /DCTDecode >>  ← JPEG encoded
stream
... binary image data ...
endstream
endobj
```

- Text stored as pixel images
- Requires OCR for extraction
- Large file sizes
- Not searchable without OCR

## Detecting PDF Type

### Method 1: Text Content Check

```python
import fitz  # PyMuPDF

def is_text_based(pdf_path):
    doc = fitz.open(pdf_path)
    text = doc[0].get_text()
    return len(text.strip()) > 50  # Has significant text
```

### Method 2: Check for Text Streams

```python
def has_text_streams(pdf_path):
    with open(pdf_path, "rb") as f:
        content = f.read()
    return b"BT" in content  # Begin Text marker
```

## Mexican Invoice (CFDI) Structure

### Required Fields

| Field | Spanish | Description |
|-------|---------|-------------|
| RFC Emisor | RFC del emisor | Sender tax ID (12-13 chars) |
| RFC Receptor | RFC del receptor | Receiver tax ID |
| Folio | Número de factura | Invoice number |
| Fecha | Fecha de emisión | Issue date |
| Subtotal | Subtotal | Before taxes |
| IVA | IVA (16%) | Value Added Tax |
| Total | Total | Final amount |

### RFC Format

```
Persona Moral (Company): ABC123456789  (12 chars)
  - 3 letters + 6 digits + 3 alphanumeric

Persona Física (Individual): ABCD123456XYZ (13 chars)
  - 4 letters + 6 digits + 3 alphanumeric
```

## Creating Test PDFs

### Method 1: Raw PDF Format

```python
pdf_content = b"""%PDF-1.4
1 0 obj
<< /Type /Catalog /Pages 2 0 R >>
endobj
...
%%EOF
"""

with open("test.pdf", "wb") as f:
    f.write(pdf_content)
```

### Method 2: Using ReportLab

```python
from reportlab.pdfgen import canvas

c = canvas.Canvas("invoice.pdf")
c.drawString(100, 750, "FACTURA")
c.drawString(100, 700, "RFC: ABC123456789")
c.save()
```

### Method 3: Using fpdf2

```python
from fpdf import FPDF

pdf = FPDF()
pdf.add_page()
pdf.set_font("Helvetica", size=12)
pdf.cell(200, 10, txt="FACTURA", ln=True)
pdf.output("invoice.pdf")
```

## PDF Text Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| BT | Begin text object | BT |
| ET | End text object | ET |
| Tf | Set font and size | /F1 12 Tf |
| Td | Move to position | 100 700 Td |
| Tj | Show text string | (Hello) Tj |
| TJ | Show text with kerning | [(H) 120 (ello)] TJ |

## Testing PDF Fixtures

### Basic Validation

```python
def test_pdf_valid(pdf_path):
    with open(pdf_path, "rb") as f:
        header = f.read(5)
    assert header == b"%PDF-"
```

### Content Validation

```python
def test_pdf_has_invoice_content(pdf_path):
    with open(pdf_path, "rb") as f:
        content = f.read().decode("latin-1", errors="ignore")
    assert "RFC" in content
    assert "FACTURA" in content or "Total" in content
```
