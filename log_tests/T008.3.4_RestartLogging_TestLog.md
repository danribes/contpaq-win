## Key Test Patterns

### Using Console Spies

```typescript
let consoleLogSpy: jest.SpyInstance;
let consoleWarnSpy: jest.SpyInstance;

beforeEach(() => {
  consoleLogSpy = jest.spyOn(console, 'log').mockImplementation();
  consoleWarnSpy = jest.spyOn(console, 'warn').mockImplementation();
});

afterEach(() => {
  consoleLogSpy.mockRestore();
  consoleWarnSpy.mockRestore();
});
```

### Testing Log Message Content

```typescript
it('should include attempt number in log', async () => {
  // Setup manager and start service
  manager = new ProcessManager({
    enableAutoRestart: true,
    restartBackoffMs: 10,
  });

  await manager.startAIService();
  consoleLogSpy.mockClear();

  // Crash service
  processes[0].emit('exit', 1, null);

  // Verify log contains attempt number
  expect(consoleLogSpy).toHaveBeenCalledWith(
    expect.stringContaining('attempt 1')
  );
});
```

### Testing Warning on Max Exceeded

```typescript
it('should warn when max restarts exceeded', async () => {
  manager = new ProcessManager({
    enableAutoRestart: true,
    maxRestarts: 1,
  });

  await manager.startAIService();

  // First crash - restarts
  processes[0].emit('exit', 1, null);
  jest.advanceTimersByTime(30);

  consoleWarnSpy.mockClear();

  // Second crash - exceeds max
  processes[1].emit('exit', 1, null);

  expect(consoleWarnSpy).toHaveBeenCalledWith(
    expect.stringContaining('Max restarts')
  );
});
```

### Clearing Logs Before Test

```typescript
// Start service (which logs)
await manager.startAIService();

// Clear startup logs
consoleLogSpy.mockClear();

// Now test specific behavior
processes[0].emit('exit', 1, null);
```

## Notes

1. **Console Spies**: Required to capture and verify log output

2. **Mock Clear**: Clear spy before testing specific log to avoid startup logs

3. **stringContaining**: Use for flexible matching without exact message

4. **Different Spy Levels**: Separate spies for log/warn/error

5. **Restore After**: Always restore spies in afterEach to prevent leaks
