## Test Cases Description

### test_sample_pdf_exists
**Purpose**: Verify sample_invoice.pdf exists in fixtures directory
**Assertion**: `os.path.isfile(pdf_path)` returns True

### test_sample_pdf_is_valid_pdf
**Purpose**: Verify file has valid PDF magic bytes header
**Assertion**: First 5 bytes equal `b"%PDF-"`

### test_sample_pdf_not_empty
**Purpose**: Verify PDF file is not empty
**Assertion**: File size > 100 bytes (actual: 1,112 bytes)

### test_sample_pdf_is_text_based
**Purpose**: Verify PDF contains text streams (not image-based)
**Assertion**: Content contains `/Type` or `BT` (Begin Text marker)

### test_sample_pdf_contains_invoice_content
**Purpose**: Verify PDF contains invoice-related text
**Assertion**: Content contains "RFC", "Factura", "Total", or similar terms
