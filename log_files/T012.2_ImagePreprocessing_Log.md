#### ImagePreprocessor Class

```python
class ImagePreprocessor:
    def detect_skew_angle(self, image: Image.Image) -> float:
        """Detect rotation angle of text"""

    def deskew(self, image: Image.Image) -> Image.Image:
        """Correct image rotation"""

    def enhance_contrast(self, image: Image.Image, factor: float = 1.5) -> Image.Image:
        """Increase image contrast"""

    def reduce_noise(self, image: Image.Image, strength: int = 2) -> Image.Image:
        """Apply median filter for noise reduction"""

    def preprocess(self, image, deskew=True, enhance_contrast=True, reduce_noise=True) -> Image.Image:
        """Apply full preprocessing pipeline"""
```

#### T012.2.2 - Deskewing
- `detect_skew_angle()`: Analyzes horizontal gradients to find text angle
- `deskew()`: Rotates image using bicubic interpolation
- Returns angle in range -45 to 45 degrees
- White background fill for rotated areas

#### T012.2.3 - Contrast Enhancement
- `enhance_contrast()`: Uses PIL's ImageEnhance.Contrast
- Configurable factor (1.0 = original, >1.0 = more contrast)
- Default factor: 1.5 (50% increase)
- Preserves image mode (RGB/L)

#### T012.2.4 - Noise Reduction
- `reduce_noise()`: Uses PIL's MedianFilter
- Configurable strength (filter size)
- Automatically ensures odd filter size
- Effectively removes salt-and-pepper noise

### Preprocessing Pipeline
```python
# Full pipeline
```
