### Design Decisions

1. **PDF 1.4 format**: Wide compatibility with PDF libraries
2. **Text-based**: Uses text operators (BT/ET/Tf/Td/Tj) for extractable text
3. **Mexican invoice format**: Includes RFC, CFDI, and Spanish terminology
4. **Minimal structure**: Small file size, fast to load in tests
5. **Helvetica font**: Standard Type1 font, no embedded fonts needed
