### `get_model_path()` Implementation

```python
DEFAULT_MODEL_PATH = "./models/layoutlm"

def get_model_path() -> str:
    return os.environ.get("MODEL_PATH", DEFAULT_MODEL_PATH)
```

- Uses environment variable `MODEL_PATH` if set
- Falls back to `./models/layoutlm` default
- Configurable for different deployment environments

### `check_model_files()` Implementation

Checks for required HuggingFace transformer model files:
1. Directory exists (os.path.exists + os.path.isdir)
2. `config.json` exists (model configuration)
3. Model weights exist (`pytorch_model.bin` OR `model.safetensors`)

```python
def check_model_files() -> bool:
    model_path = get_model_path()
    if not os.path.exists(model_path) or not os.path.isdir(model_path):
        return False
    # Check config.json and model weights...
```

### `get_model_status()` Implementation

### Updated `check_models_loaded()`
