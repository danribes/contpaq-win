### Key Components

#### OCRService Class
```python
class OCRService:
    def __init__(self, language: str = "spa", dpi: int = 300):
        self.language = language
        self.languages = [language]
        self.dpi = dpi

    def convert_page_to_image(self, pdf_path, page_num) -> Image.Image:
        """Convert PDF page to PIL Image at 300 DPI"""

    def extract_with_ocr(self, pdf_path, pages=None) -> List[OCRResult]:
        """Extract text with bounding boxes and confidence"""
```

#### OCRResult Type
```python
OCRResult = Dict[str, Union[str, int, float, Dict[str, float]]]

# Example structure:
{
    "text": "FACTURA",
    "page": 0,
    "bbox": {
        "x0": 100.0,
        "y0": 50.0,
        "x1": 200.0,
        "y1": 80.0
    },
    "confidence": 95.5
}
```

### Features Implemented

#### T012.1.1 - test_ocr_extraction.py
- 18 tests covering all OCR functionality
- Tests for image conversion, text extraction, bounding boxes, confidence

#### T012.1.2 - ocr_service.py
- OCRService class with configurable language and DPI
- Uses PyMuPDF for PDF to image conversion
- Uses pytesseract for OCR processing

#### T012.1.3 - extract_with_ocr() Method
- **T012.1.3.1**: Convert PDF page to image at 300 DPI
  - Uses PyMuPDF matrix scaling: `zoom = 300 / 72`
  - Converts pixmap to PIL Image
- **T012.1.3.2**: Run Tesseract with Spanish language
  - Uses `pytesseract.image_to_data()` for detailed output
  - Language set to "spa" (Spanish)
- **T012.1.3.3**: Extract text with bounding boxes
  - Coordinates: x0, y0 (top-left), x1, y1 (bottom-right)
  - Page number included for multi-page PDFs
- **T012.1.3.4**: Calculate confidence per text block
  - Tesseract provides confidence as 0-100 percentage
  - Filters out results with confidence = -1 (no text)
