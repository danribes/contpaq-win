### PDF Structure

```
sample_scanned_invoice.pdf
├── PDF 1.4 header
├── Catalog object (obj 1)
├── Pages object (obj 2)
├── Page object (obj 3) - references XObject
├── Content stream (obj 4) - draws image
└── Image XObject (obj 5) - grayscale image
```

### Image Properties

| Property | Value |
|----------|-------|
| Dimensions | 100 x 150 pixels |
| Color Space | DeviceGray |
| Bits Per Component | 8 |
| Compression | FlateDecode (zlib) |
| Format | Grayscale with variation |

### Design Decisions

1. **Image-based content**: PDF contains image XObject, not text streams
2. **Small dimensions**: 100x150 for fast testing, minimal file size
3. **Grayscale**: Simulates black/white scanned document
4. **Compressed**: Uses FlateDecode to reduce size
5. **Simple pattern**: Variable gray values simulate scanned text

### Key Differences from Text PDF

| Aspect | Text PDF | Scanned PDF |
|--------|----------|-------------|
| Content | BT/ET text operators | Image XObject |
| Extractable | Yes, via text parsing | No, requires OCR |
| Size | 1,112 bytes | 812 bytes |
| Object type | Content stream | /Subtype /Image |

### Technical Notes

```python
# Image XObject definition
<< /Type /XObject /Subtype /Image
   /Width 100 /Height 150
   /ColorSpace /DeviceGray /BitsPerComponent 8
   /Filter /FlateDecode /Length ... >>
```
