### T013.2.4 - Implement extract_fields() method

#### T013.2.4.1 - Prepare input tokens from text + layout
- `prepare_input()` processes text blocks with bounding boxes
- Normalizes coordinates to 0-1000 range (LayoutLM format)
- Splits text into words for tokenization
- Creates dummy image for processor

#### T013.2.4.2 - Run model inference
- `run_inference()` executes model forward pass
- Returns logits and predictions
- Handles torch import dynamically
- Proper error handling with logging

#### T013.2.4.3 - Parse model output to structured fields
- `parse_output()` groups BIO-tagged tokens
- `_parse_prediction_dicts()` for test mock format
- `_parse_prediction_array()` for numpy output
- Groups B-/I- prefixed labels into complete fields

#### T013.2.4.4 - Calculate confidence scores per field
- `calculate_field_confidence()` computes mean of token scores
- Handles empty score lists
- Returns 0.0-1.0 range

### T013.2.5 - Implement field mapping to Mexican invoice schema

#### T013.2.5.1-5 - Map all invoice fields
- `map_to_invoice_schema()` creates `InvoiceExtraction` object
- Maps vendor_rfc, vendor_name fields
- Maps invoice_number, invoice_date fields
- Maps subtotal, iva_amount, total fields
- Creates `ExtractionField` objects with confidence and bbox
- Handles missing fields gracefully
