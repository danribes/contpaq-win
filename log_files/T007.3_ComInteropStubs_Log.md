## Key Design Decisions

1. **Stub Pattern**: All methods return false/null until real SDK available
2. **IDisposable**: Proper resource cleanup pattern
3. **Registry Check**: Look in both 64-bit and WOW6432Node paths
4. **Error Tracking**: GetLastError/GetLastErrorMessage for debugging
