## Algorithm Design
1. **Table Detection**: Find rows with header keywords (Descripción, Cantidad, etc.)
2. **Column Mapping**: Map headers to x-coordinate ranges
3. **Row Grouping**: Cluster blocks with similar y-coordinates (±15px tolerance)
4. **Data Extraction**: Assign blocks to columns, parse values
5. **Validation**: Verify amount = quantity * unit_price
