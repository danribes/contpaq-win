#### emitRestart Method Update
```typescript
private emitRestart(
  service: 'ai' | 'bridge',
  restartCount: number,
  reason?: string,
  delay?: number
): void {
  const event: RestartEvent = {
    service,
    restartCount,
    timestamp: new Date(),
  };
  if (reason) event.reason = reason;
  if (delay !== undefined) event.delay = delay;
  this.emit('restart', event);
}
```

## Architecture

```
Crash Detected
    │
    └── handleAutoRestart()
        │
        ├── Calculate delay = baseDelay * 2^(count-1)
        │   ├── count=1: 1000 * 1 = 1000ms
        │   ├── count=2: 1000 * 2 = 2000ms
        │   └── count=3: 1000 * 4 = 4000ms
        │
        ├── Emit restart event (includes delay)
        │
        └── setTimeout(startService, delay)
```

## Exponential Backoff Pattern

| Restart Count | Delay Calculation | Default Delay |
|---------------|-------------------|---------------|
| 1 | 1000 × 2^0 | 1000ms (1s) |
| 2 | 1000 × 2^1 | 2000ms (2s) |
| 3 | 1000 × 2^2 | 4000ms (4s) |
| 4 | 1000 × 2^3 | 8000ms (8s) |
| 5 | 1000 × 2^4 | 16000ms (16s) |
