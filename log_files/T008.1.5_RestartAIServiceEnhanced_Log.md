## Implementation Details

### What Was Enhanced

The `restartAIService()` method already had a basic implementation (stop + start). This task enhanced it with:

1. **Restart Counter Tracking**: Increments counter only for true restarts
2. **Restart Event Emission**: Emits 'restart' event with count information
3. **Proper Error Propagation**: Errors from start are propagated to caller

#### 3. New emitRestart Method

```typescript
private emitRestart(service: 'ai' | 'bridge', restartCount: number): void {

```

#### 4. Enhanced restartAIService Method
```typescript
async restartAIService(): Promise<void> {
  // T008.1.5: Track if this is a true restart (service was running)
  const wasRunning = this.aiServiceStatus === ServiceStatus.RUNNING ||
                     this.aiServiceStatus === ServiceStatus.STARTING;

  await this.stopAIService();

  // T008.1.5: Increment restart counter only for true restarts
  if (wasRunning) {
    this.aiRestartCount++;
  }

  // T008.1.5: Emit restart event before attempting start (for true restarts)
  if (wasRunning) {
    this.emitRestart('ai', this.aiRestartCount);
  }

  // Start the service (may throw if start fails)
  await this.startAIService();
}
```

### Key Design Decisions

1. **True Restart Detection**: Only counts as a restart if service was in RUNNING or STARTING state
2. **Event Before Start**: Restart event emitted before start, allowing listeners to track restart attempts even if start fails
3. **Counter Increment Before Start**: Counter incremented before start attempt so failed restarts are still counted

## Usage Example

```typescript
const manager = new ProcessManager();

// Listen for restart events
manager.on('restart', (event) => {
  console.log(`Service ${event.service} restarted (count: ${event.restartCount})`);
});

// Start service
await manager.startAIService();

// Later, restart it
await manager.restartAIService();
// Logs: Service ai restarted (count: 1)

// Check restart count
console.log(manager.getRestartCount('ai')); // 1

// Reset counter if needed
manager.resetRestartCount('ai');
```
