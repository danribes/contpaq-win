### Design Decisions

1. **CPU-only PyTorch**: Using `torch==2.1.2+cpu` to minimize installation size on Windows machines without GPU
2. **Pinned versions**: All dependencies have exact versions for reproducible builds
3. **Pydantic v2**: Using latest pydantic for improved performance and type hints
4. **Additional utilities**: Added `python-multipart` for file uploads and `aiofiles` for async I/O
