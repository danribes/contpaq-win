## Service API

```csharp
public interface IEntryService
{
    Task<EntryResultDto> CreateAsync(CreateEntryRequest entry);
    Task<DuplicateCheckResult> CheckDuplicateAsync(string vendorRfc, string invoiceNumber, DateTime invoiceDate);
    Task<EntryResultDto?> GetByFolioAsync(string folio);
}
```

## Folio Format
Entries are assigned folios in the format: `POL-{year}-{counter:D4}`
- Example: POL-2024-0001, POL-2024-0002

## Duplicate Check Logic
Entries are considered duplicates if they match on:
- VendorRfc (case-insensitive)
- InvoiceNumber (case-insensitive)
