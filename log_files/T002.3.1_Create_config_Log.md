```python
"""
ContPAQ-Win AI Service - Configuration Module
...
"""

from functools import lru_cache
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    """Application settings with environment variable support."""

    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        case_sensitive=False,
        extra="ignore",
    )

    # Settings will be defined in subsequent tasks


@lru_cache
def get_settings() -> Settings:
    """Get cached settings instance."""
    return Settings()


settings = get_settings()
```

### Components Defined

| Component | Purpose |
|-----------|---------|
| `Settings` class | Main configuration class inheriting from BaseSettings |
| `model_config` | Pydantic v2 configuration for .env file support |
| `get_settings()` | Cached factory function for singleton pattern |
| `settings` | Convenience export for direct import |

### Design Decisions

1. **Pydantic v2 syntax**: Uses `model_config = SettingsConfigDict(...)` instead of nested `Config` class
2. **lru_cache**: Ensures settings are loaded only once (singleton pattern)
3. **Convenience export**: `settings = get_settings()` allows `from src.config import settings`
4. **Extra ignore**: Unknown environment variables are ignored rather than raising errors
5. **Case insensitive**: Environment variables can be any case

### Configuration Priority

Settings are loaded in this priority order (highest first):
1. Environment variables
2. `.env` file values
3. Default values in Settings class
