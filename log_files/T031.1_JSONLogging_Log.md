## Key Implementation Details

### JSON Log Format

Each log entry contains:
```json
{
  "timestamp": "2025-12-18T12:34:56.789Z",
  "level": "INFO",
  "logger": "contpaq.ai.module_name",
  "message": "Log message here",
  "module": "module_name",
  "function": "function_name",
  "line": 42,
  "service": "ai-service",
  "process_id": 1234,
  "thread_id": 5678
}
```

### Exception Handling

When exceptions are logged, additional fields are included:
```json
{
  "exception": {
    "type": "ValueError",
    "message": "Error description",
    "traceback": ["...stack trace lines..."]
  }
}
```

### Log File Location

- **Windows**: `%LOCALAPPDATA%\ContPAQ-Win\Logs\ai-service.log`
- **Linux/Mac**: `~/.contpaq-win/logs/ai-service.log`

### Log Rotation

Uses `RotatingFileHandler` with:
- Maximum 10 MB per log file
- Keeps 5 backup files
- UTF-8 encoding

## Usage Example

```python
from utils.logging_config import setup_logging, get_logger

# Initialize at application startup
setup_logging(level="INFO")

# Get logger in any module
logger = get_logger(__name__)

# Log with context
logger.info("Invoice processed", extra={
    "invoice_id": "INV-001",
    "duration_ms": 150,
    "pdf_pages": 3
})
```
