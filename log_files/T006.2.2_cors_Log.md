### CORS Configuration

```python
from fastapi.middleware.cors import CORSMiddleware

# CORS Configuration - localhost only for security
ALLOWED_ORIGINS = [
    "http://localhost:3000",
    "http://localhost:8080",
    "http://localhost:5000",
    "http://127.0.0.1:3000",
    "http://127.0.0.1:8080",
    "http://127.0.0.1:5000",
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=ALLOWED_ORIGINS,
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS"],
    allow_headers=["*"],
)
```

### Security Features

1. **Localhost Only**: Origins restricted to localhost/127.0.0.1
2. **No Wildcard**: Does not use `*` for origins
3. **Common Ports**: Supports ports 3000, 8080, 5000
4. **Full Method Support**: GET, POST, PUT, DELETE, OPTIONS
