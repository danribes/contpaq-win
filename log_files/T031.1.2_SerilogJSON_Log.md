## Key Implementation Details

### Compact JSON Format

Uses Serilog's CompactJsonFormatter which produces logs like:
```json
{"@t":"2025-12-18T12:34:56.789Z","@l":"Information","@m":"Processing invoice","InvoiceId":"INV-001","Amount":1500.50,"MachineName":"DESKTOP-ABC","ProcessId":1234,"ServiceName":"windows-bridge"}
```

Field mappings:
- `@t` - Timestamp (ISO 8601)
- `@l` - Level (Information, Warning, Error, etc.)
- `@m` - Message
- `@x` - Exception (if present)
- Custom properties are included at root level

### Log File Location

- **Windows**: `%LOCALAPPDATA%\ContPAQ-Win\Logs\windows-bridge-YYYYMMDD.log`
- **Linux/Mac**: `~/.contpaq-win/logs/windows-bridge-YYYYMMDD.log`

### Log Rotation

- Daily rotation (`RollingInterval.Day`)
- Size limit: 10 MB per file
- Roll on size limit exceeded
- Keep 5 backup files
- Flush to disk every 1 second

### Enrichers

Each log entry includes:
- `MachineName` - Computer name
- `ProcessId` - Process identifier
- `ThreadId` - Thread identifier
- `ServiceName` - "windows-bridge"

### Log Level Filtering

```csharp
.MinimumLevel.Information()
.MinimumLevel.Override("Microsoft", LogEventLevel.Warning)
.MinimumLevel.Override("Microsoft.Hosting.Lifetime", LogEventLevel.Information)
.MinimumLevel.Override("System", LogEventLevel.Warning)
```
