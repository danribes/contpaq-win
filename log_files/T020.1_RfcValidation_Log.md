### T020.1.3 - Implement RFC format validation
Created `src/utils/validation.py` with:
- **Length check**: 12 or 13 characters
- **Pattern validation**:
  - Persona Física: 4 letters + 6 digits + 3 alphanumeric
  - Persona Moral: 3 letters + 6 digits + 3 alphanumeric

Response includes:

- `rfc_type`: "persona_fisica" or "persona_moral"
- `normalized_rfc`: Uppercase, trimmed version
- `error`: Spanish error message if invalid

## RFC Format Reference

### Persona Física (Individual) - 13 characters
```
XXXX YYMMDD XXX
└┬─┘ └──┬──┘ └┬┘
 │      │     └─ Homoclave (3 alphanumeric)
 │      └─────── Date of birth (YYMMDD)
 └────────────── Name initials (4 letters)
```

### Persona Moral (Company) - 12 characters
```
XXX YYMMDD XXX
└┬┘ └──┬──┘ └┬┘
 │     │     └─ Homoclave (3 alphanumeric)
 │     └─────── Constitution date (YYMMDD)
 └───────────── Company name initials (3 letters)
```

## API Usage Example

### Request
```bash
curl -X POST http://localhost:8000/validate/rfc \
  -H "Content-Type: application/json" \
  -d '{"rfc": "XAXX010101000"}'
```

### Response (Valid)
```json
{
  "valid": true,
  "rfc_type": "persona_fisica",
  "normalized_rfc": "XAXX010101000",
  "error": null
}
```

### Response (Invalid)
```json
{
  "valid": false,
  "rfc_type": null,
  "normalized_rfc": null,
  "error": "El RFC tiene longitud inválida (5 caracteres). Debe tener 12 o 13 caracteres"
}
```
