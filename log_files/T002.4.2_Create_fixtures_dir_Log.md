```python
"""
ContPAQ-Win AI Service - Test Fixtures Package

This package contains test fixture files for the AI service test suite:
```

### Planned Directory Structure


### Design Decisions

1. **Python package**: Making fixtures a package allows importing fixture paths in tests
2. **Empty __all__**: No exports needed from this package
3. **Detailed docstring**: Documents the purpose and structure of the fixtures directory

### Integration with conftest.py

The `FIXTURES_DIR` constant in conftest.py points to this directory:

