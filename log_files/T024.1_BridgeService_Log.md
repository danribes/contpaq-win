# T024.1 Implementation Log: Bridge Service Client

## Date: 2025-12-18

## Task Description
Create TypeScript HTTP client for the Desktop App to communicate with the Windows Bridge service. Provides methods for duplicate checking, entry creation, vendor lookup, and vendor creation.

### T024.1.2 - Create bridge-service.ts
Created BridgeServiceClient class:
- Default URL: http://localhost:5000
- Configurable timeout (default: 30000ms)
- Exports types for requests/responses

### T024.1.3 - Implement checkDuplicate() method
Checks for duplicate entries:
- POST /api/entries/check-duplicate
- Sends vendorRfc, invoiceNumber, invoiceDate
- Returns DuplicateCheckResult

### T024.1.4 - Implement createEntry() method
Creates new accounting entry:
- POST /api/entries
- Sends full entry data including line items
- Supports forceDuplicate flag
- Returns EntryResult with folio

### T024.1.5 - Implement getVendorByRfc() method
Gets vendor by RFC:
- GET /api/vendors/{rfc}
- Returns VendorResult or null if not found
- Handles 404 gracefully (returns null)

### T024.1.6 - Implement createVendor() method
Creates new vendor:
- POST /api/vendors
- Sends rfc, name, commercialName
- Returns VendorResult with assigned code

### T024.1.7 - Handle errors with Spanish messages
Error handling:
- BridgeServiceError class with statusCode and detail
- Preserves Spanish error messages from API
- Handles network errors with Spanish messages
- Handles timeout errors

## Service API

```typescript
// Create client
const client = new BridgeServiceClient('http://localhost:5000');

// Check for duplicate
const duplicate = await client.checkDuplicate({
  vendorRfc: 'XAXX010101000',
  invoiceNumber: 'FAC-001',
  invoiceDate: new Date(),
});

// Create entry
const entry = await client.createEntry({
  vendorRfc: 'XAXX010101000',
  invoiceNumber: 'FAC-001',
  invoiceDate: new Date(),
  subtotal: 1000,
  ivaAmount: 160,
  total: 1160,
  lineItems: [],
  forceDuplicate: false,
});

// Get vendor
const vendor = await client.getVendorByRfc('XAXX010101000');

// Create vendor
const newVendor = await client.createVendor({
  rfc: 'XAXX010101000',
  name: 'Proveedor SA de CV',
});

// Check health
const health = await client.checkHealth();
```
