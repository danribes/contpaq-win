## Implementation Details

### Objective
Add service path configuration settings for external dependencies: Tesseract OCR and LayoutLMv3 model.

### Settings Added

```python
# Service Paths (T002.3.3)

TESSERACT_PATH: str = "C:\\Program Files\\Tesseract-OCR\\tesseract.exe"
"""Path to Tesseract OCR executable. Windows default installation path."""

MODEL_PATH: str = "./models/layoutlm"
"""Path to LayoutLMv3 model directory. Relative to ai-service root."""
```

### Settings Summary

| Setting | Type | Default | Purpose |
|---------|------|---------|---------|
| `TESSERACT_PATH` | str | Windows default path | Location of Tesseract OCR executable |
| `MODEL_PATH` | str | ./models/layoutlm | Location of LayoutLMv3 model files |

### Design Decisions

1. **TESSERACT_PATH default**: Uses Windows default installation path (`C:\Program Files\Tesseract-OCR\tesseract.exe`) since the target platform is Windows
2. **MODEL_PATH relative**: Uses relative path from ai-service root for portability
3. **String type**: Both are strings to allow flexibility in path formats

### Platform Considerations

**Windows (Target Platform)**:
```
TESSERACT_PATH=C:\Program Files\Tesseract-OCR\tesseract.exe
```

**Linux/Mac (Development)**:
```bash
TESSERACT_PATH=/usr/bin/tesseract
```

### Environment Variable Override

```bash
# Override via environment variables
TESSERACT_PATH=/usr/local/bin/tesseract MODEL_PATH=/opt/models python main.py
```

### Path Validation (Future)

The actual path validation will be done at runtime when the services are initialized (T011, T012, T013):
- Check if TESSERACT_PATH exists and is executable
- Check if MODEL_PATH exists and contains required model files
