#### ApiResponse.cs
Generic and non-generic API response wrappers:

```csharp
public record ApiResponse<T>
{
    public bool Success { get; init; }
    public string? Message { get; init; }
    public T? Data { get; init; }
    public ErrorDetails? Error { get; init; }
    public DateTime Timestamp { get; init; }

    public static ApiResponse<T> Ok(T data, string? message = null);
    public static ApiResponse<T> Fail(string message, string? code = null);
}
```

Supporting types:
- `ApiResponse` - Non-generic version for operations without data
- `ErrorDetails` - Structured error information

#### HealthResponse.cs
Health check response for monitoring:

```csharp
public record HealthResponse
{
    public string Status { get; init; }      // Healthy/Degraded/Unhealthy
    public DateTime Timestamp { get; init; }
    public string? Version { get; init; }
    public ComponentHealth Components { get; init; }
}
```

Supporting types:
- `ComponentHealth` - Contains SDK and Database component status
- `ComponentStatus` - Individual component health details
- `HealthStatus` - Constants for status values
