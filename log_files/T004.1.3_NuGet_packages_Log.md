### Version Selection Rationale

1. **Serilog.AspNetCore 8.0.0**
   - Matches .NET 8.0 target framework
   - Latest stable version with full .NET 8 support
   - Includes RequestLogging middleware

2. **Serilog.Sinks.File 5.0.0**
   - Latest stable version
   - Supports rolling files, size limits, retention

3. **Serilog.Sinks.Console 5.0.1**
   - Latest stable with colored output
   - Good for development debugging

4. **Swashbuckle.AspNetCore 6.5.0**
   - Latest stable version
   - Full .NET 8 compatibility
   - Supports OpenAPI 3.0

5. **Swashbuckle.AspNetCore.Annotations 6.5.0**
   - Same version as Swashbuckle for compatibility
   - Enables [SwaggerOperation], [SwaggerResponse] attributes
