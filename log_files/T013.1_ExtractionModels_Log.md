### Pydantic V2 Features Used
- `Field()` with constraints (ge, le, min_length, pattern)
- `@field_validator` for custom validation
- `@property` for computed fields
- `model_dump()` for serialization
- `Optional[]` for nullable fields
- `Decimal` for currency precision

### Validation Rules
| Model | Rule |
|-------|------|
| BoundingBox | x1 >= x0, y1 >= y0, non-negative |
| ExtractionField | confidence 0.0-1.0, field_name min_length=1 |
| LineItemExtraction | line_number >= 1, quantity/price >= 0 |
| InvoiceExtraction | source_type pattern: text|scanned |
