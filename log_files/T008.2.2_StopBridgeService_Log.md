#### stopBridgeService Implementation
```typescript
async stopBridgeService(): Promise<void> {
  if (this.bridgeServiceStatus === ServiceStatus.STOPPED) {
    return;
  }

  this.updateStatus('bridge', ServiceStatus.STOPPING);

  // If no process exists (e.g., already crashed), just clean up
  if (!this.bridgeServiceProcess) {
    this.bridgeServiceProcess = null;
    this.updateStatus('bridge', ServiceStatus.STOPPED);
    return;
  }

  return new Promise((resolve) => {
    const process = this.bridgeServiceProcess!;
    let shutdownTimeoutId: NodeJS.Timeout | null = null;
    let forceKillTimeoutId: NodeJS.Timeout | null = null;
    let isResolved = false;

    // Handler for process exit
    const onExit = () => {
      if (isResolved) return;
      isResolved = true;

      // Clear timeouts
      if (shutdownTimeoutId) clearTimeout(shutdownTimeoutId);
      if (forceKillTimeoutId) clearTimeout(forceKillTimeoutId);

      // Clean up
      this.bridgeServiceProcess = null;
      this.updateStatus('bridge', ServiceStatus.STOPPED);
      resolve();
    };

    process.once('exit', onExit);

    // T008.2.2.1: Send SIGTERM for graceful shutdown
    try {
      process.kill('SIGTERM');
    } catch (error) {
      onExit();
      return;
    }

    // T008.2.2.2: Set timeout for graceful shutdown
    shutdownTimeoutId = setTimeout(() => {
      if (isResolved) return;

      // T008.2.2.3: Force kill with SIGKILL
      console.warn('Bridge Service did not shut down gracefully, force killing...');

      try {
        process.kill('SIGKILL');
      } catch { /* Process may already be dead */ }

      // Give SIGKILL a brief moment to take effect
      forceKillTimeoutId = setTimeout(() => {
        if (isResolved) return;
        process.removeListener('exit', onExit);
        onExit();
      }, 1000);
    }, this.config.shutdownTimeoutMs);
  });
}
```

## Architecture

```
stopBridgeService()
    │
    ├── Check if already stopped → return
    │
    ├── Update status to STOPPING
    │
    ├── Check if process exists
    │   └── No → clean up and return
    │
    ├── Setup exit handler
    │   └── onExit: clear timeouts, clean up, resolve
    │
    ├── Send SIGTERM
    │   └── Error? → call onExit and return
    │
    └── Start shutdown timeout
        └── Timeout exceeded?
            ├── Send SIGKILL
            └── Start force cleanup timeout
                └── Force onExit if still not resolved
```

## Shutdown Flow

1. **Status → STOPPING**: Signal that shutdown is in progress
2. **SIGTERM**: Request graceful shutdown (process can save state)
3. **Wait**: Up to `shutdownTimeoutMs` (default 5000ms)
4. **SIGKILL**: Force terminate if graceful shutdown fails
5. **Cleanup**: Clear process reference, set status to STOPPED

## Edge Cases Handled

1. **Already stopped**: Returns immediately (idempotent)
2. **No process**: Cleans up state without trying to kill
3. **Process ignores SIGTERM**: SIGKILL after timeout
4. **Process ignores SIGKILL**: Force cleanup after 1 second
5. **kill() throws**: Caught and handled gracefully
6. **Multiple stop calls**: Only first one executes
