## Implementation Details

### Objective
Create a sample environment file that documents all configuration settings with default values and explanatory comments.

### File Created

**Location**: `ai-service/.env.example`

```env
# ContPAQ-Win AI Service - Environment Configuration
# Copy this file to .env and adjust values as needed.
# Do NOT commit .env to version control.

# ===================
# Server Settings
# ===================

HOST=127.0.0.1
PORT=8000
LOG_LEVEL=INFO

# ===================
# Service Paths
# ===================

TESSERACT_PATH=C:\Program Files\Tesseract-OCR\tesseract.exe
MODEL_PATH=./models/layoutlm
```

### Settings Documented

| Setting | Example Value | Description |
|---------|---------------|-------------|
| `HOST` | 127.0.0.1 | Server bind address |
| `PORT` | 8000 | Server port |
| `LOG_LEVEL` | INFO | Logging verbosity |
| `TESSERACT_PATH` | Windows default | OCR executable path |
| `MODEL_PATH` | ./models/layoutlm | AI model directory |

### Design Decisions

1. **Comprehensive comments**: Each setting has explanatory comments
2. **Section organization**: Settings grouped by category (Server, Paths)
3. **Platform examples**: Notes for Windows, Linux, Mac paths
4. **Security reminder**: Header warns not to commit .env file

### Usage Instructions

```bash
# Copy to .env
cp .env.example .env

# Edit values as needed
nano .env  # or your preferred editor

# Run the service
python -m uvicorn main:app
```
