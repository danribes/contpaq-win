## Architecture Context

The Database component stores all application data locally using SQLite:

1. **Invoices** - PDF metadata, file paths, processing status
2. **Extracted Fields** - AI-extracted data with confidence scores
3. **Field Mappings** - User corrections for model improvement
4. **Audit Log** - History of all operations and changes

### Why SQLite?
- **Single file** - Easy backup and portability
- **No server** - No additional service to manage
- **Reliable** - ACID compliant, corruption resistant
- **Fast** - Excellent performance for local operations
- **Cross-platform** - Works on Windows and development environments
