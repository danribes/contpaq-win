### Design Decisions

1. **Top-level statements**
   - Modern C# pattern for minimal boilerplate
   - Cleaner than traditional Main() method
   - Standard for .NET 6+ templates

2. **Bootstrap logger**
   - Captures startup errors before configuration loads
   - Ensures logging works from first line

3. **Global exception handling**
   - try-catch around entire application
   - Log.Fatal for terminal errors
   - Proper cleanup with finally block

4. **No HTTPS/Auth**
   - Service is localhost-only (127.0.0.1:5000)
   - Called only by desktop app on same machine
   - Security enforced by OS firewall
