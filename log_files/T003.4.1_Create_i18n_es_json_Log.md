### Design Decisions

1. **Hierarchical Organization**: Grouped by feature area for easy maintenance

2. **Consistent Naming**: camelCase keys matching TypeScript interfaces

3. **Complete Coverage**: All UI text externalized for easy translation

4. **Context-Aware Messages**: Error messages explain the problem clearly

5. **Formal Spanish**: Using "usted" form for professional tone
   - "¿Está seguro...?" not "¿Estás seguro...?"
   - "Desea" not "Quieres"

6. **Mexican Spanish**: Using terminology common in Mexico
   - "Factura" for invoice
   - "RFC" for tax ID
   - "IVA" for VAT
