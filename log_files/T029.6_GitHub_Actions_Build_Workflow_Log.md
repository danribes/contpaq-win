Main CI/CD workflow file that orchestrates the entire build process.

## Issues Encountered and Resolved

### Issue 1: Vite Entry Module Not Found
**Error:** `Could not resolve entry module "index.html"`
**Cause:** Vite defaults to looking for `index.html` in project root, but it's at `src/renderer/index.html`
**Solution:** Created `vite.config.ts` with `root: path.resolve(__dirname, 'src/renderer')`

### Issue 2: Rollup Binaries Missing
**Error:** `Cannot find module @rollup/rollup-win32-x64-msvc`
**Cause:** Using `optional=false` in `.npmrc` skipped all optional dependencies including rollup binaries
**Solution:** Removed `optional=false` from `.npmrc`, used regular `npm ci`

### Issue 3: Canvas Native Module Rebuild Failure
**Error:** `Cannot open include file: 'cairo.h'`
**Cause:** electron-builder tries to rebuild canvas for Electron, but Cairo/GTK libraries aren't available on GitHub runners
**Solution:** Remove canvas from `node_modules` before electron-builder runs

### Issue 4: Missing tsconfig.main.json
**Error:** `The specified path does not exist: 'tsconfig.main.json'`
**Cause:** TypeScript config for main process was never created
**Solution:** Created `tsconfig.main.json` with CommonJS output configuration

### Issue 5: Missing CSS File
**Error:** `Could not resolve "./styles/index.css"`
**Cause:** The CSS file imported by `index.tsx` didn't exist
**Solution:** Created `src/renderer/styles/index.css` with Tailwind directives

### Issue 6: npm ci Network Timeouts
**Error:** `ETIMEDOUT` when downloading Electron
**Cause:** GitHub Actions runner network issues connecting to GitHub
**Solution:** Added retry logic with exponential backoff and alternative Electron mirror

### Issue 7: Missing Installer Assets
**Error:** `The system cannot find the file specified` (line 53 - icon.ico)
**Cause:** icon.ico, nssm.exe, and Tesseract binaries weren't in the repository
**Solution:** Added workflow steps to download NSSM, create placeholder icon, and download Tesseract

## Workflow Architecture

```
┌─────────────────────────────────────────────────────────┐
│                   GitHub Actions                         │
├─────────────────────────────────────────────────────────┤
│  Trigger: push tag v* OR workflow_dispatch               │
├─────────────────────────────────────────────────────────┤
│  1. Setup                                                │
│     ├── Checkout repository                              │
│     ├── Setup Python 3.11                               │
│     ├── Setup Node.js 20                                │
│     ├── Setup .NET 8.0                                  │
│     └── Install Inno Setup 6                            │
├─────────────────────────────────────────────────────────┤
│  2. Build AI Service                                     │
│     └── PyInstaller → contpaq-ai-service.exe            │
├─────────────────────────────────────────────────────────┤
│  3. Build Windows Bridge                                 │
│     └── dotnet publish → ContPAQWinBridge.exe           │
├─────────────────────────────────────────────────────────┤
│  4. Build Desktop App                                    │
│     ├── npm ci (with retry)                             │
│     ├── Vite build (renderer)                           │
│     ├── TypeScript compile (main)                       │
│     ├── Remove canvas                                   │
│     └── Electron Builder → win-unpacked/                │
├─────────────────────────────────────────────────────────┤
│  5. Prepare Installer Assets                            │
│     ├── Download NSSM                                   │
│     ├── Create/copy icon                                │
│     └── Download Tesseract                              │
├─────────────────────────────────────────────────────────┤
│  6. Build Installer                                      │
│     └── Inno Setup → ContPaq-proPDF-X.X.X-Setup.exe     │
├─────────────────────────────────────────────────────────┤
│  7. Release                                              │
│     ├── Upload artifact                                 │
│     └── Create GitHub Release (if tag)                  │
└─────────────────────────────────────────────────────────┘
```

## How to Trigger a Build

### Automatic (via tag)
```bash
git tag v0.1.3
git push origin v0.1.3
```

### Manual (via GitHub UI)
1. Go to Actions → Build Installer
2. Click "Run workflow"
3. Enter version number (e.g., 0.1.3)
4. Click "Run workflow"
