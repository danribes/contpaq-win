## Architecture Context

The Windows Bridge is one of three main components in the ContPAQ-Win architecture:

1. **Desktop App** (Electron/React) - User interface
2. **AI Service** (Python/FastAPI) - Invoice processing with LayoutLMv3
3. **Windows Bridge** (C#/.NET) - ContPAQi SDK integration ← This component

The Windows Bridge will:
- Run as a Windows service managed by NSSM
- Expose REST API endpoints for the Desktop App
- Use COM interop to communicate with ContPAQi SDK
- Handle document posting and company management
