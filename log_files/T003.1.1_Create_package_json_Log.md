### Design Decisions

1. **Vite for bundling**: Faster builds than webpack, great React support
2. **Electron ^28**: Latest stable version with security updates
3. **better-sqlite3**: Synchronous, fast SQLite for Electron
4. **Tailwind CSS**: Utility-first CSS framework per requirements
5. **TypeScript**: Type safety for main and renderer processes
6. **Separate build scripts**: Main and renderer built independently
