## Implementation Details

### Objective
Create a secure preload script that bridges communication between the main process and renderer process using Electron's contextBridge API.

### File Created

**Location**: `desktop-app/src/main/preload.ts`

### Core Components

#### 1. Imports
```typescript
import { contextBridge, ipcRenderer, IpcRendererEvent } from 'electron';
```

#### 2. ElectronAPI Interface

| Method | Type | Purpose |
|--------|------|---------|
| invoke | (channel, ...args) => Promise | Two-way IPC (request/response) |
| send | (channel, ...args) => void | One-way IPC (fire and forget) |
| on | (channel, callback) => void | Subscribe to main process events |
| removeListener | (channel, callback) => void | Unsubscribe from events |
| removeAllListeners | (channel) => void | Remove all listeners for channel |

#### 3. Channel Whitelisting

**Invoke Channels (Request/Response):**
- AI Service: `ai:extract-invoice`, `ai:check-health`, `ai:get-status`
- Windows Bridge: `bridge:check-health`, `bridge:get-vendors`, etc.
- Database: `db:get-invoices`, `db:save-invoice`, etc.
- App: `app:get-version`, `app:open-file-dialog`, etc.

**Send Channels (One-way):**
- `app:log`, `app:error`
- `window:minimize`, `window:maximize`, `window:close`

**Receive Channels (Events):**
- `ai:status-changed`, `bridge:status-changed`
- `app:update-available`, `app:update-downloaded`
- `invoice:processing-progress`

### Security Features

1. **Channel Validation**: Only whitelisted channels can be used
2. **No Direct ipcRenderer Access**: Renderer cannot access ipcRenderer directly
3. **Event Object Stripping**: IpcRendererEvent is not exposed to renderer
4. **Error Logging**: Invalid channel usage is logged for debugging

### API Exposure

```typescript
contextBridge.exposeInMainWorld('electronAPI', electronAPI);
contextBridge.exposeInMainWorld('api', electronAPI);
```

Accessible in renderer as:
- `window.electronAPI.invoke('channel', data)`
- `window.api.send('channel', data)`

### TypeScript Integration

```typescript
declare global {
  interface Window {
    electronAPI: ElectronAPI;
    api: ElectronAPI;
  }
}
```

### Design Decisions

1. **Dual namespace exposure**: Both `electronAPI` and `api` for flexibility

2. **Channel whitelisting**: Explicit list prevents unauthorized IPC calls

3. **Typed interface**: Full TypeScript support for IDE autocomplete

4. **Event callback wrapping**: Strips IpcRendererEvent for security

5. **Error handling**: Invalid channels return rejected promises or log errors
