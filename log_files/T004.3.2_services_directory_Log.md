### New Interfaces Added

#### IVendorService.cs
Interface for vendor (proveedor) operations:

```csharp
public interface IVendorService
{
    Task<VendorDto?> GetByRfcAsync(string rfc);
    Task<IEnumerable<VendorDto>> SearchAsync(string searchTerm, int limit = 20);
    Task<VendorDto> CreateAsync(CreateVendorRequest vendor);
    Task<bool> ExistsAsync(string rfc);
}
```

DTOs included:
- `VendorDto` - Vendor data transfer object
- `CreateVendorRequest` - Request to create vendor

#### IEntryService.cs
Interface for accounting entry (póliza) operations:

```csharp
public interface IEntryService
{
    Task<EntryResultDto> CreateAsync(CreateEntryRequest entry);
    Task<DuplicateCheckResult> CheckDuplicateAsync(
        string vendorRfc, string invoiceNumber, DateTime invoiceDate);
    Task<EntryResultDto?> GetByFolioAsync(string folio);
}
```

DTOs included:
- `CreateEntryRequest` - Request to create entry
- `EntryLineItem` - Line item for entry
- `EntryResultDto` - Result of entry creation
- `DuplicateCheckResult` - Result of duplicate check
