## Key Design Decisions

1. **Single Worker**: AI models share memory; multiple workers = multiple model copies
2. **Localhost Binding**: Security - Windows Bridge proxies external requests
3. **Long Timeout**: AI operations (OCR, inference) can take 30+ seconds
4. **Environment Detection**: Different settings for dev vs production
