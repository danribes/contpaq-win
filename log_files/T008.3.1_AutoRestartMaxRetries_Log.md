#### handleAutoRestart Method
```typescript
private handleAutoRestart(
  service: 'ai' | 'bridge',
  code: number | null,
  signal: string | null
): void {
  // Check if auto-restart is enabled
  if (!this.config.enableAutoRestart) {
    return;
  }

  // Check if max restarts exceeded
  const restartCount = service === 'ai' ? this.aiRestartCount : this.bridgeRestartCount;
  if (restartCount >= this.config.maxRestarts) {
    this.emitMaxRestartsExceeded(service);
    return;
  }

  // Increment restart count
  if (service === 'ai') {
    this.aiRestartCount++;
  } else {
    this.bridgeRestartCount++;
  }

  // Emit restart event with reason
  const reason = `crash (exit code: ${code}${signal ? `, signal: ${signal}` : ''})`;
  this.emitRestart(service, newRestartCount, reason);

  // Restart the service
  if (service === 'ai') {
    this.startAIService().catch(console.error);
  } else {
    this.startBridgeService().catch(console.error);
  }
}
```

### Integration Points

Auto-restart is triggered from exit handlers when:
1. Service status is NOT `STOPPING` (not a deliberate stop)
2. Exit code is non-zero (crash)

```typescript
// In startAIService exit handler:
this.aiServiceProcess.on('exit', (code, signal) => {
  if (this.aiServiceStatus === ServiceStatus.STOPPING) {
    // Normal shutdown - don't auto-restart
  } else if (code !== 0) {
    // Crash - trigger auto-restart
    this.handleAutoRestart('ai', code, signal);
  }
});
```

## Architecture

```
Process Crash Detection
    │
    └── Exit Handler (code !== 0 && status !== STOPPING)
        │
        └── handleAutoRestart()
            │
            ├── Check: enableAutoRestart?
            │   └── No → Return
            │
            ├── Check: restartCount >= maxRestarts?
            │   └── Yes → Emit maxRestartsExceeded, Return
            │
            ├── Increment restartCount
            │
            ├── Emit restart event with reason
            │
            └── Call startAIService() or startBridgeService()
```

## Key Behaviors

| Scenario | Result |
|----------|--------|
| Crash with auto-restart enabled | Auto-restart triggered |
| Crash with auto-restart disabled | No restart |
| Graceful stop (exit code 0) | No restart |
| Max restarts exceeded | maxRestartsExceeded event |
| Manual restart | Uses separate counter logic |

## Notes

1. **Independent Counters**: AI and Bridge services have separate restart counters
2. **Manual Reset**: `resetRestartCount(service)` allows resetting the counter
3. **Reason Tracking**: Restart events include the crash reason for debugging
4. **Non-Blocking**: Auto-restart is async and doesn't block the exit handler
