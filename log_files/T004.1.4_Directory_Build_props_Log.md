### Design Decisions

1. **TreatWarningsAsErrors = true**
   - Enforces code quality from the start
   - Prevents technical debt accumulation
   - All warnings must be resolved before commit

2. **WarningLevel = 5**
   - Maximum warning verbosity in C# 9+
   - Catches more potential issues
   - Includes all informational warnings

3. **Deterministic = true**
   - Ensures same source = same binary
   - Supports build verification
   - Important for security and deployment

4. **AnalysisLevel = latest**
   - Always use newest analysis rules
   - Catches modern anti-patterns
   - Automatic updates with SDK

### Inheritance Behavior
- Properties in Directory.Build.props are inherited by all .csproj files in subdirectories
- Individual projects can override settings if needed
- Reduces duplication across projects
