### Structure

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <meta http-equiv="Content-Security-Policy" content="..." />
    <meta name="description" content="ContPAQ Win - Sistema de gestión de facturas" />
    <title>ContPAQ Win</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="./index.tsx"></script>
  </body>
</html>
```

### Key Elements

| Element | Purpose |
|---------|---------|
| `<!DOCTYPE html>` | HTML5 doctype declaration |
| `<html lang="es">` | Spanish language attribute |
| `charset="UTF-8"` | UTF-8 character encoding |
| `viewport` meta | Responsive design support |
| `Content-Security-Policy` | Security headers |
| `<div id="root">` | React mounting point |
| `<script type="module">` | Module-based script loading |

### Design Decisions

1. **Spanish Language**: Set `lang="es"` for ContPAQ's target Spanish-speaking market

2. **Content Security Policy**: Restricts script sources to 'self' only, with inline styles allowed for Tailwind

3. **Module Script**: Uses `type="module"` for ES module support with Vite bundler

4. **Root Div**: Standard React convention with `id="root"` for ReactDOM.createRoot()

5. **Minimal HTML**: Clean, semantic HTML5 structure following modern best practices

### Security Features

- **CSP Header**: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'`
- **No inline scripts**: All JavaScript loaded from external modules
- **Strict resource loading**: Only allows resources from same origin

### Integration Points

- **Vite**: Script src references TSX file which Vite transforms
- **React**: Root div serves as mounting point for React app
- **Electron**: Loaded by BrowserWindow.loadFile() in main process
- **Tailwind**: Styles injected via index.tsx imports
