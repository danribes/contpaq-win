  return (
    <HashRouter>
      <div className="flex flex-col min-h-screen bg-gray-50">
        <header>...</header>

          <Routes>
            <Route path="/" element={<HomePage />} />

### Design Decisions

1. **HashRouter**: Used instead of BrowserRouter for Electron compatibility
   - Works with `file://` protocol
   - No server-side routing needed
   - URLs like `file://index.html#/processing`

2. **Placeholder Pages**: Created stub page components for:
   - HomePage - Will show invoice list
   - ProcessingPage - Will handle PDF upload and extraction
   - SettingsPage - Will show configuration options
   - NotFoundPage - 404 catch-all

3. **Tailwind CSS**: All styling uses Tailwind classes:
   - `flex flex-col min-h-screen` for full-height layout
   - `bg-gray-50` for subtle background
   - `max-w-7xl mx-auto` for content centering
   - Status indicators with colored dots

4. **Spanish UI**: All text in Spanish:
   - "Sistema de gestión de facturas"
   - "Procesar Factura"
   - "Configuración"
   - "Página no encontrada"
   - "Iniciando..."

5. **Status Bar**: Shows service health with:
   - AI Service status indicator
   - Windows Bridge status indicator
   - Version number
