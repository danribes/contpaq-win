## API Usage Example
```typescript
import { AIServiceClient } from './services/ai-service';

const client = new AIServiceClient('http://localhost:8000');

// Single file extraction
const file = new File([pdfBytes], 'invoice.pdf', { type: 'application/pdf' });
const extraction = await client.extractInvoice(file);
console.log(extraction.vendorRfc.value);

// Batch extraction
const files = [file1, file2, file3];
const batchResult = await client.extractBatch(files);
console.log(`Processed ${batchResult.successful}/${batchResult.totalFiles}`);

// Health check
const health = await client.checkHealth();
if (health.healthy) {
  console.log(`AI Service running v${health.version}`);
}
```

## Configuration Options
```typescript
interface AIServiceClientOptions {
  timeout?: number;     // Default: 60000ms
  maxRetries?: number;  // Default: 3
}
```

## Error Handling
- Network errors: Retry up to maxRetries with exponential backoff
- 4xx errors: Throw AIServiceError immediately (no retry)
- 5xx errors: Retry with backoff, throw after max retries
- Timeout: Throw AIServiceError

## Response Type Conversion
The client automatically converts Python API responses (snake_case) to TypeScript types (camelCase):
- `source_file` → `sourceFile`
- `vendor_rfc` → `vendorRfc`
- `processing_time_ms` → `processingTimeMs`
- Confidence values: 0-1 (decimal) → 0-100 (percentage)
