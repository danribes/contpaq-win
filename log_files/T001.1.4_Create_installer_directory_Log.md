## Architecture Context

The Installer component handles the deployment of ContPAQ-Win:

1. **NSSM (Non-Sucking Service Manager)** - Manages background services
2. **PowerShell Scripts** - Automate installation and configuration
3. **Assets** - Include icons, splash screens, and third-party binaries

The installer will:
- Register AI Service as a Windows service via NSSM
- Register Windows Bridge as a Windows service via NSSM
- Create desktop shortcuts for the Electron app
- Configure environment variables and paths
- Set up firewall rules for localhost-only services
