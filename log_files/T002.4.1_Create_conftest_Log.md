### Constants Defined

| Constant | Value | Purpose |
|----------|-------|---------|
| `FIXTURES_DIR` | `Path(__file__).parent / "fixtures"` | Directory for test fixture files |

### Design Decisions

1. **FIXTURES_DIR as module constant**: Allows other test modules to import and use the same path
2. **test_settings as dict**: Flexible configuration that can be extended or modified
3. **temp_env_file cleanup**: Uses try/finally to ensure temporary files are always deleted
4. **sample_pdf_path returns Path**: Returns expected path even if file doesn't exist yet, allowing tests to skip gracefully
5. **reset_settings_cache autouse**: Automatically clears lru_cache between tests to prevent test pollution
