### Configuration Structure

#### Content Configuration
Tailwind's content array specifies which files to scan for class names:

```javascript
content: [
  "./src/**/*.ts",
  "./src/**/*.tsx",
  "./src/**/*.html",
  "./index.html",
]
```

This ensures proper tree-shaking/purging in production builds.

#### Theme Extension

### Design Decisions

1. **Explicit file patterns**: Used separate `.ts` and `.tsx` patterns instead of glob braces for better readability and test compatibility

2. **ContPAQ branding colors**: Primary blue scale matches professional accounting software aesthetic

3. **Status colors**: Standard semantic colors for invoice processing states (success, warning, error, info)

4. **Typography**: Inter for UI text, JetBrains Mono for invoice data/numbers

5. **Empty plugins array**: Ready for future additions (forms, typography, etc.)

### Configuration Type

Used JSDoc type annotation for IDE support:
```javascript

```
