### Key Components

#### InvoiceRepository Class
```typescript
export class InvoiceRepository {
  constructor(db: Database.Database);

  async createInvoice(data: CreateInvoiceData): Promise<Invoice>;
  async getInvoiceById(id: string): Promise<Invoice | null>;
  async updateInvoice(id: string, data: UpdateInvoiceData): Promise<Invoice | null>;
  async listInvoices(options?: ListInvoicesOptions): Promise<Invoice[]>;
  async checkDuplicate(hash: string): Promise<DuplicateCheckResult>;
  async deleteInvoice(id: string): Promise<boolean>;
}
```

#### TypeScript Interfaces
- `Invoice` - Full invoice entity with all fields
- `CreateInvoiceData` - Required fields for creating invoice
- `UpdateInvoiceData` - Optional fields for updating
- `ListInvoicesOptions` - Filter options (state, states, limit, offset)
- `DuplicateCheckResult` - Result of duplicate hash check

#### Invoice States
```typescript
type InvoiceState = 'UPLOADED' | 'EXTRACTED' | 'VALIDATED' | 'POSTED';
```

#### Source Types
```typescript
type SourceType = 'text_based' | 'scanned';
```

### Key Features
1. **UUID Generation**: Uses `crypto.randomUUID()` for invoice IDs
2. **Timestamps**: Auto-sets `created_at` and `updated_at`
3. **Foreign Keys**: Validates `vendor_id` references
4. **State Validation**: SQLite CHECK constraints enforce valid states
5. **Duplicate Detection**: Hash-based duplicate checking
6. **Pagination**: Support for limit/offset in list queries
7. **Multi-State Filter**: Filter by single state or multiple states
